# 课表小组件显示规则

iOS、watchOS、Android、鸿蒙的课表小组件都按这份规则显示。小组件同时承担「日历小组件」的角色，所以主视角永远是今天。

> 2026-11-13 起 iOS 加了文字大小、上课倒计时与进度、隐藏已上完的课等显示开关和下一次课预告（第 10 节），假期倒计时在整宽的日期栏里收到「第 N 周」下面（第 1 节）。Android 已跟进。
>
> 2026-09-29 起 iOS 恢复了「最近节假日常驻」（第 1 节），默认开启；Android 2026-11-13 跟进（只在中号、大号整宽的日期栏里），鸿蒙未跟进。
>
> 2026-09-27 起 iOS 改了换日标注（第 2 节）、休息状态（第 3 节）、两日课表的放假祝福（第 4 节），并加了大号的显示方式（第 5 节）。Android 已跟进换日着色、假期状态、时间线及每个组件的独立设置；鸿蒙仍待跟进。

## 1. 日期栏

- 日期栏永远是今天：日期、星期、农历（「农历日期」开关）、第 N 周。
- 今天是法定假日、传统节日或节气时，日期栏带一个节日徽标。
- 「最近节假日常驻」开关（默认开，iOS 在 App 的小组件设置里）：开着时，今天不在假期里、120 天内有法定假期，日期栏第二行右边常驻一句倒计时「距国庆节还有 5 天」（天数用主题色大一号）。
  - 中号、大号整宽的日期栏：第二行没有课表名和跨日标注要写时，倒计时收到「第 N 周」下面，两行靠右，不单占一行。
  - 一行挤不下（小号）时换到下一行靠右；再放不下就不显示。Android 的小号不显示。
  - 不显示的情况：调休那天、第二行右边挂着「明天的课」时、两日课表（半宽列放不下）、下面正在显示休息状态（休息状态自己会大字写这段假期）。
  - 关掉时日期栏不报倒计时，假期只在休息状态里出现。

## 2. 课程区

按顺序判断，命中即停：

1. **今天还有没结束的课** → 显示今天的课。
   - 临近课程：当前或下一节起的课。
   - 今日课表：整天的课，已经下课的灰显（放不下时先省掉前面已下课的）。
2. **模式「接着显示下一次课」（默认）** → 今天之后 21 天内第一个有课的日子的课。
   - 日期栏照旧是今天，课程正上方挂一条标注说明这是哪天的课：「明天 周二」「后天 周三」「10/2 周五」（明天、后天不写日期）。
   - 课程照常上色，不压暗：压暗表示「已经上完」，拿来表示别的日子的课会被看成上过了。
   - 21 天内都没课 → 走第 3 步。
3. **模式「只看今天」**
   - 今日课表：今天排过课就继续列出今天的课（全部灰显）；今天本来就没课 → 休息状态。
   - 临近课程 → 休息状态。
4. **休息状态**（见第 3 节）。

模式在每个小组件自己的设置里选（iOS 为「编辑小组件」→「今天的课上完后」），只有这两项。没有单独配置入口的平台用默认值「接着显示下一次课」。

## 3. 休息状态

- 120 天内有法定假期时，排成和「临近课程」一门课一样的三行，贴着底边：
  - 还没开始：小标签「4 天后」（前一天是「明天」）、标题「国庆节」、说明「10.1 - 10.7 · 休 7 天」。上面另有一行小字说今天：今天排过课并已上完是「今日课程已结束」，本来没课是「今日无课」。
  - 正在假期里：小标签「放假中」、标题是祝福（「国庆快乐」「清明安康」）、说明同上。不写上面那行小字，「放假中」已经说明了。
- 120 天内没有假期：居中一行「今日课程已结束」或「今日无课」。不再有「周末快乐」。
- 大号今日课表在法定假日当天（今天本来没课）换成和两日课表一样的放假祝福，见第 4 节。
- 锁屏矩形：有假期时上面是标题（「国庆节」，放假中是祝福），下面「4 天后 · 10.1 - 10.7 · 休 7 天」；没有假期时是「今日无课」和「打开课表查看本周安排」。
- 锁屏单行只放一句：祝福 → 假期倒计时 → 「今日无课」，取第一个有的。

「节假日提示」开关关掉时，日期栏徽标、常驻倒计时和休息状态里的假期都不显示（「最近节假日常驻」跟着失效）。

## 4. 两日课表

- 左列是今天，右列默认是今天之后 21 天内最近有课的一天（找不到就是明天），可选固定为明天。
- 右列不是明天时，列头标「后天的课」「10/2 的课」。
- 某一列没课：其他日子写「没有课程」；今天那列写「今日无课」。
- 今天是法定假日时，今天那列换成放假祝福：彩炮图标、祝福（「国庆快乐」）、这段假期的起止日期，下面一天一个点标出放到第几天（「第 2 天 · 还剩 5 天」「假期最后一天」，只休一天的不画点）。清明换成叶子图标。关掉「节假日提示」时只留图标和祝福。
  - iOS、Android：彩炮可以点，点一下整个小组件放一次烟花（清明不放）；Android 遵循系统关闭动画的设置。
- 两天同一周时，「第 N 周」只在右列写一次。

## 5. 大号的显示方式

- 大号今日课表和两日课表可选「时间线」或「列表」（iOS 在「编辑小组件」里选，今日课表默认时间线，两日课表默认列表）。中号、小号一律列表。
- 时间线：左边一列起止时间，课程卡片按时长分高度、铺满组件高度，较长的课间单独标出。

## 6. 临近课程（中号）两栏标签

| 情况 | 左栏 | 右栏 |
|---|---|---|
| 正在上课 | 当前 | 接下来 |
| 今天还没开始上第一节 / 课间 | 下一节 | 之后 |
| 显示的是别的日子 | 第一节 | 接下来 |

## 7. 刷新时机

- 今天每节课开始、结束后 1 分钟。
- 午夜 00:01（换日）。
- 兜底每 30 分钟一次。
- 开着「上课倒计时与进度」时：每节课上课前一小时（「距上课」出现）。iOS 的倒计时和进度由系统计时器实时推进，不另刷新。Android 的倒计时由系统的 Chronometer 推进，它数到 0 不会自己停，所以桌面上有临近课程时另外逼近倒计时的终点（上课、下课的整点）重画一次；进度条画在图里，正在上课时每 5 分钟重画一次。

## 8. 数据来源

- 小组件只读 App 写在本地的一份课表，不自己请求服务端。App 每次拿到课表（整学期或单周）后按日期展开写入；退出登录时删除。
- 格式与 iOS `ios_next/CpuTime/CpuTime/NativeWidgetLocalSchedule.swift` 的 `Record` 一致：
  - `semester`：学期。
  - `days`：`[{ day, label, date, week, courses: [{ name, teacher, location, note, slotNote, startTime, endTime, startSlot, endSlot }] }]`，放假日写成空课表，调休补课日写成被调换那天的课。
  - `holidays`：`[{ date, name }]`，从周历调休表里 `kind == "off"` 的日子挑出、规整成法定节日名（见 `PublishedHoliday.fromOffDays`）。
- 按周取的快照只替换那一周的日子，同一学期的其他日子保留。
- 本地没有这份数据时（还没打开过新版 App），可以退回旧的服务端小组件接口。

## 9. 农历与节日

- 农历用系统的中国农历历法（iOS `Calendar(identifier: .chinese)`、Android `android.icu.util.ChineseCalendar`、鸿蒙 `@ohos.i18n` 的 chinese 日历）。
- 节日表、清明算法、徽标优先级（法定假日 > 节日 > 节气 > 农历）、祝福语、倒计时文案都照 iOS `ios_next/CpuTime/CpuTime/ChineseCalendar.swift`。
- `holidays` 覆盖离线推算的法定假期；没有发布的年份按节日离线推算。
- ICU（Android、鸿蒙）在朔落在北京时间午夜前后的几个月会把初一算错一天（如 2027 年春节晚一天、2030 年春节早一天），两端各有一张与 iOS 逐日比对得出的修正表（`ChineseCalendarInfo.java`、`ChineseCalendar.ets` 里的 `ICU_LUNAR_OVERRIDES`），两张表要保持一致。

## 10. 文字大小、倒计时与其余显示开关

在 App 的小组件设置里统一设置（iOS「设备与设置 › iPhone 小组件」，Android「课表 › 更多 › 桌面课表小组件」），旧版本存下的设置缺这些项时取默认值。

- **文字大小**：自适应、小（0.9）、标准（1，默认）、大（1.12）；每个小组件可以在自己的编辑页另选，默认跟随 App。
  - 整块内容一起缩放：内容排在 `1 / 比例` 大小的画布里再放大回去，字、色条、间距同一个比例；小组件四周的留白和背景不缩放。放大后放不下的课收进「后面还有 N 门课」，不挤出去。
  - 自适应依次试 1.16、1.08、1：最满的排法放得下就用，都放不下是标准大小，所以课少的日子字大、课多的日子和原来一样。Android 另外要求放大后没有字被截成省略号、周次没被挤掉。
  - iOS 锁屏的三种尺寸不缩放。日程小组件跟 App 里的设置（Android 的日程小组件「自适应」按标准大小）。
- **上课倒计时与进度**（默认开）：临近课程的「当前」「下一节」标题右边是「距下课 23:10」「距上课 12:40」，只给今天的课；「距上课」在上课前一小时出现。正在上的课下面有一条进度（临近课程的一栏、列表行、时间线卡片）。小号临近课程显示两节时没有标题行，也就没有倒计时和进度。
- **隐藏已上完的课**（默认关）：今日课表和两日课表今天那列不再把上完的课灰着留着。今天的课都上完时：选了「接着显示下一次课」照旧换到下一次课；「只看今天」的今日课表显示休息状态，两日课表今天那列写「今日课程已结束」。
- **时间线标出课间休息**（默认开）：关掉后时间线上半小时以上的课间不再标「休息 N 分钟」，只留一道窄缝。
- **周次**（默认开）：日期栏的「第 N 周」。
- **下一次课预告**：大号今日课表今天的课都放得下、底下还空着时，接着列下一个有课日开头的几门：一条「明天 周四」的标注，下面三门、两门或一门小一号的课（那天还有更多时标注右边写「后面还有 N 门课」）；连一门都放不下时退成一行，标注后面写「08:00 药物设计学 等 2 门」；再放不下不预告。时间线只在今天一两门课时预告（三门以上卡片本来就铺满），列表放得下就预告。选了「只看今天」不预告。

## Android 编辑入口

长按桌面小组件后选择编辑，或进入 App → 课表 → 更多 → 小组件，在“编辑桌面小组件”中选择对应实例。两个同类型组件的选项独立保存，取消编辑不保存。支持课后行为、小号节数、两日日期、大号时间线/列表、这一个小组件的文字大小，以及课程名称、教室、教师、时间、农历和节假日开关。添加时采用与 iOS 相同的默认值。移除组件会清理对应配置。

Android 使用 RemoteViews 与 Canvas 实现同一排版规则；日期和课程状态来自本地课表，放礼花仅在用户点击时短暂刷新透明图层。iOS 锁屏 WidgetKit 与 Android 桌面宿主是不同系统表面，本次对齐范围为五种桌面课表组件。
