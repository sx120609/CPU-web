药大拾间桌面端

把校园服务装进一个窗口，再加两件网页做不到的事。

它能替你做什么

  • 校园网自动连接掉线自动重认证；判断出你不在校园网时不会瞎试
  • 多平台学习入口六个平台统一从客户端打开，登录态和常用入口都保留在同一个壳里
  • 常驻后台关掉窗口收进托盘，可开机自启

两个开关，之后也能改

答案来自独立答题 AI，只发送当前题目内容，不携带站内知识库或用户资料；访问与额度策略由服务器实时下发。

打开学习平台

选择平台后会在客户端新标签中打开，登录态、窗口和常用入口都保留在同一个壳里。

账号密码按平台分别使用系统安全存储加密；仅在对应平台出现账号密码登录框时自动填充。二维码、短信验证码不会保存。
有新版本 学习平台改版后旧版入口可能失效，建议更新。
