药大拾间桌面端

校园服务，装进一个窗口。

网站的全部功能照常可用，另外再做两件网页做不到的事：自动连校园网，以及在客户端里上网课。

它能替你做什么

三件事，开着就在做。

  • 校园网自动连接掉线自动重新认证；判断出你不在校园网时不会瞎试
  • 多平台网课标签七个平台统一从客户端打开，助手自动识别视频、作业与考试
  • 常驻后台关掉窗口收进托盘，可开机自启

最后两个开关

之后随时能在“工具”里改。

答案来自独立答题 AI，只发送当前题目内容，不携带站内知识库或用户资料；访问与额度策略由服务器实时下发。

有新版本 网课平台改版后旧版助手可能失效，建议更新。

概览

客户端在后台替你做的事，以及常用入口。

打开网课平台

平台会在客户端新标签中打开，助手按平台自动接管。账号密码保存在“网课助手”里设置。

网课助手

自动化、答题方式与各平台账号。

运行状态选择网课平台后，助手会在对应标签页自动接管。 运行中

自动化

以上改动要重新打开对应的网课标签才生效。

答题

每题间隔随机等待，切章与提交前等待由客户端采用稳妥默认值 – 秒

平台账号密码

账号密码按平台分别使用系统安全存储加密；仅在对应平台出现账号密码登录框时自动填充。二维码、短信验证码不会保存。
