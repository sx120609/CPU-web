# 2026-07-02 工作日志

## 刷课工具项目启动（药大刷课助手）

### 背景
用户要做一个学习通/知到刷课工具，针对"水课"通识视频。要求：
- 用户必须登录平台账号才能用
- 视频刷课免费（拉人气），AI 答题按额度计费
- 桌面 App 形态，对小白友好

### 关键决策
1. **复用现有平台账号体系**：CPU-web 项目已有完整的学校 SSO 登录 + JWT + authRequired 中间件，不重新造轮子
2. **客户端技术栈**：Electron + Vue3 + Element Plus（复用现有前端栈），放在 desktop/ 目录
3. **自动化方案**：MVP 用 Electron BrowserWindow + executeJavaScript 注入（油猴脚本同款），不额外装 Playwright Chromium，省 150MB。反检测后续迭代
4. **额度模型**：视频免费 / AI 计费。新增 CourseBotQuota（余额）+ CourseBotUsageLog（消耗流水+错题沉淀）两张表

### 后端改动（server/）
- `prisma/schema.prisma`：新增 CourseBotQuota、CourseBotUsageLog 两表，User 加关系字段
- `src/routes/courseBot.ts`（新）：/quota 查额度、/heartbeat 心跳校验登录态、/ai-answer 预留
- `src/routes/index.ts`：挂载 /course-bot 路由（authRequired）
- `src/utils/loginClient.ts`：新增 desktop 客户端类型识别

### 客户端骨架（desktop/，全新）
- `electron/main.ts`：主进程，窗口管理 + IPC + JWT安全存储(safeStorage)
- `electron/store.ts`：JWT 加密落盘
