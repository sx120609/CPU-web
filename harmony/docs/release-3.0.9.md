# HarmonyOS 3.0.9（29）发布包

包名 `cn.lizmt.cpuweb`。版本清单、启动地址和 User-Agent 均为 3.0.9（29），沿用既有发布证书与 Profile。

## 更新内容

- 新增宿舍课表：从原生课表「更多」进入，用宿舍码邀请室友，查看共同空闲时间与未来一周的早八名单。原生端提供当前学期完整课表，界面和计算规则与网页共用；独立日程尚不参与宿舍空闲计算。
- 日程接入个人课表：周视图按时间显示日程，日视图列出当天安排，支持新建、修改和勾选；与网页和其他客户端使用同一份日程数据。
- 课程支持自定义起止时间；宿舍快照保留本地课程修改和自定义时间。
- 修复空闲时段漏报、缺失课表数据误判和账号切换期间的同步问题；优化手机上的触控、文字和深浅色显示。
