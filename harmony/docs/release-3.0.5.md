# HarmonyOS 3.0.5（25）发布包

包名 `cn.lizmt.cpuweb`，应用清单、入口版本参数与 User-Agent 为 3.0.5（25）。沿用既有发布证书和 Profile，历史导出包保留。版本号按要求从 3.0.3（23）直接到 3.0.5（25），仓库里没有 3.0.4（24）的构建或记录。

## 更新内容

相对 3.0.3（23），课表与 iOS 4.14 对齐（提交 `3d3b0d99`）：

- 六种课表风格（经典、简约、格子、表格、素笺、站牌），覆盖周、日、月三种视图；经典仍是默认值。深色课表改用网站深色主题的中性灰，课程配色不变。
- 月视图：带农历、节日与调休标记的月历，下方列出所选日期的课程，可跳到当天的日视图。
- 今天所在的列标出当前时间；日视图标出正在上、即将开始和已结束的课程。
- 放假日不显示课程，调课日显示被调来那天的课程；可隐藏周末，周末有课或调休时仍显示。
- 点课程打开速览，速览里的「编辑」进入编辑器；编辑器支持一门课多个上课时间和不连续的节次，并提示时间重叠。
- 重叠的课程并排显示，可设为「优先显示」。
- 共享课表：生成、更新、撤销分享码；输入分享码或链接，预览后保存到本机，只读打开。
- 编辑器桥接受网页课表定义的全部节次；此前第 12 节在原生编辑器里可选但保存被拒。

未移植：iOS 上「关心」某份共享课表以接入实时活动；「分享所选周课表」仍是文字。

## 服务端依赖

共享课表的「我的分享码」「摘要」接口和个人修改里的 `priority` 字段来自服务端提交 `a9d92248`。旧服务端上：自己的分享码列表为空、每次发布得到新码、撤销失败；优先显示的开关保存后不生效。其余功能不依赖它。本次没有确认线上服务端的版本。

## 商店截图

仿照 iOS 截商店图的做法：用同一份示例课表（iOS 的 `NativeScheduleDebugFixture`，18 门课，学校作息时间），放在与登录后相同的底部标签栏里，不需要账号。脚手架的 `--ps data promo` 提供这份数据，`--ps clean true` 隐藏模拟器的系统状态栏，`--ps now 14:00` 固定当前时间。

```sh
node harmony/scripts/capture-store-screenshots.mjs <hdc.exe> <device> <dir>/screens
python harmony/scripts/compose-store-screenshots.py <dir>/screens <dir>/posters
```

- `screens/`：12 张 1080 × 2340 的原始界面（周视图经典／简约／素笺、日视图站牌／简约、月视图经典／简约、课程速览、课程编辑、共享课表、深色格子与深色经典）。
- `posters/`：7 张 1080 × 1920（9:16）的带标题图，字体为 Noto Sans SC（SIL OFL）。

截图来自验收包而不是签名包：界面组件相同，数据是示例，共享课表页显示的分享码是替身给的假码。AppGallery 对截图尺寸和张数的现行要求没有核对。
