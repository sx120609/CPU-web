# HarmonyOS 3.0.10（30）发布包

包名 `cn.lizmt.cpuweb`。版本清单、启动地址和 User-Agent 均为 3.0.10（30），沿用既有发布证书与 Profile。

## 更新内容

- 日程和课表合为一体：点课表上的日程直接在课表上编辑、删除；点空着的节次可选「添加日程」或「添加课程」，日期和开始时间自动填好；更多菜单新增「日程与待办」，可一句话记下一条，查看待办和接下来一周的安排，并开关「微信和 QQ 也提醒」。不再跳到服务栏目里的网页。
- 修复「现在」时间线停在打开课表时的位置：午休时它会落在第 4、5 节之间，不再显示在第四节里；课表上的日程块也随课表高度正确对齐。

## 来源与验证

- 源码提交：`5a0125a560cf6f6db3ecf457809f713dd13606b6`，通过 `git archive` 导出后独立构建。功能提交为 `b1efee8f`（时间线）与 `15bd2b30`（日程）。
- 站点已部署 `15bd2b30`，日程编辑依赖的网页桥 `save` / `remove` / `relay` / `parse` 已在线上。
- DevEco Studio 6.1.1 / SDK API 24 执行 release `assembleApp` 成功；包内 `buildMode=release`、`debug=false`、版本 3.0.10 / 30，随包桥与源码字节一致，只含 `pages/Index`。
- 内层 HAP、外层 APP 均使用原发布证书签名，并通过华为 `verify-app`；最终 APP 内的 HAP 与独立签名 HAP 逐字节一致。
- 鸿蒙回归 194 项通过（含新增的日程保存、删除和一句话识别测试）。功能在模拟器验收壳中验证过：午休时间线、各课表风格与日视图、点空节次新建日程、点日程编辑与删除、「日程与待办」。
- 签名 HAP 在模拟器上从 3.0.9 覆盖安装，访客冷启动、热启动与冷启动课表深链均显示原生登录页。
- 未进行真机验收、真实账号登录下的日程读写及通知提醒验收。签名与构建验证不代表设备验收或平台审核通过。
