# HarmonyOS 3.2.1（34）发布包

包名 `cn.lizmt.cpuweb`，应用名「药大拾间」。版本清单、启动地址和 User-Agent 均为 3.2.1（34）。发布证书和发布 Profile 与 3.2.0 相同（2026-11-06 生成的「药大拾间发布Profile-锁屏卡片」）。

## 更新内容

- 目标 SDK 从 HarmonyOS 6.1.1（API 24）升到 HarmonyOS 7（API 26.0.0），最低仍为 HarmonyOS 6.0（API 20）。这是第一个用 DevEco Studio 26.0.0 / SDK 26.0.0.105 构建的包。
- 课程只响应点按：周视图的六种风格、日视图和双栏日条里的长按菜单及预览卡片都已取消。点课程打开速览，速览底部是这门课的操作：编辑整门课、调整这一次、在这节课加日程、这次停课；调过的那一节可以再调整或恢复原安排，停课的那一节只提供恢复。
- 停课那一节的速览不再显示日程一栏；日程为空时的提示只在有添加按钮时才提到按钮。
- 从未选过课表风格的用户默认用「简约」。原来存着「经典」的，首次启动本版时改成「简约」一次；之后再选回「经典」会保留。
- 情侣课表、宿舍课表和共享课表的邀请链接改为以站点根地址拼接，不再打开网页的 404 页。
- 应用市场有新版本时，用系统的更新弹窗提示。

## 目标版本升到 26.0.0 带来的变化

- 阴影半径为 0 在目标版本 26.0.0 起会画出不带模糊的阴影。日视图「已上完」的课程卡片原来靠 0 表示不要阴影，已改为 `-1`。
- 对话框、Toast 和文本选择菜单在 HarmonyOS 7 上默认使用系统的沉浸式材质；下拉选择、小号按钮的触摸热区最小高度从 28 vp 变为 32 vp；组件内置文本的换行有调整。这几项没有改代码，也没有在 HarmonyOS 7 设备上看过。
- 用 SDK 26 编译时，`Circle().fill()`／`.stroke()` 报 22 条「26.0.0 起支持」的警告：API 26 为 `Circle` 增加了可传 `ColorMetrics` 的重载。本项目只传颜色字符串和资源，在 API 24 模拟器上圆点照常绘制。

## 商店发布

本版不依赖站点部署：邀请链接和更新提示所需的网页与接口已在线上（生产提交 `9cc0e9ed`）。软件包上传时选「测试和正式上架」，商店信息沿用已发布版本。

建议的「新版本特性」：

> · 适配 HarmonyOS 7。
> · 点一下课程就能看详情并操作：编辑整门课、只调整这一次、这次停课、在这节课加日程，都在同一处。
> · 课表默认使用“简约”风格，仍可在课表设置里换回其他风格。
> · 修复情侣课表、宿舍课表和共享课表的邀请链接打开后提示页面不存在的问题。
> · 应用市场有新版本时会提示更新。

提交和审核结果以 AppGallery 控制台为准。
