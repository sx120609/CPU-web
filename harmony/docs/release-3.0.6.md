# HarmonyOS 3.0.6（26）发布包

包名 `cn.lizmt.cpuweb`，应用清单、入口版本参数与 User-Agent 为 3.0.6（26）。沿用既有发布证书和 Profile，历史导出包保留。

## 更新内容

相对 3.0.5（25），提交 `bc268ff2`：

- 修复课程备注：课表把课程的备注显示成合并节次后的标签（如「06-07节」），在编辑器里保存这门课会用它覆盖原来的备注。3.0.3 起就有。现在课程块在节次标签之外保留课程原来的备注，速览和编辑器只读人写的备注；教务给的「06-07节」和空备注保存成的「第 6-7 节」不算备注。规则与网页 `noteFromCourse`、安卓 `editableNote` 相同。已经被覆盖掉的备注找不回来：存下来的就是那个标签。
- 跟进 iOS 4.14（70）的课表改动（iOS 提交 `234bf66d` 里课表的部分）：
  - 日视图的七天条由各风格自己绘制，就是它周视图的日期表头，选中的日期和今天各有标记：简约是浅色圆角块，格子是带框的方块，表格是填满的格子，素笺是一层淡色，站牌是反白的色块，今天保留下划线。经典沿用原来的七天条。
  - 站牌只在时间和日期上用等宽字体，课程名、教室等改用系统字体，数量和倒计时用等宽数字。
  - 站牌的日视图在开始时间下方写结束时间，行尾不再重复「上午／下午／晚上」。
  - 站牌周视图表头的日期写成「05」，加粗。
  - 周次和月份标题跟随风格的字体；素笺和站牌下，导航条用风格自己的墨色。
- 随包的课程编辑桥带上了 `48963949` 的修复：隐藏或编辑一门课，不再把它另一段周次的同名课一起隐藏。这个修复在 3.0.5 打包之后合入，本版第一次随鸿蒙包发出。

与 iOS 不同：七天条始终显示七天（本端日视图的左右滑动就是七页），周视图隐藏空周末时也一样。

未移植：iOS 同一提交里的相机／相册权限说明和网页文件下载，是 iOS 外壳自己的问题；iOS 上「关心」某份共享课表以接入实时活动；「分享所选周课表」仍是文字。

iOS 端备注的同一个问题还在（速览和编辑器直接读 `slotNote`），本机没有 Swift 工具链，没有改。
