# HarmonyOS 3.0.3（23）发布包

2026-10-06。包名 `cn.lizmt.cpuweb`，应用清单、入口版本参数与 User-Agent 同步为 3.0.3（23）。保留既有发布证书、Profile 和历史导出包。

## 更新内容

- 手机课表对齐 Web 的控件顺序、间距、课程颜色、渐变和边框；修复日视图日期条覆盖第一节课程。
- 节次数量和时间读取校历配置，支持完整 12 节；周／日网格、课程详情、个人课程编辑和文本／ICS 导出使用相同配置。
- 日视图的上一周／下一周正确切换周次。
- 共享桥等待登录状态初始化完成后再报告账号；兼容旧课表缺少当前周的情况；教务会话恢复保留学期选择器，切换账号清空，可信校历元数据可更新。
