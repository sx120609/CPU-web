# HarmonyOS 3.0.3（23）发布包

包名 `cn.lizmt.cpuweb`，应用清单、入口版本参数与 User-Agent 为 3.0.3（23）。沿用既有发布证书和 Profile，历史导出包保留。

本页记录 2026-10-07 的 r2 包，它取代 2026-10-06 的首个 3.0.3 包（`output/harmony-3.0.3/`，未上传 AppGallery）。首个包构建自一个落后于 `main` 的本地工作区，缺少 `main` 上已有的服务卡片与课表改动，不应再使用。

## 更新内容

相对已发布的 3.0.1（21）：

- 原生登录页：未登录时显示原生登录（统一认证、保持登录、须同意隐私政策与用户协议），登录仍由网页的登录流程完成。
- 日视图使用独立的七天分页和日期条；修复历史学期切换后学期选项累积、选错学期无法继续切换的问题。
- 节次数量和时间读取校历配置，支持完整 12 节；周／日网格、课程详情、个人课程编辑和文本／ICS 导出使用同一配置。
- 课表顶部与 iOS、安卓客户端一致：一排胶囊控件和一排无边框的周次切换，日期栏只高亮今天或所选日期；360 vp 宽的手机一屏显示完整 12 节，课程名每行至少四个汉字。
- 网页“存储与缓存”页可以统计并清理 ArkWeb 的网络缓存和临时文件；登录状态与站点数据不在清理范围内。
- 包含 `main` 上 3.0.1 之后的鸿蒙改动（服务卡片本地课表、农历与节假日、调休等）。

共享课表桥没有改动，随包 `NativeWebCompatibility.js` 与 `main` 的生成结果一致。
