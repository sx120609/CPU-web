# HarmonyOS 3.1.0（31）发布包

包名 `cn.lizmt.cpuweb`，应用名改为「拾间校园」。版本清单、启动地址和 User-Agent 均为 3.1.0（31），沿用既有发布证书与 Profile。

## 更新内容

- 应用名改为「拾间校园」。桌面图标和应用列表显示新名称；App 内按所选学校显示品牌（药大拾间、南医拾间）。
- 原生登录页可以选择学校：学校列表来自站点 `/api/schools`；选定后统一认证、验证码和品牌名都按该校显示；没有统一认证的学校直接使用站内账号登录。
- 学校要求新设备扫码确认时（南医），登录页显示学校给的二维码，并自动查询扫码结果。二维码可以通过系统保存按钮存进相册，再按学校给的链接打开扫码 App；可以换一张二维码，也可以返回登录。
- 学校选择和扫码验证由随包桥安装，未登录时也可用，不依赖站点为鸿蒙安装原生桥。
- 课表卡片的默认标题改为「课表」，实际显示的标题由站点按学校给出。

## 来源与验证

- 源码提交：`0b2e9aa937ceaa98d448dd0b7b477b33aae850fd`，通过 `git archive` 导出后独立构建。功能提交为 `96405999`（登录页选校与扫码）和 `2b37ffc1`（随包桥安装登录接口）。
- DevEco Studio 6.1.1 / SDK API 24 执行 release `assembleApp` 成功。包内 `buildMode=release`、`debug=false`，版本 3.1.0 / 31，随包桥与源码一致，只含 `pages/Index`，应用名资源为「拾间校园」。
- 内层 HAP 和外层 APP 均使用原发布证书签名，并通过华为 `verify-app`。最终 APP 内的 HAP 与单独签名的 HAP 逐字节一致。
- 鸿蒙回归测试 195 项全部通过。
- 本机站点（含学校驱动和扫码说明）配合模拟器，用调试包验证：
  - 学校列表、切换学校与品牌名、重启后保留所选学校。
  - 扫码面板：二维码、已扫描状态、系统保存授权与保存到相册、无扫码 App 时的提示、返回登录。扫码结果为模拟数据。
- 签名 HAP 在模拟器上覆盖安装 3.0.10：
  - 访客冷启动、热启动与冷启动课表深链都显示原生登录页，登录页连接线上站点时已显示学校选择。
  - 桌面图标名称为「拾间校园」。
- 未进行真机验收，也未用真实南医账号完成扫码登录。签名与构建验证不代表设备验收或平台审核通过。
