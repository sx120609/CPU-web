# HarmonyOS 3.3.0（35）发布包

包名 `cn.lizmt.cpuweb`，应用名「药大拾间」。版本清单、启动地址和 User-Agent 均为 3.3.0（35）。发布证书和发布 Profile 与 3.2.1 相同（2026-11-06 生成的「药大拾间发布Profile-锁屏卡片」）。

## 更新内容

- 服务卡片的显示开关（「更多 › 桌面与锁屏服务卡片」）：
  - 文字大小：自适应、小、标准、大。整块内容一起缩放，放不下的课数进「后面还有 N 门课」；「自适应」在课少时放大。锁屏卡片不缩放，日程卡片跟同一个设置。
  - 上课倒计时与进度：临近课程的「当前」「下一节」右边是「距下课」「距上课」，上课前一小时出现；正在上的课下面有一条进度。卡片自己带时钟按秒走，不等系统刷新。
  - 隐藏已上完的课、周次、农历日期、节假日提示、最近节假日常驻，以及课程名称、教室、老师、上课时间四项课程信息。
- 卡片排版：整宽日期栏把假期倒计时收到「第 N 周」下面；4×4 今日课表底下有空位时预告下一次课。
- 情侣课表和叠加课表的周视图可以选「并排」（双栏日条，默认）或「合并」（两人的课排在同一张周课表里），入口在「课表样式」和情侣课表管理页；双栏日条第一次出现时有一条带「改回合并」的提示。
- 「课表怎么用」指引：课表第一次显示时出现一次，之后在「更多 › 使用指引」里打开；简约风格下可以直接换回「经典」。
- 修复：表格、素笺风格的卡片里半宽日期栏的「第 10 周」被裁掉最后一个字；站牌风格的合并周视图里卡片上的上课时间被裁成「08:0」；日程卡片最后几行被切掉。

各项的规则见 [小组件显示规则](../../docs/schedule-widget-rules.md) 的「鸿蒙服务卡片」一节和 [README](../README.md)。

## 商店发布

本版不依赖站点部署。软件包上传时选「测试和正式上架」，商店信息沿用已发布版本。应用市场在售的是 3.2.0（33），3.2.1（34）没有上架，所以「新版本特性」把 3.2.1 的内容一并写上：

> · 服务卡片可以调文字大小，课少的日子自动放大。
> · 卡片上显示“距下课”“距上课”的倒计时，正在上的课带一条进度。
> · 卡片新增隐藏已上完的课、周次、农历、节假日等显示开关；大号今日课表会预告下一次课。
> · 情侣课表和叠加课表的周视图可以选“并排”或“合并”，不习惯两栏的可以改回原来的样子。
> · 新增“课表怎么用”指引，可以一键把风格换回“经典”。
> · 适配 HarmonyOS 7；点一下课程就能看详情并操作。
> · 修复邀请链接打开后提示页面不存在的问题。

提交和审核结果以 AppGallery 控制台为准。
