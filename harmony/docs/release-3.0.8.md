# HarmonyOS 3.0.8（28）发布包

包名 `cn.lizmt.cpuweb`，应用清单、入口版本参数与 User-Agent 为 3.0.8（28）。沿用既有发布证书和 Profile，历史导出包保留。

## 更新内容

相对 3.0.7（27）：

- 情侣课表（规则与网页、安卓相同，见 [docs/couple-schedule.md](../../docs/couple-schedule.md)）：
  - 课表页的管理面板：生成邀请码、输入邀请码绑定、解除、暂停共享、选自己的颜色（七种，选对方正在用的就是互换）。
  - 打开「显示 TA 的课」后一个人一种颜色。TA 单独的课整格用 TA 的颜色并带「TA」标签；与我的课同一时段时，在我的课下方写一行「TA 课名」；两人同上的课写「♥ 一起」。
  - 日视图时间轴居中，左边是我的课，右边是 TA 的课。
  - 周标题下的状态行：TA 现在在上什么课、在一起的天数、显示开关。
  - 自己的课表有变化时上传快照，供对方查看。
- 月视图：去掉下方的当日课程列表，格子里直接列课名（最多三行，再多显示「+N」）；点某一天进入那天的日视图。双人模式下每天多一行「TA N 门」。
- 同一时段排了两门不同的课时弹一次提示：多半是教务数据有误，先到教务系统核对，确有问题再点课程编辑或删除。同一处只提醒一次，设了优先显示的不算。
- 教室显示：「教学楼A102」写成「A102」，覆盖课表格子、速览、分享文字、日历导出、桌面卡片和读屏标签。只对「教学楼＋A–E 楼栋＋房号」生效；课程数据不变，隐藏和编辑记录仍按原始地点匹配。

## 服务端依赖

- 情侣课表的颜色选择需要服务端带有 `CoupleMember.color`（迁移 `20261009090000_add_couple_member_color`）。服务端未部署时，颜色保持默认的蓝／粉，其余功能不受影响。
- 绑定、上传快照和读取对方课表使用已上线的 `/api/couple/*` 接口。
