# 人脸识别
来源：https://xxh.cpu.edu.cn/rlsb/list.htm
部门：信息化建设管理处

您可以在企业微信【工作台】-【人脸识别】应用自助添加或更换照片用于校园门禁通行，如在人脸门禁识别过程感觉识别速度较慢或需多次识别时，依自身需要可按照下面的操作步骤进行人脸识别照片的更换。

准备工作：下载并安装企业微信App并已加入中国药科大学企业。

打开企业微信App，点击工作台-【人脸识别】：

1. 添加照片

(1).《人脸识别采集使用授权书》，确认并勾选我同意；

(2).点击下方统一拍照按钮->确定拍照->开始拍照，选择拍照或相册中的一张新人像照片（建议：纯色背景如白墙下的正脸五官清晰无后期处理），确认后点击【上传】。

出现“核验通过”提示信息即为成功添加，可即时使用人像照片用于人脸识别通行。

2.更换照片

在更换照片上传后如出现“比对失败，该照片与人员极可能不是一个人”提示信息，请更换另一张照片；多次上传仍失败可请携带本人有效证件（如身份证、学生证、校园卡）到江宁校区图书馆七楼704信息应用部现场更换。
