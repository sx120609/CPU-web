# 客户端绑定校园邮箱操作说明
来源：https://xxh.cpu.edu.cn/b4/33/c13644a242739/page.htm
日期：2026-07-31
部门：信息化建设管理处

1. 普通用户建议使用网易邮箱官方客户端“网易邮箱大师”绑定校园邮箱。

2. 第三方客户端配置指南：

（1）登录网页版邮箱，点击左上角的设置—>邮箱设置

（2）点击客户端设置—>生成客户端授权码

填写客户端授权码信息，确认生成。

（3）红框中的即为客户端授权码，在配置邮件客户端时使用，每个授权码只能绑定一次。

（4）将授权码填写在第三方邮件客户端配置页面密码栏即可（不要填写邮箱登录密码）
