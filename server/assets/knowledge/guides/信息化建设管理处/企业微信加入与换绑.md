# 企业微信
来源：https://xxh.cpu.edu.cn/qywx/list.htm
部门：信息化建设管理处

中国药科大学企业微信账号扫码加入操作步骤

一、下载企业微信APP。

二、使用微信app扫描注册二维码

三、具体操作步骤：

1.点击加入学校按钮

2.加入成功后点击打开企业微信；

3.选择微信登录

4.点击下方待加入企业

5.选择中国药科大学

6.进入企业微信会自动跳转至 统一身份认证页面

7.输入自己的账号及密码

8.认证成功后会自动跳转至首页，企业微信第一次加载需要一定时间（根据网络环境略有不同）

9.认证完成

解绑中国药科大学企业微信手机号码更换操作步骤

一, 具体操作步骤（手机号无法找回）

1.进入账号管理页面

2.当手机号码丢失无法找回 进入修改手机号码

3.输入手机号码后，完成操作（此操作会删除当当前账号，请谨慎操作）

二, 具体操作步骤（手机号可用）

1.进入账号管理页面

2.进入更换手机文档，按照文档步骤进行操作

注销中国药科大学企业微信账号操作步骤

一、具体操作步骤

①进入账号管理页面

②点击注销按钮（此操作不可逆，请谨慎操作）
