# 微软Windows-Office
来源：https://xxh.cpu.edu.cn/wrWindows/list.htm
部门：信息化建设管理处

一、适用范围

校园网用户（包括教职员工、学生）均可使用微软正版软件下载与激活服务。

二、软件版本

1.操作系统：Windows 8（32位/64位）、Windows 8.1（32位/64位）、Windows 10（32位/64位）中英文版本、Windows 11。

2.办公软件：Office 2013（32位/64位）、Office 2016（32位/64位）、Office 2019（32位/64位）、Office 2021(32/64位)、Office 2024(32/64位)。

3.办公软件：Office for Mac 2019、2021、2024标准版。

4.windows、office新版本在服务期内自动更新发布。

三、Windows激活流程

1.下载正版软件及激活客户端下载地址：http://ms.cpu.edu.cn(校内网访问)

2.安装操作系统或办公软件。办公软件为ISO格式 ，请使用解压软件解压后安装；

3.激活步骤，共有两种激活方式，在此以“激活脚本”为例：

下载并解压“激活脚本”、右击激活脚本，选择“以管理员身份运行”，如图1所示：

四、MacOS Office激活流程

下载相应的Office for Mac，解压后有两个文件，大文件为Office安装包，小文件为激活文件。先运行安装包进行安装，后运行激活文件进行激活。

五、相关说明

1.激活客户端必须在校园网内使用且只需在软件安装后运行一次，此后不需再次运行。激活后的计算机需要每半年连接到校园网一次，系统将自动完成验证激活工作。

2.任何用户都有保护知识产权的义务，禁止未经授权向校外任何个人和组织分发软件副本和激活程序。

3.微软校园软件正版化实施后，校内各单位无需购买已有版本的微软相关软件（Windows、Office等）。

4.使用微软正版软件后，仍然需要及时访问微软的补丁更新网站，及时修补安全漏洞，降低安全风险。

5.在更换微软正版操作系统时，请各位师生先备份数据，以防数据丢失。

6.正版化软件以年为单位提供服务，请关注相关信息发布。
