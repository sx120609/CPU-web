# Web VPN系统使用说明
来源：https://xxh.cpu.edu.cn/06/5d/c13645a198237/page.htm
日期：2025-09-23
部门：信息化建设管理处

1.浏览器中输入https://webvpn.cpu.edu.cn，打开统一身份认证界面。该系统第一次登录时建议使用chrome浏览器或其他浏览器的极速模式进行登录。

2.完成登录后自动打开学校信息门户界面，可通过信息门户中的相应链接访问相关校内信息系统。

3.如需下载图书馆电子资源，可点击信息门户“校内直通车”中的“图书馆”图标。

4.如需要访问的资源或系统未在信息门户中链接，可点击“校内直通车”中的“VPN”，打开VPN系统的功能界面。用户可根据所访问资源或应用的类型，选择不同的协议，输入目标域名或地址（如www.cnki.net）后点击“立即跳转”即可。

5.关于该vpn系统的使用，如有疑问请电话咨询图书与信息中心网络运营部（86185502）。
