# SSL VPN系统使用说明
来源：https://xxh.cpu.edu.cn/06/5b/c13645a198235/page.htm
日期：2023-07-25
部门：信息化建设管理处

1. 首次登陆时通过浏览器输入https://svpn.cpu.edu.cn，如果没有安装客户端EasyConnect，则在弹出的页面中选择操作系统对应的客户端进行下载安装。

电脑端客户端下载页面

手机端客户端下载页面

2. 安装完毕后，电脑桌面上或手机应用中会有快捷方式EasyConnect，进行登录。

3. 在服务器地址中输入https://svpn.cpu.edu.cn后点击连接，输入数字化校园账号和密码，进行登录（如非本人电脑请勿勾选记住密码和自动登录）。

4. 登录成功后

（1）电脑端：电脑桌面右下角会有客户端图标，双击可以显示资源列表。

（2）手机端：手机屏幕顶部状态栏会显示客户端图标和钥匙图标，打开EasyConnect应用，点击“资源列表”、“书签”，可显示常用校内资源。

5. 连上VPN后，默认校内资源和图书馆电子资源流量通过VPN访问，访问公网资源流量通过用户本地网络访问。

6. 如VPN已使用完毕，请右击电脑桌面右下角客户端图标进行注销，或通过手机APP进行注销。

提示：

1. VPN针对在校师生开放，每账号仅支持一个并发，请大家妥善保管账号密码，切勿外借，由于账号外借造成的损失或法律责任，由用户自行承担。

2. 由于部分手机浏览器采用云端加速等代理功能（如UC），造成部分仅限校内访问的应用在使用VPN时仍无法访问，此时关闭云端加速等代理功能即可。

3. 因VPN系统性能有限，请大家完成VPN使用需求后或暂不使用时主动注销系统，如果您登录系统后超过10分钟无页面活动，则账号会自动登出。

4. 关于VPN系统的使用，如有疑问请电话咨询图书与信息中心网络运营部（86185502）。
