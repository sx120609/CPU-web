# 宿舍网上网认证系统使用说明
来源：https://xxh.cpu.edu.cn/06/6c/c13651a198252/page.htm
日期：2023-10-13
部门：信息化建设管理处

我校宿舍网认证系统已与运营商完成对接，即用户将数字化校园统一身份认证账号和运营商宽带账号完成绑定后，在宿舍网认证系统输入统一身份认证账号和密码，选择已开通宽带服务的运营商后，就可以访问互联网。

1.宿舍网认证系统

用户终端以自动获取IP地址（DHCP）的方式连接至宿舍网后，可以在浏览器中输入：sushe.cpu.edu.cn，打开宿舍网认证系统界面。如下图：

2.绑定运营商宽带账号

用户可依据自身网络环境，选择（1）—（4）任意一种方式进行账号绑定。

（1）到运营商营业厅进行宽带账号绑定；

（2）在校园网外网环境下，通过VPN打开“宿舍网账号绑定平台”；

A.通过Webvpn登录账号绑定平台

B.通过客户端vpn登录账号绑定平台

（3）在校园内网（CPU）环境下，在浏览器中输入https://css.cpu.edu.cn/Self/login/?302=LI或扫描下方二维码打开用户自助服务系统。

（4）在新的宿舍网环境下，打开宿舍网认证系统后点击页面上的“运营商账号绑定”链接，打开用户自助服务系统。

（5）打开用户自助服务系统后，输入统一身份认证账号和密码（同校园网账号和密码）登录，如下图。

点击页面顶端的“服务”菜单，进入“绑定运营商账号”服务。


绑定成功后会有如下信息提示

3.登录宿舍网

登录宿舍网，只需在宿舍网认证系统页面输入统一身份认证账号和密码（同校园网账号和密码），并选择个人已开通宽带服务的运营商即可访问互联网。

登录宿舍网后，除可以访问互联网资源外，还可以直接访问校园网内网资源和图书馆电子文献资源。

4.忘记账号或密码

（1）如忘记统一身份认证账号（校园网账号），可访问此链接查询（[找回密码](https://id.cpu.edu.cn/grzx/findpassword)）。

如忘记统一身份认证密码（校园网密码，非运营商宽带密码），可于工作期间携证件（校园卡或学生证）到图书馆704室办理密码重置，联系电话86185448。


5.疑问或故障报修

关于宿舍网的使用，如有疑问或遇到故障，可通过企业微信报障平台（企业微信>工作台>网络报修）报障，也可向图书与信息中心运维部（图书馆708室）现场报障或电话报障（86185450）。

6.常见故障排除

（1）上网认证登录页面弹不出来

请检查路由器上网模式是否设置为“自动获取IP（DHCP）”；

请检查是否获取到正确的ip地址（10.12.*.*）；

在浏览器中手动输入sushe.cpu.edu.cn或1.1.1.1看能否弹出页面；

请检查网络线缆是否接好；

企业微信报障或拨打电话（86185450）报障。

（2）登录时提示“未绑定运营商账号，请正确绑定运营商账号再试”

没有完成统一身份认证账号与运营商账号绑定；

登录时选择的不是已绑定账号的运营商，如已经绑定了“中国移动”的账号，登录时选择的是“中国电信”或“中国联通”。

（3）账号绑定时提示“绑定失败，请核对运营商账号的密码是否正确，或联系运营商核对您的运营商密码”

绑定的运营商宽带账号或密码错误，请输入正确的运营商宽带账号和密码，如不清楚宽带账号或密码，可向运营商咨询。

（4）登录时提示“账号错误”或“密码错误”

输入的统一身份认证账号或密码（校园网账号或密码）错误，请输入正确的统一身份认证账号和密码。

（5） 登录时提示“绑定的运营商账号不正确”或“绑定运营商账号的宽带密码不正确”

绑定的运营商宽带账号及宽带密码不正确，请重新绑定运营商宽带账号。

（6） 登录时提示“运营商在线数超出限制，请联系运营商处理”

在线终端数量超出运营商限制。请登录“自助服务平台”在首页查看自己的在线终端数量，注销部分终端后再重新登录测试，如果还有问题请联系运营商，需要运营商后台清理在线终端。

（7）登录时提示 “运营商账号欠费或停机”

出现此报错的原因是运营商宽带账号欠费或停机。如出现如上报错，请联系运营商营业厅处理。

（8） 登录时提示“运营商账号组信息错误，请联系运营商处理”

出现此报错的原因是运营商账号属性绑定错误。有可能绑定的是账号属性是家庭宽带，不是校园宽带。如出现如上报错，请联系运营商营业厅处理。
