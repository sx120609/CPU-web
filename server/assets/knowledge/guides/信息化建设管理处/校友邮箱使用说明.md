# 关于校友邮箱使用说明
来源：https://xxh.cpu.edu.cn/2b/9c/c13644a207772/page.htm
日期：2024-06-14
部门：信息化建设管理处

1.学生毕业，学生邮箱会自动转为校友邮箱，暂停发信功能，但登录和收信功能正常。若恢复发信功能，校友可在微信中搜索“中国药大校友会”小程序，完善身份信息后，在“服务-电子邮箱”中自助恢复发信功能。

2.校友邮箱若忘记密码，可通过学生邮箱登录页面的“忘记密码”，通过预留手机号找回密码。

3.若校友没有绑定手机，或者已更换手机，可通过“中国药大校友会”小程序自助修改。

校友邮箱如遇问题，可电话联系：86185100
