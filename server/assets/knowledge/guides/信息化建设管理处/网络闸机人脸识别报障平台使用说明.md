# 关于药大校园网络、闸机、人脸识别相关系统报障平台使用说明
来源：https://xxh.cpu.edu.cn/08/08/c13678a198664/page.htm
日期：2024-03-08
部门：信息化建设管理处

各位老师、各位同学：

为了更好地服务于师生，现再次将药大校园网络、闸机、人脸识别相关系统的报障平台使用做个说明。

信息化建设管理处通过药大企业微信报障平台，实现全天候24小时接障。

一、适用系统：

1、校园内公共网络：药大江宁校区、玄武校区内校园内公共网络，含有线网络、无线网络、学生公寓内网络，其他各种专用网络归各建设单位自行保障。

2、闸机、人脸识别系统：两校区大门、江宁所有学生公寓、玄武所有学生公寓、江宁实验大楼一、二期各入口处的闸机、人脸识别等相关系统。

二、报障平台的使用说明：

1、打开药大企业微信，找到“工作台“”，点击“网络报修”模块。详见截图：

2、找到下方故障一栏，选择“故障申告”。详见截图：

3、填写相应信息，最后点击提交即可完成网络、门禁、人脸识别等相关报修。详见截图：

1、工作要求：当天接障、当天处理。

2、如果特殊情况不能当天解决，将及时反馈给相关师生，并确定完成期限。
