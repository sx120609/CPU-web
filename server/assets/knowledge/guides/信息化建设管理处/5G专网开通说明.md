# 5G专网业务开通操作说明
来源：https://xxh.cpu.edu.cn/4f/b4/c13645a217012/page.htm
日期：2025-01-13
部门：信息化建设管理处

我校在校师生开通5G专网后，可实现在全国范围内的5G信号下，不换卡、不换号、不用VPN，随时随地接入校园网，高速无感知访问图书馆、校内信息系统等校内资源以及互联网资源。(当前只支持南京移动手机号、南京联通手机号申请）

一、自助服务平台申请（校园内网访问）

1. 用户在校园内网或VPN环境下

方式一：登录信息门户https://i.cpu.edu.cn/，搜索 “5G专网申请”应用或在办事大厅中搜索“5G专网申请”。

方式二：访问 http://192.168.199.16:8080/Self/sso_login

2.点击“5G专网业务”>“业务申请”进入申请页面

3.确认用户信息，勾选相应条款，点击“提交”进行开通。

☆如果5G业务手机号栏为空或与当前使用手机号不符，请点击“[点击此处修改](https://id.cpu.edu.cn/grzx/home)”，进行修改。

☆携号转网用户请联系下方对应运营商进行登记，三个工作日后可重新申请。



二、运营商掌上营业厅开通

移动：自助服务平台提交申请成功后，点击页面中的链接（http://wap.js.10086.cn/F9)，登录移动掌上营业厅。

在如下图所示的页面中，学校栏选择“中国药科大学”，点击“立即办理”。

联通：自助服务平台提交申请成功后，无需二次申请，5个工作日内将由10010下发业务叠加签字链接，完成线上签字，即视为业务申请开通成功。

具体审核结果会通过企业微信消息中心进行推送，也可通过的“5G专网业务办理记录查询”中对开通结果进行查询。

三、注意事项

1. 5G专网业务仅对我校正式教职工和在校学生开放申请；

2. 目前5G专网业务暂时只支持南京移动和南京联通的手机号码申请；

3. 用户申请开通5G专网业务的手机须支持中国移动和中国联通5G网络，否则无法正常开通；

4. 开通后第一次通过5G流量访问校园网可能会出现数分钟的卡顿，属正常情况。待加载完成或刷新后，后续即可正常使用。
