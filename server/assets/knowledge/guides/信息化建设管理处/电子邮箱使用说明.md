# 中国药科大学电子邮箱使用说明

日期：2023-08-29
部门：信息化建设管理处

1.如何访问邮箱？

1.1webmail访问

用户可采用web方式，进行收发邮件。

教职工邮箱入口：https://mail.cpu.edu.cn/

学生邮箱入口：https://mail.stu.cpu.edu.cn/

1.2专用客户端（推荐）

用户可采用“网易邮箱大师”，进行收发邮件。

“网易邮箱大师”APP支持各类终端，安全好用，设置简单。

网易邮箱大师下载地址：https://dashi.163.com/

1.3第三方客户端

设置方式参考：https://qiye.163.com/help/l-11.html

授权码方式绑定校园邮箱：https://xxh.cpu.edu.cn/b4/33/c13644a242739/page.htm

2.如何开通邮箱？

2.1在校师生邮箱

在校师生，如需校园邮箱，可通过信息门户，自助激活后方可使用。

激活办法：

登录信息门户（http://i.cpu.edu.cn)，进入个人主页，在“数字提醒”—“邮件”—“请激活”位置，进行自助激活。（仅限校内激活）

如果已开通邮箱，点击“邮件（数字）”会直接跳转到邮箱。

2.2校友邮箱

学生邮箱不设期限，毕业后自动转为校友邮箱，继续使用。

没有校园邮箱的校友，可通过校友会小程序在线申请。

3.学生邮箱和教师邮箱有什么区别？

我校学生邮箱和教职工邮箱都是采用网易云邮箱产品，功能完全一样。为了区别身份，邮件系统现实行分域管理，教职工邮箱后缀为@cpu.edu.cn，学生和校友开通邮箱后缀为@stu.cpu.edu.cn。

4.忘记密码了怎么办？

4.1已绑定手机用户

如果用户已绑定手机，忘记密码可通过邮箱登录页面的“忘记密码”找回密码。

4.2未绑定手机用户

如果没有绑定手机，在校师生可以带有效证件来办公室修改；毕业校友可以通过校友会小程序绑定手机、修改密码。

5.邮箱如何绑定手机？

登录邮箱，在“应用中心”里的“密保平台”里设置或修改自己的手机号，如图所示。

6.绑定的手机号停用了，邮箱又无法登录，怎么修改？

在校师生可以带有效证件来办公室现场修改。

毕业校友可以通过校友会小程序绑定手机、修改密码。

7.如何添加英文别名？

登录邮箱，在“应用中心”里的“自定义别名”里设置自己的别名，如图所示。

注意：用户别名只允许设置一次，如果修改，可以带有效证件到办公室修改。

8.客户端授权密码设置

使用客户端添加账号，如果无法添加成功，请检查“客户端授权密码”是否开启。其查看方法如图所示。

若对邮箱安全要求高，可按说明开启“客户端授权密码”。

若使用某些非专业客户端，如：企业微信等，只能关闭“客户端授权密码”，方可添加成功。
