# 统一身份认证系统微信、ＱＱ扫码登录操作说明
来源：https://xxh.cpu.edu.cn/12/ef/c14179a201455/page.htm
日期：2024-05-08
部门：信息化建设管理处

我校统一身份认证系统支持微信、QQ、企业微信扫码登录。企业微信加入中国药科大学后即可直接扫码登录统一身份认证系统，微信、QQ需要先进行绑定。

一、绑定微信

在统一身份认证页面点击微信图标

使用微信扫码，并在手机上点击同意按钮

此时在电脑端统一身份认证绑定微信页面输入统一身份认证账号密码，点击绑定按钮即可完成绑定。

下次登录时，在登录页，点击微信图标，使用微信扫码即可直接进入系统。

二、绑定QQ

点击统一身份认证登陆页的ＱＱ图标

电脑上如果已经登录QQ，可在页面看到自己的QQ，点击即可；未登录QQ，请使用手机QQ扫码。

此时在电脑端统一身份认证绑定ＱＱ页面输入统一身份认证账号密码，点击绑定按钮即可完成绑定。

下次登录时，在登录页，点击ＱＱ图标，使用ＱＱ扫码即可直接进入系统。
