# 综合档案室简介
来源：http://xb.cpu.edu.cn/ab/53/c9098a109395/page.htm
日期：2023-10-12
部门：综合档案室

校长办公室综合档案室位于江宁校区图书馆附楼二楼，馆舍面积约500平方米。

我校1982年分别设立了文书档案室和科技档案室，科技档案室归校长办公室领导，文书档案室归党委办公室领导。1989年3月我校将文书档室和科技档案室合并，成立了综合档案室。综合档案为科级建制，现在编2人，隶属于校长办公室领导。内设综合业务室 、档案利用室、整理编目室、业务指导室。我校档案工作由校长分管，同时接受教育部、江苏省教育厅以及各级档案行政管理部门的指导、监督与检查。1997年1月，我校综合档案室被国家档案局评为“科技事业单位档案管理国家二级”单位。

综合档案室收藏档案起于1949年（1936年至1948年原国立药学专科学校的档案现收藏在第二历史档案馆），至2010年底共有档案 20762卷，其中永久、长期档案14856卷。一个全宗，分党群、行政、教学、科研、产品、基建、设备、出版、外事、财会10个门类。室存资料259册，录音、录像、影片档案1984盘，照片档案1919张以及人事处移交的死亡五年以上教职工的人事档案202卷。保存有校庆时各级领导的题词，校友赠品等实物。

综合档案室依简便实用原则编制了十多种检索工具，69册目录。

我校档案自1994年以后按《高等学校档案实体分类法》的要求，采用十大类分类方法进行统一分类、编号、排架，并按《档案库房管理制度》由综合档案室集中保管。我校档案实行部门立卷制度，综合档案室负责对全校档案工作进行监督、检查和指导，各部门配有兼职档案人员，形成了校长—校办主任—综合档案室—各部门分管领导—兼职档案人员的档案工作网络。
