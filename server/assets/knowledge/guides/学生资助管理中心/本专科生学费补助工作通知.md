# 关于2022-2023学年本专科生学费补助工作的通知
来源：http://xgc.cpu.edu.cn/a7/07/c8725a173831/page.htm
日期：2022-10-13
部门：学生资助管理中心

各学院：

根据《关于印发<中国药科大学学生学费补助实施细则>的通知》（药大学〔2019〕373号），现就2022-2023学年学费补助工作有关事项通知如下:

## 一、补助对象

全日制本专科在校学生中的孤儿或烈士子女，且在学年家庭经济困难学生认定范围之内。

## 二、补助标准

原则上不超过当年学费。

## 三、材料申报

（一）学生登录学工平台，打开“学费补助”应用，提交本专科学费补助申请及上传相关证明材料；经辅导员审核，学院资助管理员、学院书记审核后（10月19日前），报学校学生资助管理中心。到截止时间后，系统会自动关闭，请务必按时操作。

证明材料须能证明受补助学生为孤儿或烈士子女，例如：

1.由家庭所在地乡镇（街道）民政部门、村（居）委会任何一单位核实、盖章的相关文本材料。乡镇（街道）民政部门如无专用公章，可由政府代章。

2.孤儿证或儿童福利证，上传内容须包含证件名、学生姓名、公章；烈士证，上传内容须包含证件名、姓名、公章。

（二）学院审核通过后，获得本专科学费补助的学生导出《本专科学费补助申请表》word文档（1份），手写签名上交至辅导员，经学院盖章后于10月19日前上交至学生资助管理中心。

学生工作处

2022年10月12日
