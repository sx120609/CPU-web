# 关于做好2026年我校服兵役学生国家教育资助工作的通知
来源：http://xgc.cpu.edu.cn/b8/6e/c8725a243822/page.htm
日期：2026-09-10
部门：学生资助管理中心

各学院：

根据《财政部 教育部 人力资源社会保障部 退役军人部 中央军委国防动员部关于印发〈学生资助资金管理办法〉的通知》（财教〔2021〕310号）和《中国药科大学服兵役学生国家教育资助实施细则》的通知（药大学〔2026〕73号）要求，现就做好2026年服兵役国家教育资助工作通知如下：

## 一、有关说明

（一）自2024年秋季学期起（以入伍时间为准），学费补偿、国家助学贷款代偿以及学费减免的标准，本科生每生每年不超过20000元，研究生每生每年最高不超过25000元，超出标准部分不予补偿、代偿或减免。

（二）全日制在校退役士兵学生全部享受本科生国家助学金，资助标准为每生每年3700元，即每生每学期1850元。由学校资助中心直接发放，无需学生申请。

（三）对于退役后自主就业，通过全国统一高考考入高校且符合申请条件的本科学生，申请退役士兵学费资助前，请前往就近的县级及以上退役军人服务中心(站)“建档立卡”或补充更正个人信息，尽量缩短核验时间，确保在截止日期前完成系统审核工作。核验最终不通过(首次核验、二次核验、申诉均不通过)的学生，可认定为非自主就业退役士兵，不符合资助条件。学生对核验结果如有异议，可咨询相关退役军人事务部门。

## 二、报送材料

### （一）学费补偿或国家助学贷款代偿

1.《入伍通知书》复印件1份；

2.《应征入伍服兵役高等学校学生国家教育资助申请表Ⅰ》【1份，申请学生通过全国征兵网在线填写、打印本表（手填及复印无效）】；

特别说明：原则上《申请表Ⅰ》中学生开户银行账户信息需填写与学校绑定的银行卡账户信息；若毕业生注销与学校绑定的银行卡，则需填写本人任意一张银行卡信息，并自己查询此银行卡的联行号，用铅笔在《申请表Ⅰ》“学生银行账户信息”处备注。

3.在校期间获得国家助学贷款的学生，需同时提供《国家助学贷款借款合同》复印件。

### （二）学费减免

1.复学证明（或学籍异动表）复印件1份；

2.《应征入伍服兵役高等学校学生国家教育资助申请表Ⅱ》【1份，申请学生通过全国征兵网在线填写、打印本表（手填及复印无效）】；

3.《退役证书》复印件1份；

4.自主就业退役士兵身份证明原件1份。（自主就业，考入我校的入学新生需要提供）

备注：学费减免为一次性申请，学费分年补偿。除申请当年之外，其余学年均需提供在读证明（纸质版）。
