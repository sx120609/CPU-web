# 关于2025-2026学年本科生国家奖学金和国家励志奖学金评审工作的通知
来源：http://xgc.cpu.edu.cn/ba/4e/c8725a244302/page.htm
日期：2026-09-18
部门：学生资助管理中心

各学院：

为激励学生勤奋学习、努力进取，促进德、智、体、美、劳全面发展，中央政府出资设立了国家奖学金、国家励志奖学金。根据教育部及学校有关学生资助工作的文件精神，现就2025-2026学年本科生国家奖学金、国家励志奖学金评审工作的有关事项通知如下：

## 一、评审对象、条件、程序及奖励标准

2022级学生按照《关于印发<中国药科大学国家奖学金评选办法>的通知》（药大学〔2019〕372号）、《关于印发<中国药科大学国家励志奖学金评选办法>的通知》（药大学〔2019〕371号）文件执行。

2023级至2025级学生按照《关于印发<中国药科大学国家奖学金评选办法>的通知》（药大学〔2026〕77号）、《关于印发<中国药科大学国家励志奖学金评选办法>的通知》（药大学〔2026〕76号）文件执行。

补充说明：从2024年起，本科生国家奖学金奖励标准由每生每年8000元提高到10000元；本科生国家励志奖学金奖励标准由每生每年5000元提高到6000元。

## 三、材料申报

### （一）《国家奖学金申请审批表》系统填写要求：

1、因《国家奖学金申请审批表》需要提交教育部评审，请各位同学、老师务必认真对待，否则材料不合格将会被教育部取消国家奖学金名额。请同学务必认真阅读系统中《国家奖学金申请审批表填写说明》，并严格按照填写说明填写；请老师务必认真审核学生材料，并阅读填写提示，填写推荐理由或院系意见。

2、因往年国家奖学金申请审批表中的获奖信息填写错误过多，请学生认真对照获奖证书填写获奖信息，确保填写的获奖日期、获奖名称、颁奖单位与获奖证书完全一致；各学院须对照获奖证书核查学生填写的获奖信息。

（二）各学院须在10月12日前提交国家奖学金相关材料、须在10月19日前提交国家励志奖学金相关材料：

1、学生登录数智学工平台，打开“奖学金申请”模块，选择“2025-2026学年本科生国家奖学金”、“2025-2026学年本科生国家励志奖学金”，提交奖学金申请；经辅导员、学院资助管理员和学院书记审核后，报学校学生资助管理中心。到截止时间后，系统会自动关闭，请务必按时操作。

2、学院本学年评审细则如有变化调整的，请将纸质文本盖学院章后的扫描件（PDF）发送至邮箱427722017@qq.com。

（三）联系人：徐老师；联系电话：025-86185422。

## 四、注意事项

（一）2025-2026学年对应时间为2025年9月至2026年8月。

（二）根据全国学生资助管理中心要求，公示时间严格计算应以24小时为准，即开始公示当日当时至第二天当时为一天。如此，学院公示不少于3个工作日实际在具体日期上应超过3天。院（系）意见的落款时间应在公示结束后。

（三）国家奖学金和国家励志奖学金不能兼得。

（四）奖学金评定学年为2025-2026学年，故在2026年9月转专业学生、大类招生专业分流学生、拔尖创新班选拔学生、滚动分流学生、休学学生仍在原行政班级评定奖学金。

（五）2025年9月转专业学生、滚动分流学生，2025-2026学年必修课加权成绩只计算转入专业当学年教学计划安排的必修课程，补修及免修的必修课程均不纳入计算。

（六）高水平运动员必修课期末考试原始成绩须达到60分及以上，方可申请奖学金。在此基础上，按照《中国药科大学高水平运动员学籍管理暂行规定》（药大教〔2012〕97号）加上比赛奖励分及训练奖励分，以加分后的成绩来参评奖学金。

（七）享受少数民族录取照顾政策的新疆、西藏学生必修课期末考试原始成绩须达到60分及以上，方可申请奖学金，并且只能以原始成绩来参评奖学金。

（八）所有奖学金均由计财处直接划拨到获奖学生用于缴纳学费的银行卡中，请此卡遗失的同学到相关银行营业网点办理，并及时将卡号告知计财处（行政楼1楼）。
