# 关于开展2026年博士生优秀奖学金评审工作的通知
来源：http://xgc.cpu.edu.cn/c2/25/c8725a246309/page.htm
日期：2026-10-26
部门：学生资助管理中心

各学院：

根据《中国药科大学博士生优秀奖学金管理暂行办法》（药大学〔2015〕231号）等文件规定，现将2026年博士生优秀奖学金评审工作的相关事宜通知如下：

## 一、名额分配

| 学 院 | 博士生人数 | 名额（上限） |
| --- | --- | --- |
| 药学院 | 554 | 277 |
| 中药学院 | 253 | 127 |
| 生命科学与技术学院 | 155 | 78 |
| 国际医药商学院 | 81 | 41 |
| 工学院 | 111 | 56 |

| 多靶标天然药物全国重点实验室 | 224 | 112 |

| 生物医药卓越工程师学院 | 18 | 9 |
| 马克思主义学院 | 1 | 1 |

备注：

1.各学院博士研究生统计数为具有中华人民共和国国籍且纳入全国研究生招生计划的一、二、三、四年级全日制（全脱产学习）研究生；不含留学生、委培、延期毕业、休学、保留学籍、旁听课程、提前听课学生。

2.名额原则上按照四舍五入的方式取得。

3.因马克思主义学院博士研究生人数较少，故隔年分配1个名额。2025年未分配名额。

## 二、评审有关说明

（一）学生参评须导师知情并同意。

（二）2026年博士生优秀奖学金成果认定的时间由各学院评审委员会根据学院实际，集体讨论决定，并告知本学院所有研究生，本学年成果认定时间范围不可与上一学年重复（本次评选涉及到学年指的是2025-2026学年）。

## 三、材料申报

（一）学生登录数智学工平台，打开“奖学金申请”模块，选择“2026年博士生优秀奖学金”，提交奖学金申请，经学院资格确认后11月6日前提交。到截止时间后，系统会自动关闭，请务必按时操作。

（二）如果学院评审委员会成员或评审细则有变化（含新制定），请于10月30日前将盖章后的扫描件发送至邮箱lf987lf@126.com。

（三）校级审核及公示无异议后，请学院批量导出《博士生优秀奖学金申请审批表》（1份、正反面打印）并盖章，按照专业、学号排序，11月16日前报研究生工作部。经学校盖章后返还学院并记入学籍档案。
