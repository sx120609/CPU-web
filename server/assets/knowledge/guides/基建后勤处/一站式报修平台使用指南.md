# 关于中国药科大学一站式报修平台使用指南
来源：http://jjc.cpu.edu.cn/08/d1/c490a198865/page.htm
日期：2024-03-13
部门：基建后勤处

各位老师、各位同学：

为了更好地服务师生，现将中国药科大学一站式报修平台（当天接单、当天反馈）的使用方法说明如下：

一、一站式报修平台使用说明

1、进入一站式报修平台

方法一：打开中国药科大学企业微信，找到“工作台”，点击“一站报修”模块。详见截图：

方法二：搜索“中国药科大学基建后勤处”微信公众号，找到下方“暖心服务”一栏，选择“一站式服务”。详见截图：

方法三：微信小程序搜索“一站式报修”，选择“中国药科大学一站式报修”。详见截图：

方法四：校内每个宿舍、教室、办公室等全部房间将陆续张贴一站式报修小程序码，用微信扫码即可进入一站式报修平台。

2、进入一站式报修平台主页，点击“+”号。详见截图：

3、填写大致的问题描述，上传故障照片或故障视频，选择问题类型和所在位置，选择上门的日期和时间，最后点击提交即可完成报修。详见截图：

二、注意事项

1、维修人员在收到报修信息后，会尽快通过电话联系报修人，报修期间请保持手机电话的畅通通。

2、请正确选择维修类型，后台会根据维修类型将报修的信息分派到不同的维修人员。

三、运维工作要求及投诉电话

1、 工作要求：当天接单、当天处理。

2、 如果特殊情况不能当天解决，将及时反馈给相关师生，并确定完成期限。
