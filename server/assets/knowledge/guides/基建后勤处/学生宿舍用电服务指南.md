# 中国药科大学学生宿舍用电服务指南
来源：http://jjc.cpu.edu.cn/08/d3/c490a198867/page.htm
日期：2024-03-07
部门：基建后勤处

一、如何购电

1.线下方式：通过安装在食堂和自助服务厅的一卡通终端服务机，选择购电服务。

2.线上方式：校园网内，通过企业微信内的校园卡务应用的交电费，购买电量。

3.人工方式：工作时间在计财处柜台缴纳电费，凭单到江宁校区E组团学生服务大厅或玄武门校区科研大楼物业办公室人工充电。

★因校园一卡通系统23﹕30到第二天2﹕0盘点暂停服务，盘点期间不能购电。

二、查看剩余电量

1.线下方式：在宿舍楼的电表箱内，查看自己房间电表上显示的剩余电量。

2.线上方式：线上购电界面有剩余电量显示，另外校园网内登录企业微信 — 用电服务，显示登录学生宿舍的剩余电量和购买记录。

登录信息门户，在个人主页 － 宿舍用电查询，显示登录学生宿舍的剩余电量和购买记录。

3.人工方式：在江宁校区E组团学生服务大厅或玄武门校区科研大楼物业办公室请工作人员查询。

三、信息推送

相关信息由购电系统推送到学校企业微信发送，微信里需要关注中国药科大学企业微信并开启提示，推送条件和内容如下：

1.四人间学生宿舍剩余电量低于20度，十人间宿舍低于30度。推送信息给宿舍每个人，包括时间、房号、剩余电量。

2.购电成功，推送给购电学生，包括时间、房号、购电金额。

★夜间免打扰23﹕00到第二天7﹕00，不推送用电信息。晚间欠费不停电，次日八点停电并推送信息。

四、故障反馈

以上服务过程中有任何问题，可以到江宁校区E组团学生服务大厅（86185313）或玄武门校区科研大楼物业办公室（83271470）反馈，请工作人员协调解决。
