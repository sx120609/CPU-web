# 中心简介
来源：http://xinli.cpu.edu.cn/12/f9/c14181a201465/page.htm
日期：2024-05-08
部门：心理发展中心

心理发展中心隶属马克思主义学院，负责全校的心理健康教育工作。

中心根据大学生心理发展特点及社会发展的需要，深化心理健康教育工作的内涵，拓展心理健康教育工作的领域，明确了“起点介入、多层渗透、分段辅导、整体推进”十六字工作方针。目前中心工作已形成融心理咨询、普及教育、心理测评、课程建设等为一体的综合性心理健康教育工作，对于促进我校的人才培养产生了积极的影响。《中国教育报》、《高教领导参考》等媒体均对我校心理健康教育工作作了专题报道。

2009年11月，我校被授予“江苏省大学生心理健康教育与研究示范中心”荣誉称号。2013年3月，我校在“教育部2013年全国大学生心理健康教育工作会议”上作了“以读增知，以行促悟，打造特色心理健康教育工作模式”为题的经验介绍。2016年5月，我校获评“江宁大学城心理健康教育工作先进集体”。2020年江苏教育频道对我校心理健康教育工作做了《中国药科大学：健康心理是感触幸福的密码》的专题报道。2021年6月，在江苏省心理学会大学生心理专业委员会2021年会上，我校被评为“2019-2021年度大学生心理健康教育工作先进集体”。

心理发展中心目前拥有办公室、心理咨询室、心理治疗室、团体心理活动室、图书资料室、心协活动室等，总计400平方。先后购买了相关的软硬件，如团体沙盘、音乐放松舱、智能呐喊宣泄仪、智能宣泄仪等。
