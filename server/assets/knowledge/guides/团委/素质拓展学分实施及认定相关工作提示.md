# 素质拓展学分实施及认定相关工作提示
来源：https://tw.cpu.edu.cn/96/21/c19559a235041/page.htm
日期：2026-04-03
部门：团委

素质拓展学分实施及认定相关工作提示（根据《中国药科大学素质拓展学分实施及认定暂行办法》药大〔2017〕93号文件梳理）

1. “素质拓展”课程是本科生课程的重要组成部分，共1个必修学分，名为素质拓展学分，对应200个实践学时。

2. “素质拓展”成绩登记在第八学期成绩单，累计第一至第七学期获得的实践学时数a：
   - 200≤a＜240，成绩记为85分；
   - 240≤a＜280，成绩记为90分；
   - 280≤a＜320，成绩记为95分；
   - a≥320，成绩记为100分。

3. 在毕业学年的5月份未获得200个实践学时的，成绩单“素质拓展”课程记为59分，不能获得1个学分，按照学校相关规定，学生可根据“差多少补多少”的原则进行补修，在补足所差实践学时后“素质拓展”课程记为80分。

4. 日常项目开展、审核及相关组织工作由校“素质拓展学分”工作领导小组办公室（设在校团委）负责，各学院设立相应组织机构开展工作。

5. 本办法未涉及到的事项，将提交“素质拓展学分”工作领导小组讨论决定。对学分认定有异议者可向“素质拓展学分”工作领导小组反映。

6. 凡弄虚作假者，按照学校学生管理规予以处理。

7. 实践学时获取方式：通过“PU口袋校园”平台报名参加活动，并按活动要求、签到、签退即可得到相应活动实践学时，1PU对应1个实践学时。
