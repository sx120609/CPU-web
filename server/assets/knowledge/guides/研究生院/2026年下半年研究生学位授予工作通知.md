# 关于做好2026年下半年研究生学位授予工作的通知
来源：http://yjsy.cpu.edu.cn/b0/86/c6314a241798/page.htm
日期：2026-06-24
部门：研究生院

各相关学院、研究生导师及研究生：

为做好我校2026年下半年研究生学位申请与授予工作，现就有关事宜通知如下：

一、总体要求

2026年下半年研究生申请学位的流程、环节，严格按照《关于做好2026届毕业研究生学位论文答辩工作的通知》的相关要求执行。参见链接：http://yjsy.cpu.edu.cn/94/0e/c6335a234510/page.htm。

二、学位论文盲审

研究生在申请答辩前须通过校级论文盲审，上半年通过盲审的研究生不需要重新送审。校级盲审参照《关于做好2026届毕业研究生学位论文盲审工作的通知》要求执行。参见链接：http://yjsy.cpu.edu.cn/8f/86/c6335a233350/page.htm。

拟9月份和12月份申请学位的研究生，均以学院为单位提交盲审论文电子版(PDF格式）、摘要（TXT格式）、导师送审同意书（导师签字、学院盖章，扫描版）及汇总表。上述材料请提交至研究生院学位办姚老师，邮箱：1780824809@qq.com。9月份批次提交论文的截止时间为7月8日下午3点，12月份批次提交论文的截止时间为10月8日下午3点。

下半年硕士学位论文平台盲审结果为不合格的，可提出申诉。申诉后，平台增送2份盲审：若2份评审结果均为通过，则盲审最终结果视为通过；若其中有1份不通过，则最终盲审结果为不通过。申诉所产生的增送盲审费用由导师承担。选择不申诉的可在3个月后重新送审，所需费用由导师承担。博士学位论文平台盲审不合格者，按照《关于做好2026届毕业研究生学位论文盲审工作的通知》相关要求处理。

三、学位材料提交

拟9月份和12月份申请学位的研究生，请分别于9月14日前、11月23日前在系统中提交答辩申请；答辩通过后在系统中完成答辩结果录入，并分别于9月16日、11月25日将纸质学位申请材料提交至所属学院。学院将分别于9月17日、11月26日与研究生院学位办（行政楼717）进行拟毕业研究生学位申请材料的交接，两次交接的截止时间均为当日下午4点。

四、学位审定及证书发放

学校将在9月和12月分别召开校学位评定委员会会议，讨论毕业及学位事宜，并在会后发放毕业和学位证书。
