# 关于2026-2027学年第一学期学生注册工作的通知
来源：http://yjsy.cpu.edu.cn/b6/30/c6306a243248/page.htm
日期：2026-08-28
部门：研究生院

2026-2027学年第一学期注册工作已经开始，具体安排如下：

一、网上学期注册

网上学期注册请前往研究生信息管理系统学生端，“个人管理—学期报到注册”环节完成注册。

二、个人信息完善

个人信息完善请前往研究生信息管理系统学生端，“个人管理—个人信息维护”进行检查与填写。个人信息涉及学籍登记表信息采集，毕业时将予以存档，请务必认真检查，如实填写。

三、学生证注册

1、注册时间：注册工作须在2026年9月30日前完成，具体时间由学院自行安排。

2、根据教育部、国铁集团最新规定，自2025年起，学生火车票优惠资质全面实行线上核验，不再通过“学生证贴优惠卡”方式办理。有需要的同学可通过“铁路12306”APP线上办理，无需线下盖章或提交纸质材料，建议在每学年首次购票前完成线上核验。

3、注册办法：注册章由学院统一管理，学生以班级为单位凭学费收据或助学贷款证明到辅导员办公室进行集体注册。

4、注册要求：

1)本次仅为2026-2027学年第一学期注册，注册时间统一写2026年9月。

2)根据《中国药科大学研究生学籍管理规定》，未缴纳学费的学生不予注册；本学年已申请助学贷款的研究生正常注册，凭学费收据或助学贷款证明到辅导员处注册。

3)请各学院严格把关，注册章由学院统一管理，不得单独交与学生或由学生自行保管。
