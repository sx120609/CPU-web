# 关于研究生导师开展2026届毕业研究生离校审批工作的通知
来源：http://yjsy.cpu.edu.cn/ae/5d/c6306a241245/page.htm
日期：2026-06-11
部门：研究生院

各研究生培养单位及各位研究生导师：

按照学校2026年毕业季总体工作安排，学校已于6月10日面向符合条件的毕业统一启动毕业离校系统，全校2026届毕业生在6月18日完成离校工作。

为确保毕业研究生在离校前与课题组（实验室）做好工作资料和物品交接，毕业离校系统特设置导师审批必办环节。经导师审核完成后，研究生毕业生离校系统界面生成电子离校单（状态为毕业证书可发放），由辅导员审核后发放毕业证书。

现将研究生导师线上审核研究生离校流程发布，请各位导师及时开展研究生离校审批工作。

一、手机端

在【企业微信】---【工作台】---【数智学工】-【毕业生离校】板块，点击【离校审核列表】，进入后在页面切换到导师角色，在办理状态中选择未办理查看待审核学生，可按照如下流程图示单个或批量审核研究生离校信息。

二、电脑端

打开网页[https://ydxg.cpu.edu.cn/sfrz/login295106，](https://ydxg.cpu.edu.cn/sfrz/login295106%EF%BC%8C)用学校统一身份认证方式登录进入【数智学工】，右上角切换至导师角色后，在顶部菜单点击【学工管理】，在弹出的【离校管理】中进入【环节办理】，在办理情况中筛选未办理，可对列表学生名单进行单个或批量审核。
