# 关于保卫部（处）、人民武装部江宁校区办公地点调整的通知

全体师生员工：

| 消防科 | 保卫部（处）办公室104 | 025-86185119 |

人民武装部办公地点同步调整，与保卫部（处）合署办公，地点同上。原办公、值班电话保持不变。
