# 关于江宁校区警务室身份证业务恢复办理的通知
来源：http://bwc.cpu.edu.cn/b6/0b/c8022a243211/page.htm
日期：2026-08-27
部门：保卫处

各位师生：

江宁校区警务室身份证业务自9月2日起恢复办理，办理时间为每周三上午9:30-11:30；办理地点：中国药科大学警务室；咨询电话：025-86185115。

注意事项如下：

## 一、江苏省内户籍

公安机关签发的有效证件原件（户口本、驾照、身份证、护照等）

［注：若无，可提供苏政通APP或交管12123电子证件尝试受理］

## 二、江苏省外户籍

1、公安机关签发的有效证件原件（户口本、驾照、身份证、护照等）

2、在宁居住、就业、就学证明（学生证、居住证、在校证明、工作证等）

［注：若无，可提供户籍省份省级政务服务平台电子证件或交管12123电子证件尝试受理」

## 三、拍照要求

1、不可佩戴美瞳、饰品

2、不可化浓妆、不可较浅色头发、长发需扎马尾
