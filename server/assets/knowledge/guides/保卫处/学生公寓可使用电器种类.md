# 关于公布学生公寓可使用电器种类的通知
来源：http://bwc.cpu.edu.cn/58/39/c8024a88121/page.htm
日期：2013-12-03
部门：保卫处

校保〔2013〕2号

各部门、单位：

为规范学生公寓用电，进一步加强违章电器管理，杜绝火灾安全隐患，维护学生公寓良好的学习和生活环境，确保学生生命财产安全。经研究决定，对学生公寓除学校己配置电器外，可使用电器种类如下：

（1）台灯（建议使用冷光源，若使用白炽灯，功率不得超过25W）

（2）充电器（输出电压在12V以下，不许放在床铺上使用）

（3）微风（吊）扇（功率15W以下）

（4）小功率电吹风

（5）电脑

（6）洗衣机

（7）空调（按规定申请）

上述电器必须到正规电器市场购置，禁止使用“三无”（无中文标识、无厂名、无厂址）产品、劣质产品和自制的用电设备。除学校己配置电器和本通知规定的电器种类外，学生公寓使用其它电器均视为违章电器，一律禁止使用。若发现则由各物业管理单位统一代保管至毕业。

特此通知，请遵照执行。

中国药科大学保卫处

2013年12月3日
