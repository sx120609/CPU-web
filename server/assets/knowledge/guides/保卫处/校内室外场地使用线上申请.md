# 关于统一线上审批校内室外场地使用申请的通知
来源：http://bwc.cpu.edu.cn/83/b6/c8020a230326/page.htm
日期：2025-12-02
部门：保卫处

关于统一线上审批校内室外场地

使用申请的通知

全体师生：

为进一步优化服务流程，提高相关场地审批效率，落实“数据多跑路，师生少跑腿”的服务目标，自即日起，保卫处对本部门负责的“二食堂东侧场地”的使用申请流程进行优化升级。现将相关事宜通知如下：

## 一、申请方式变更

原线下纸质申请表递交与盖章审批流程即日起全面取消。所有“二食堂东侧场地”的使用申请，统一通过线上渠道进行。请申请人通过企业微信工作台提交申请。

## 二、线上操作指南

手机企业微信操作：第一步，打开工作台，选择“我的门户”；第二步，在“我的应用”中选择“更多”，找到“公共服务”；第三步，选择“公共服务”下的“校内室外场地使用申请表”，点击“我要办理”。

## 三、场地使用申请须知

1.保卫处审批室外场地，专指江宁校区第二食堂东侧广场摆台场地（申请时，请勿勾选“体育馆和体育场”选项）。校内其他室外区域原则上不允许设置摆台活动，如确有摆台活动需要，请相关活动的校内主管部门联系保卫处单独进行备案。

2.此申请仅限学校部门、单位，正式注册的学生社团或学生组织所进行的各类非营利性公益活动，不接受个人申请，不接受校外单位申请，不接受商业性、营利性活动申请。

3.使用场地时请服从现场管理，落实相应安全措施，注意安全，场地使用完毕，保持现场整洁，清除装饰物和垃圾。

4.活动中严禁发放、张贴违规宣传品，指导老师或活动主管部门需审核相关宣传用品。

5.严格按申报获批内容、时间和地点进行，不得擅自更换或扩大活动场所、变更活动时间和活动内容。

6.场地使用期间，遵守校内安全管理制度，不得违规接电、使用扩音设备，现场设置需合理规范，避免造成交通堵塞。

7.指导老师务必到场指导。

8.如需申请“体育馆和体育场”场地，请咨询体育部。

感谢各位师生的理解与配合！
