# 关于开通线上办理户口借用申请说明
来源：http://bwc.cpu.edu.cn/6a/af/c8020a92847/page.htm
部门：保卫处

为规范学生集体户口管理，方便户口借用，目前已开通线上办理户口借用申请，请需要借用使用户口的同学注意以下操作方法与注意事项：

## 一、操作方法：

手机企业微信操作：第一步打开工作台，选择“我的门户”；第二步在“我的应用”中选择“更多”，找到“公共服务”；第三步选择“公共服务”下的“常住人口登记表借出申请”，点击“我要办理”。

## 二、注意事项：

1.借用原件的请携带学生证：如办理婚姻登记、购房、公证等事项，户口原件借出期限为15天，需将学生证暂放在户籍室保存，还表后归还学生证。

2.借用复印件的无需携带学生证：如办理签证、报考驾校等其他事项，借用复印件，复印件不押学生证，无需归还。

3.借用户口常表原件需妥善保管，及时归还，避免个人户口信息泄露。

4.学生集体户口因各校区落户地址的差异和就读校区不同实行分校区管理。

5.对于毕业生，学校提供户口常表保存一年服务；毕业后学生户口常表只迁不借。

6.办理身份证、护照等证件，无需借用《常表》，直接去江宁市民中心三楼办理（地址：江宁区杨家圩路2号）。详情请参考身份证办理指南。
