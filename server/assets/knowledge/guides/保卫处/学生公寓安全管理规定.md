# 学生公寓安全管理规定
来源：http://bwc.cpu.edu.cn/58/36/c8024a88118/page.htm
日期：2016-10-13
部门：保卫处

为了加强学生住宿管理，规范学生行为，营造良好的寝室文化与环境，维护学生正常的学习、生活、安全秩序。根据教育部《普通高等学校学生管理规定》结合我校实际，特制定本规定：

1、在校居住的学生应按学校分配的房间、床位居住，不准擅自调换寝室、转让他人；房间钥匙不准交他人使用;不许留宿他人。

2、公寓内应严格执行安全用电制度，严禁违章使用电器（按<《关于公布学生公寓可使用电器种类的通知》校保〔2013〕2号>执行），一经发现立即查处，对违章电器予以没收；严禁私自拉乱接电线。

3、在校学生严禁在公寓内饲养宠物，一经发现立即通报本人所在院、部、系进行处理。

4、在校居住学生应自觉遵守作息制度、按时归宿，严禁在校外租房居住；迟归者必须出示有关证件并登记、说明情况，如不服从管理，交本人所在院、部、系处理。

5、公寓内所有学生都应遵守《中国药科大学消防安全管理规定》，保持楼道畅通，不准随意堆放物品，不得作娱乐场所之用；楼内消防器材等安全设施，非紧急情况下，不得随便移位、挪动、玩弄和损坏。

6、各类票证、银行卡、重要资料等贵重物品要妥善保管，切勿乱放、乱丢；室内无人或就寝前应及时熄灯、锁门、关窗；对上门推销物品的应坚决抵制，并及时通知物业管理员和保卫处；不在公寓内发生推销及买卖行为。

7、公寓内严禁存放易燃、易爆、有毒及管制类器具等危险物品；公寓内严禁打麻将、酗酒、赌博、举办舞会、打架斗殴、聚众闹事、举行宗教活动，不得大声喧哗，高声放音乐；配合并支持物业管理员的工作，不得刁难哄闹。

8、切实遵守各项防火规定，严禁在公寓内焚烧废纸等杂物，严禁使用明火照明（蜡烛、酒精灯、煤油灯等），严禁在床铺上点蚊香、吸烟，不得乱丢烟头。

9、公寓内应保证干净整洁，严禁向窗外倒水，乱丢物品。

10、发现形迹可疑者要及时通知物业管理员和保卫处。发生案件或事故，要保护现场并及时向保卫处报告，要积极配合学校有关部门或公安机关调查处理。

11、本规定解释权归中国药科大学保卫处、基建后勤处、学生工作处所有；若其他学生公寓相关管理规定与本规定冲突的，以本规定为准。

12、本规定自公布之日起生效.

2016年10月13日
