# 学生户口迁出办理须知
来源：http://bwc.cpu.edu.cn/0a/56/c8020a199254/page.htm
部门：保卫处

## 一、 毕业生户口集体迁移

毕业生离校前，户籍室依照毕业生本人在《毕业生户口迁出办理登记表》（见毕业前具体通知）填写的户口迁移地址为依据，集中办理户口迁出手续。

## 二、 零散迁移

学生携带相关材料到户籍室领取《常住人口登记表》，到江宁市民中心三楼自行办理。

所需材料如下：

（一）毕业生在毕业集体迁移时未能及时办理户口迁出的：

迁往原籍/工作地：①本人身份证、②毕业证原件。

升学：①本人身份证、②录取通知书原件。

### （二）在校期间户口迁出：

①准迁证（如迁到省外需开具准迁证，江苏省内不需要）、②本人身份证、③学生证、④手写申请书（写明“保证不再迁入学校”、辅导员签字）、⑤同意迁出证明（户籍室开具）。

（三）退学学生户口迁出：①本人身份证、②退学文件。

（四）结业学生户口迁出：①本人身份证、②结业文件。

（五）如需他人代办户口迁出手续，代办人需持①学生本人身份证复印件、②学生本人手写委托书（见下模板）及③毕业证原件/退学文件/结业文件/录取通知书原件等相应材料办理。
