# 机动车准入申请办理指南
来源：http://bwc.cpu.edu.cn/f1/4d/c8020a127309/page.htm
部门：保卫处

为更好服务教职工及临时工作人员机动车准入申请办理，减少线下业务办理流程，现已开通机动车准入申请线上办理服务。有关业务办理详情如下：

## 一、 操作方式

1. PC端操作

（1）进入办事大厅

（2）在所属部门一栏选择保卫处（部）、人民武装部，随后选择机动车准入申请。

（3）点击“立即办理”，进入后填写相关信息即可。

2.手机企业微信操作

（1）打开企业微信，选择“工作台”的“我的门户”

（2）选择“机动车准入申请”

（3）点击“我要办理”，进入后填写相关信息即可。

## 二、 特别提示

1.常规申请：无特殊情况直接线上办理即可；如有特殊情况可纸质申请，详情查看附件《中国药科大学车辆准入申请表》。

2.审批处理：申请提交经部门领导审批后，管理员将在5个工作日内处理。

3.申请主体限制：教职工可直接申请机动车准入；临时工作人员申请时需先填写校内联系人信息。

4.申请车辆要求：每位教职工仅可申请1个车牌，限本人或配偶名下车辆；如有特殊情况需在备注中说明；若申请车牌超出限制数量，默认替换原登记车牌。

5.使用及安全责任：办理准入后，须遵守学校交通相关规定，服从管理，严禁超速、逆行、乱鸣笛及在禁停区域停靠；车辆及所载物品的安全责任由申请人自行承担。
