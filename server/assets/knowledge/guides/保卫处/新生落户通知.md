# 关于2026级新生落户的通知
来源：http://bwc.cpu.edu.cn/b7/1a/c8022a243482/page.htm
日期：2026-09-05
部门：保卫处

为做好我校2026级新生落户工作，现将新生落户相关事项通知如下：

## 一、材料准备

1、录取通知书复印件。

2、身份证正反面复印件。

3、手写《学生委托书》（见模板）。

4、《新生信息采集表（个人）》（见模板）。

5、户口迁移证原件。内容要求：

（1）迁往地址：南京市江宁区龙眠大道639号；

（2）出生地、籍贯：写明**省**县/市；

（3）迁移证右上角迁移证号第一位不能为“0”；

（4）迁移原因：招生。

## 二、材料递交

请各学院于2026年9月16日17:00前，以学院汇总的形式：

将①纸质版新生落户统计表（电子版拷贝至户籍室）、②学生户口迁移证+录取通知书复印件+身份证复印件+手写《学生委托书》+《新生信息采集表（个人）》（按照统计表填写顺序排列），交至学校行政楼413。
