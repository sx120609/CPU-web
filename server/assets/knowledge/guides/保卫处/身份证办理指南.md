# 身份证办理指南
来源：http://bwc.cpu.edu.cn/6a/b7/c8020a92855/page.htm
部门：保卫处

## 一、办理地址与时间

### （一）校内办理

- 地点：学校警务室（E组团门口）

- 办理时间：每周三上午，9:30-11:30

- 咨询电话：025-86185115

### （二）校外办理

- 地点：江宁市民中心三楼（江宁区杨家圩路2号）

- 时间：周一至周六，8:00-18:00

- 咨询电话：025-69977080

## 二、需携带材料

### （一）江苏省内户籍

携带公安机关签发有效证件（户口本、驾照、原身份证、护照等），如无可提供苏证通APP或交管12123电子证件尝试受理。

### （二）江苏省外户籍

携带公安机关签发有效证件原件（户口本、驾照、身份证、护照等），以及在宁居住、就业、就学证明（学生证、居住证、在读证明等）。

## 三、注意事项

拍照要求：不可佩戴美瞳、饰品，不可化浓妆，不可较浅发色，长发需扎马尾，不可穿浅色或大衣领衣物。
