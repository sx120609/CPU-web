# 关于开通线上办理监控调阅申请的通知
来源：http://bwc.cpu.edu.cn/39/57/c8020a145751/page.htm
日期：2021-03-31
部门：保卫处

即日起开通线上监控调阅申请业务，不再受理纸质申请。

## 一、操作方法

1、电脑操作

第一步，进入一站式服务大厅；第二步，在所属部门一栏选择保卫处（部）、人民武装部；第三步，选择监控调阅申请。

2、手机企业微信操作

第一步，打开企业微信，选择工作台的办事大厅；第二步，选择监控调阅申请；第三步，依据表格内容如实填写申请。

## 二、特别提示

填写申请时必须点击“我承诺”，承诺内容如下：本人自愿申请调阅监控，申请事由全部属实，用于维护自身权益，自觉遵守学校规定，服从学校管理，做到不拍摄、不传播！

注意事项如下：1、本申请仅可用于自身事务，他人事务请当事人另行申请。2、当事人调阅监控时请勿拍照摄像，更不可发布到互联网上。3、当事人所调阅监控的内容若涉及他人隐私，禁止宣扬。4、有关外卖丢失事项请自行联系商家处理，不受理审批外卖相关调阅监控申请。5、本申请仅供本校师生使用，校外人员遇到特殊情况需要调阅监控的，请联系对口管理部门或自行报警处理。
