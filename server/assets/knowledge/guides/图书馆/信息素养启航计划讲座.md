# 信息素养启航计划
来源：https://lib.cpu.edu.cn/
部门：图书馆

信息素养启航计划

文献检索从入门到专业系列讲座

写论文、做课题、查文献，信息素养是每个学生的必修课。图书馆特别推出8场“信息素养启航计划”系列讲座，从图书馆资源入门到专业数据库实战，从中文文献到外文医学文献，从专利基础到药物研发情报，覆盖不同文献类型和不同年级需求。不论你是刚接触检索的新手，还是高年级同学和研究生，都能找到适合自己的讲座。快来看看哪一场最适合你！

第一场：信息检索第一课——图书馆资源与检索基础

零基础也能听懂的检索入门课，带你认识图书馆纸电资源、免费学术资源，并理解布尔逻辑、字段检索等基本理论。

适合：大一、大二及未系统学过文献检索的同学。

第二场：中文文献检索实战入门——以CNKI为例

以CNKI为例，手把手教你拆检索词、调检索字段、用布尔逻辑，把中文文献检索策略真正用起来。

适合：大一、大二、大三及未系统学过检索课的同学，建议先听第一场。

第三场：PubMed外文药学文献检索基础

聚焦PubMed，讲清MeSH主题词检索的价值和用法，并覆盖基本检索、高级检索、字段限定、文献类型筛选等外文药学文献检索基本功。

适合：大三、大四、研一及需要外文药学文献检索的同学，建议先听第一、二场中文文献检索基础。

第四场：SciFinder基础科研场景应用——物质、反应与文献检索

围绕SciFinder，介绍物质、反应与文献三者的检索以及结构式、CAS号检索，并聚焦药物化学、材料、合成等科研场景。

适合：化学、药学方向，有科研需求的高年级和研一。

第五场：药智数据检索与利用——注册、市场与政策信息

面向药品注册、市场与政策信息，讲解药智数据的检索、筛选、导出和利用，服务药品研发与市场分析。

适合：药学、中药、药事管理、市场注册方向，有具体数据需求的高年级和研究生。

第六场：专利基础——科研创新中的助力与守护

从专利信息、专利申请到专利保护，零基础读懂专利文献，掌握常用专利检索方法，让专利成为科研创新的助力与守护。

适合：对专利、科研创新有兴趣的同学，零基础也无妨。

第七场：AI赋能PQDT Global——全球博硕论文数据库的高效利用

以AI赋能PQDT Global，带你获取全球博硕论文资源，用AI辅助选题、学术检索、内容解读与信息管理，助力开题与毕业论文。

适合：大四、研一、准备开题或写毕业论文者。

第八场：CDDI/CCI检索应用——药物研发情报、专利家族与竞争分析

聚焦CDDI/CCI，介绍药物研发情报、专利家族与竞争分析，帮助从情报数据中提炼研发决策参考。

适合：有明确课题、研发方向或竞争情报需求的老师、研究生及高年级学生。
