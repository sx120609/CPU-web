# 情报咨询服务
来源：https://lib.cpu.edu.cn/
部门：图书馆

依托图书馆丰富的馆藏资源以及良好的馆际协作网络，运用信息分析方法与手段，组织开展基于事实数据、科技信息、文献资料等的学科分析与评估等各类情报咨询服务，为学校职能部门、院系的科研管理决策、学科建设、人才培养与引进、科学研究、国际交流合作等提供精准的数据支持与科学的决策参考。

主要服务内容：

（1）ESI学科动态分析

Essential Science Indicators（简称ESI）是基于Web of Science核心合集数据库的深度分析型研究工具，能够为科技政策制定者、科研管理人员、信息分析专家和研究人员提供多角度的学术成果分析。ESI以10-11年为一个周期对对全球高校及科研机构的论文数据进行统计和比较，对论文总被引次数排列在前1%的学科进行排序，每两个月公布一次进入全球前1%的大学及科研机构的排序。图书馆基于ESI数据库，定期更新中国药科大学ESI学科动态，针对学校ESI相关学科、高水平论文进行跟踪监测与分析。

（2）学科态势与竞争力分析

面向学校“双一流”建设，以情报理论为基础，依托图书馆丰富的馆藏资源，为学校职能部门、院系、科研人员提供学科分析服务，亦可根据用户需求定制化学科分析服务，包括学术成果产出、学科发展态势、学术影响力、高水平论文、重点研究方向、期刊发文分析、合作趋势、学院与学者贡献度、对标机构的学科竞争力分析等。

（3）人才挖掘与评价

基于论文、专利、项目等多源数据，结合学校、学院需求，探索建立人才评价指标，对科研人员的学术成果、学术影响力等进行全景分析，助力挖掘高水平人才，为管理决策提供情报参考。
