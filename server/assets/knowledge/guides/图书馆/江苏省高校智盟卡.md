# 江苏省高校智盟卡
来源：https://lib.cpu.edu.cn/
部门：图书馆

智盟卡（全称“江苏省高校智盟卡”）由江苏省高校数字图书馆联盟JALIS推出，旨在加强江苏高校联盟成员馆之间的资源与服务协同，为全省师生提供更加便捷、高效的文献获取与信息服务。

我校统招本科生、硕士生、博士生、教职工均可自主申请开通江苏省高校智盟卡，凭此卡即可前往联盟高校图书馆借阅对外开放的图书。

智盟卡目前提供的服务主要包括：

进校入馆：允许用户凭智盟卡进入联盟内高校图书馆，使用馆藏资源。

馆藏查询：提供便捷的联盟馆藏查询服务，方便用户快速定位所需资源。

文献服务：提供纸质图书借阅，满足用户文献需求。目前，每位用户最多可同时借阅5本图书，借期为1个月，不可续借。对于图书借阅超期等违章行为，将依据各高校图书馆的现有规则进行处理。

注册认证

1、关注“江苏省高校数字图书馆JALIS”微信公众号；点击公众号菜单栏“智盟卡”-“首次绑定认证”。

2. 联盟统一身份认证

（1） 机构选择“中国药科大学”，查看认证说明，若符合认证条件，点击“前往认证”，授权获取用户昵称和头像。

（2）点击“前往认证”，将跳转至中国药科大学统一身份认证，用户输入有效账号和密码，身份认证成功且在中国药科大学图书馆持有有效账号，即可开通高校智盟卡。若开通失败，可致电咨询025-86185502。具体流程见图书馆公众号推文
