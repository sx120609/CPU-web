# 微型图书馆借还柜使用说明
来源：https://lib.cpu.edu.cn/
部门：图书馆

一、设置地点

江宁校区教学楼D楼、学生宿舍G组团、H组团、C组团及经管文楼一楼“1983活动室”

二、借、还图书操作流程

1、在界面处点“借书”/“还书”；

2、使用校园卡进行登录；

3、选择柜门，点击需要打开的柜门，点击完成，听到响声后请手动打开柜门，取出、归还图书，关上柜门即可代表借/还成功；

4、还书时可以放置图书于任意柜门内；

5、确认操作完成后，点击返回首页；

6、“借书”/“还书”成功。

三、查询续借图书操作流程

1、点击“查询续借”；

2、使用校园卡进行登录；

3、勾选（空白框）所要续借的图书

4、确认图书信息无误后，点击“续借”

5、续借成功。

四、其他

本微型图书馆借还柜借出的图书，须在本图书柜归还，非本图书柜借出的图书禁止在此归还。
