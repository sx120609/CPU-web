# 图书馆概况
来源：https://lib.cpu.edu.cn/
部门：图书馆

中国药科大学图书馆馆藏特色鲜明、资源底蕴深厚。图书馆总建筑面积2.89万平方米，其中江宁校区图书馆面积2.3万平方米，玄武门校区图书馆面积0.59万平方米，软硬件设施完备，为师生提供优质的文献服务环境。

本馆文献资源储量丰富、学科体系完善，已形成了以药学为特色，生物医药相关学科文献协调发展的多学科藏书体系。目前，图书馆拥有印刷型馆藏文献122万余册，可利用电子资源近500万种，全方位覆盖学校教学、科研与学科建设需求。

电子文献类型齐全，重点突出。馆内可提供中文电子期刊2万余种、外文电子期刊近2万种，收录中外文网络数据库及特色数据库近200个，学科覆盖面广、专业针对性强。所有电子文献与数据库资源依托校园网，实现24小时全天候开放，保障师生随时便捷调取学术资源。

围绕师生学习科研与成长发展需求，图书馆搭建了全方位、多层次的文献信息服务体系。常规提供资源检索、馆藏查询、图书借阅、图书荐购、新书通报、图书展览、文献传递、信息素养教育等基础服务，同时深耕学术科研领域，开展科技查新、学科精准服务、科研情报分析、专利信息分析等深度知识服务，助力师生科研创新与学术提升。

秉持学校“精业济群”的校训，中国药科大学图书馆将持续深耕专业化、数智化、特色化建设，为学校药学人才培养与科研创新赋能增效。
