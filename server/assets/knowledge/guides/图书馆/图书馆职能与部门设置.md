# 图书馆职能与部门设置
来源：https://lib.cpu.edu.cn/
部门：图书馆

图书馆是学校的文献信息中心，为学校教学和科学研究提供文献信息服务。主要承担以下职能：

一、负责全校文献资源建设、发展规划和绩效评价。以学科特色为导向采购纸质、电子资源，注重资源质量评估与管理，利用数据分析优化采购决策，形成动态更新的馆藏体系；

二、负责中外文图书、期刊的保管及借阅服务，确保知识获取便捷；

三、负责情报检索服务，知识产权信息服务。对接院部需求，提供嵌入式科研支持与信息素养培训，助力教学科研精准化；

四、开展阅读推广，改造空间功能，联动“三全育人”机制，将文化浸润融入学生教育，打造集学习、展览、休闲于一体的校园文化中枢；
