# 图书捐赠
来源：https://lib.cpu.edu.cn/
部门：图书馆

我校图书馆长期接受社会各界人士及本校师生、校友捐赠的图书。各类捐赠图书已成为我馆藏书的宝贵来源，在知识的传承和交流方面发挥着重要作用，在不断丰富馆藏的同时，支持我校图书馆的建设和发展。
