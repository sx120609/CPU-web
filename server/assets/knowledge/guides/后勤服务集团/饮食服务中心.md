# 饮食服务中心
来源：http://hqjt.cpu.edu.cn/14571/list.htm
部门：后勤服务集团

饮食服务中心下设江宁校区一食堂与玄武门校区食堂。江宁校区一食堂第一餐厅汇聚20余家风味小吃；第二餐厅设有中式快餐、民族风味、精致糕点；第三餐厅有大厅和包间，提供个性化餐饮服务。玄武门校区食堂设有中式快餐、风味小吃和接待包间。两校区食堂共同为师生提供全方位餐饮服务，满足师生多样化就餐需求。

饮食服务中心秉承公益性、服务性、安全性原则，始终将食品安全与卫生放在首位，严格把控食材采购验收环节，不断研发创新菜肴，努力做到膳食均衡、品种丰富，力争为师生提供健康、美味、舒心的餐饮服务。
