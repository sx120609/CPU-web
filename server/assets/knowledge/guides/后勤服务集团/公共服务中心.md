# 公共服务中心
来源：http://hqjt.cpu.edu.cn/14575/list.htm
部门：后勤服务集团

公共服务中心主要负责校园生活保障用房（商贸综合体）、综合服务大厅、校园收发室、菜鸟驿站的日常管理。公共服务中心秉承“有我在 你无忧”的服务理念，全心全意为学校教学科研和全体师生员工服务。

商贸综合体：负责校园生活保障用房的日常管理，食品安全、水电消防安全巡查、物价管控监督等工作。

综合服务大厅：咨询接待、投诉建议、校园维修、对接协调工作、各商户水电抄收等相关工作。

校园收发室：各类报刊杂志、信件、机要文件等的签收、发放、派送等工作。

菜鸟驿站：快递包裹收、发、存工作，开学季新生行李包裹服务、毕业季大件包裹服务的组织调度工作、提供在校学生勤工俭学岗位。
