# 水电保障与维修中心
来源：http://hqjt.cpu.edu.cn/14573/list.htm
部门：后勤服务集团

水电保障与维修中心主要负责校园基础设施的维护、修缮、紧急抢修和水电保障任务。中心严格按照国家各类作业规范及后勤服务集团总公司质量安全管理体系的要求和内容，有序开展工作。秉承“有我在、你无忧”的服务理念，全心全意为学校教学科研和全体师生员工提供服务。

水电保障与维修中心主要职责范围：

（1）负责学校水、电、瓦木和五金等日常零星维修工作；

（2）负责学校或集团下达的各类小型修缮任务；

（3）负责学校水电应急抢修及重要活动的保障工作;

（4）负责学校的供水、供电及变(配)电所(房)、水泵房的安全运行；

（5）负责水、电管网、线路的日常巡查检修、水电保养等工作；

（6）完成学校、集团领导交办的其他应急性工作。
