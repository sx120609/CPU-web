# 关于组织2026届毕业生填写《毕业生登记表》的通知
来源：http://xgc.cpu.edu.cn/9c/d7/c8725a236759/page.htm
日期：2026-05-07
部门：学生工作处

各学院：

根据2026年毕业季总体工作部署，现将我校2026届毕业生填写 《毕业生登记表》的具体工作安排和相关要求通知如下：

## 一、填表对象

1.《高等毕业生登记表》：达到毕业条件并申请毕业的本科生；

2.《毕业研究生登记表》：达到毕业条件并申请毕业的研究生（硕士、博士）。

## 二、填写要求

1.每位同学的毕业生登记表只有一份，领到表格后，须认真阅读填写说明和注意事项（见附件），务必准确、规范、完整填写。

2.毕业班辅导员组织学生对毕业生登记表填报内容进行审核，确保表中各项内容无误、完整。

## 三、用印安排

1.毕业生登记表由本人、班级、学院逐级签署意见后，以学院为单位，按照本科生、研究生分类收齐并核实数量，安排专人提前将用印时间报给学工处，由学工处统筹安排各学院分批集中有序申请盖校印。

2.根据各学院毕业生人数，为保障有序分批前去盖章，建议毕业生人数比较多的学院专场办理用印，其他学院可合并在一起办理用印。

## 四、重要说明

毕业生登记表是归入学生档案的必须材料，是毕业生学习经历的重要证明，不可或缺，须和其他学生档案资料（从入学时的学生登记表开始）归入毕业生档案，不能遗失或遗漏。

附件：

毕业生登记表规范填写说明

1.“姓名”栏中填写户籍登记所用的姓名。少数民族学生的姓名用字要固定，不能用同音字代替。

2.“出生日期”栏中填写出生年月，年份一律用4位数字表示，月份一律用2位数字表示，如“2003.05”。

3.“民族”栏中填写民族的全称（如汉族、回族、朝鲜族、维吾尔族等），不能简写“汉”“回”“鲜”“维”等。

4.“籍贯”栏中填写祖籍所在地。 “籍贯”按现在的行政区划填写，要填写省、市或县的名称，如“辽宁大连”“河北盐山”。直辖市直接填写市名，如“上海”“重庆”等。

5.“入党时间”栏填写成为预备党员的时间（一般是支部大会通过，须与入党志愿书中记载的时间一致）。

6.“健康状况”根据本人的具体情况填写“健康”“一般”或“较差”；有严重疾病、慢性疾病或身体伤残的，如实简要填写即可。

7.“照片”栏中贴彩色近照。

8.“本人简历”从小学时填起，起止时间填到月（年份用4位数字表示，月份用2位数字表示，一般入学是9月，毕业是6月，如1992.09-1998.06），前后要衔接，不能空断（因病休学、休养、等中断的时间等都要如实填写）。

9.家庭主要成员及重要社会关系要填写填表时的真实情况。

10.学位：按照毕业授予学位填写：如理学学士/硕士/博士等。

11.学制按照所在专业培养年限填写：如，4年、5年、3年等。

12.表内所列项目，如没有就填写“无”。

13.登记表中的班级、学院意见及相关签字、日期等内容须全部填写，不要遗漏。

14.须用黑色签字笔工整清晰填写，不能有涂改，各项内容的签名、日期须完整，确保不遗漏。
