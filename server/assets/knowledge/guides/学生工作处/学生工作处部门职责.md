# 部门职责
来源：http://xgc.cpu.edu.cn/49/01/c9547a149761/page.htm
日期：2025-11-18
部门：学生工作处

学生工作部（处）研究生工作部是校党委、行政领导下主管学生工作的职能部门，主要负责学校大学生思想政治教育和学生管理服务工作。部门内设教育管理办公室、学生资助管理中心及社区管理中心三个科室。

教育管理办公室

主要负责部门综合办公、学生思想教育和日常管理、辅导员队伍建设工作，引领学生成长成才，为学生提供良好的管理服务保障。

1.负责部门公文、印章管理、人事、财务预算、资产、工作计划及总结、对外交流、国有资产、信息化（网站、学工系统）、后勤保障及新媒体运转（药大学工微信公众号）；

2.负责学生思想政治教育工作，开展各项主题教育活动，运营管理易班网络社区；

3.负责学生评优及表彰、违纪处分、学风建设、安全稳定等日常事务管理及相关规章制度制定工作；

4.负责学生骨干队伍建设和优秀学生典型选树工作；

5.负责迎新、开学典礼、毕业生离校与毕业典礼的组织和推进工作；

6.负责辅导员队伍的选聘配备、岗位培训、业务指导及考核评优工作。

学生资助管理中心

秉持服务学生成长成才的工作理念，建立以国家助学贷款为主体，勤工助学为主导，“奖、助、贷、勤、补、免”六位一体，资助与育人相结合的联动助学体系，引导学生健康成长、全面发展。

1.贯彻宣传各级各类学生资助政策，制定完善各项学生资助实施细则。

2.负责家庭经济困难学生认定，组织家庭经济困难学生家访；负责新生“绿色通道”管理。

3.负责奖学金、助学金、国家助学贷款、临时困难补助、学费补助申请、审核及发放等；负责校内勤工助学管理，开展“勤工助学先进个人”评比；负责服兵役国家资助、毕业生基层就业学费补偿贷款代偿申请、审核、上报及发放等工作。

4.负责开展多种形式资助育人活动，做好学生发展型资助育人工作。

5.负责全国学生资助管理信息系统的数据采集、整理与录入工作；做好江苏省学生资助绩效评价工作、中央部属高校学生资助绩效问卷调查工作等工作。

6.负责学校年度资助工作总结等稿件上报，学院资助绩效考核等工作。

社区管理中心

主要负责“一站式”学生社区综合管理模式改革建设和学生社区住宿管理；

1.聚焦“党建引领”“队伍入驻”“学生参与”“文化建设”“条件保障”“数字赋能”，推动“一站式”学生社区建设从“有形覆盖”向“有效辐射”转化提升，配合做好社区内学生思想政治教育和行为规范管理；

2.牵头制定和修订学生社区规章制度，开展文明社区创建，发挥学生社区榜样力量，增强学生自理自律意识，配合做好社区内辅导员的日常教育、管理和培训；

3.开展学生社区宿舍入住、调整、退宿、无障碍宿舍等统筹，组织学生社区宿舍内务卫生、违章电器等检查抽查，做好学生社区勤工助学岗位的选聘与酬金发放；

4.维护学生社区管理信息系统，指导、监督物业公司做好学生宿舍的各项管理服务工作，配合相关部门做好学生宿舍维修协调工作；

5.维护学生社区学生学习和生活秩序，及时处理、上报学生社区内的各种突发事件；

6.做好学生社区学生宿舍房源清查，提供学生社区整体环境改造、家具设备等更新出新需求建议，协助做好学生宿舍维修改造清空工作。
