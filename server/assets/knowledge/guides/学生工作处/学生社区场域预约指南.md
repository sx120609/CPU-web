# 学生社区场域预约指南
来源：https://xgc.cpu.edu.cn/81/69/c18006a229737/page.htm
日期：2025-11-18
部门：学生工作处

## 学生社区功能室在线预约操作流程

第一步：【登录中国药科大学企业微信，进入“工作台”，点击“会议室”】

第二步：【在“会议室”选择地点：南京（市）-学生组团-楼层】

第三步：【选择预约时间，申请预定】

第四步：【填写相关内容，提交会议主题，等待审批】

审批完毕，预约成功，点击“发起讨论”联系领取钥匙。

活动室预约成功后,若计划变动,须在使用时间前半小时内取消预约。

## 孟目的书院在线预约操作流程

第一步：【登录中国药科大学企业微信，进入“工作台”，点击“智慧孟院”】

第二步：【点击“书院功能区预约”】

第三步：【选择预约时间，选择预约功能室（如需审批，请等待审批结果）】

预约成功后前往使用。如有问题或困难，请与物管站联系。
