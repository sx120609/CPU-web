# 关于做好2025级本科生转专业工作的通知
来源：https://jwc.cpu.edu.cn/94/c2/c885a234690/page.htm
日期：2026-03-27
部门：教务处

各院部、有关部门：

根据《中国药科大学全日制本科生转专业工作实施办法（2025年修订）》（药大教〔2025〕120号）文件精神，现将我校2025级本科生转专业工作安排通知如下：

一、总体要求

（一）转专业工作在尊重学生个性化发展的基础上，应遵循公平、公正、公开与择优原则进行。

（二）学校负责对转专业工作实行总体协调，统筹安排。各学院成立由主要领导担任组长的转专业工作领导小组，负责转专业工作的具体组织与实施，名单见附件1。

（三）每位同学最多可填报2个专业志愿。

二、申请对象及条件

（一）申请对象：2025级在校全日制本科学生（在校一年级学生，不包含拔尖创新人才培养计划等特色培养计划学生，以及留级学生和复学学生）。

（二）申请条件：

1．政治思想表现良好，学习态度端正。

2．身体条件符合申请转入专业的体检标准。

3．不存在未撤销的纪律处分。

4．无考试作弊、发表论文抄袭等学术不诚信或学术不端行为记录。

5．学生只能跨招生大类填报专业。

（三）有以下情况之一者，不能申请转专业：

1．以特殊招生形式录取的学生，国家有相关规定或者录取前与学校有明确约定的。招生时国家已明确规定不能转专业的学生，含定向生、国防生、艺术类、体育类等专业学生；其他招生时有特殊要求的提前批次录取学生、外国语中学推荐保送录取的学生等；未经全国统一高考招收的特殊录取类型学生，含专转本、第二学士学位等。

2．正在休学或保留学籍的学生，或应予退学的学生。

3．本科期间已进行了一次转专业的学生。

4．中外合作办学专业学生。

5．其他有失公平、公正、公开的情形。

三、各专业接收计划及考核办法

详见各学院2025级本科生转专业工作实施细则，可在教务处及各学院网站进行查询。

链接：http://jwc.cpu.edu.cn/88/0c/c885a231436/page.htm

四、转专业工作程序

（一）报名：分为预报名和正式报名两个阶段。

符合转专业申请条件的学生在规定时间内填写《中国药科大学本科生转专业申请表》（见附件2），交所在学院。各学院对申请转专业学生进行资格审查。

1. 预报名及初审：4月1日-4月7日。各学院对申请转出学生进行资格初审，填报《申请转专业学生预报名汇总表》（见附件3），电子版上报教务处。

2．预报名情况公布：4月8日-4月15日。各学院按照本院转专业工作实施细则，对申请转入学生的课程加权平均成绩进行计算，并在学院网站公布。

3．正式报名：4月16日。

4．资格审查：4月17日-4月22日。各学院对申请转出学生的资格进行审核，并公示3天，公示无异议后填报《申请转专业学生正式报名汇总表》（见附件4），报送教务处（包括盖章纸质版和电子版）。教务处对各学院报送的正式报名学生名单统一公布。

（二）转专业资格及进入学院考核名单公示：

4月23日-4月30日。各学院按照本院转专业工作实施细则，公示进入学院考核的学生名单（含学生课程加权平均成绩），公示期3天。

（三）学院选拔：5月1日-5月18日。各学院完成申请转入本学院学生的综合考核工作。

（四）录取：分为第一志愿录取和第二志愿录取两个阶段。

5月19日-5月24日。各学院根据接收计划和第一志愿学生的最终成绩排名进行录取，并在学院网站公示第一志愿拟录取学生名单，公示期3天。5月24日前，各学院将《转专业第一志愿拟录取名单》（见附件5）报送教务处（包括盖章纸质版和电子版）。

5月25日-5月28日。第一志愿未录满的专业开展第二志愿录取工作。相关学院根据第二志愿学生的最终成绩排名进行录取，并在学院网站公示第二志愿拟录取学生名单，公示期3天。公示无异议后将《转专业第二志愿拟录取名单》（见附件6）报送教务处（包括盖章纸质版和电子版）。

未参加接收学院相关考核的学生，或未达到接收学院公布的接收要求的学生，不予录取。

（五）拟录取名单公示：6月7日前。教务处公示转专业拟录取名单。

（六）审定和名单公布：6月18日前。由校教学工作委员会审定转专业录取名单，并公布准予转专业学生名单。

（七）转专业学生学籍变更：9月1日之前。

五、其他事宜

（一）各学院根据本通知工作进度的要求安排相关工作。面试小组由至少3名以上教师组成，笔试、面试等考核过程全程录像，视频资料至少保存半年。请将本通知的精神向学生传达，认真做好学生转专业的咨询工作。

（二）学生应切实做好自身学业规划，跨大类转专业的学生，将可能面临需要补修大量新专业必修课的情况，必须慎重参与转专业。课程补修采用重修的方式进行，学生根据自身情况合理安排补修。

（三）转专业的学生一旦被录取并公示后，其学籍将由学校统一予以变更，学校不再接受学生转回原专业的申请。

（四）经批准转专业的学生，从下一学年开始进入所转专业学习，并按照转入专业的标准缴纳学费。

（五）申请特殊情形转专业的学生，应填写相关表格并附有关证明材料，向所在学院提出申请，具体报名时间同跨大类转专业报名时间。

（六）学籍及课程修读按照《中国药科大学全日制本科生转专业工作实施办法（2025年修订）》（药大教〔2025〕120号）相关规定执行。
