# 中英文成绩单、英文证书及在读证明办理流程
来源：https://jwc.cpu.edu.cn/23/21/c866a8993/page.htm
日期：2023-07-14
部门：教务处

一、在校普通全日制本专科生、2003级(入校时间)及以后的已毕业普通全日制本专科生

在校生可办理：中英文成绩单，在读证明，预计毕业证明，学籍异动证明

已毕业学生可办理：中英文成绩单，学历学位证明

电子成绩单及证明在线**免费**办理：

需要在系统绑定个人邮箱发送过去才生效带电子章，否则是无效文件！

在校生入口：https://dzpzstu.cpu.edu.cn/student/

**特别提醒：应届毕业生在当年度的9月前仍用在校生入口进行办理！**

已毕业学生入口：

PC端地址：https://dzpzstu.cpu.edu.cn/student/#/ykdxLogin

手机端地址：https://dzpzstu.cpu.edu.cn/

操作说明：药科大学可信电子凭证服务平台操作手册.docx

电子版的证明即为原件，需纸质版证明可将电子证明打印/彩印出来。

二、2002级及以前的往届普通全日制本专科毕业生

可办理：中英文成绩单，英文证书，中文学历学位证明

时间：每周一全天（每学期第二周起，第一周不受理）

上午9:30-11:00，下午14:00-16:00

地点：行政楼202办公室，025-86185203，联系人：殷老师

可联系校内人员代为办理（提供委托书和身份证复印件），如需入校，校友请从中国药科大学校友会小程序预约，其他人员按照校外人员进校要求，提前两个工作日，在中国药科大学公众号，进入“药大生活--访客预约”模块，“到访单位”选择教务处，提交相应的材料，由教务处审核。

付费方式：一卡通或计财处缴费（行政楼一楼）

收费标准：

| 项目（一份） | 所需材料 | 价格（元） |
| --- | --- | --- |
| 中文成绩单 | 学号 | 10 |
| 中英文成绩单 | 学号 | 160 |
| 英文毕业证 | 身份证、学位证、毕业证<br>（原件或复印件均可） | 50 |
| 英文学位证 | 身份证、学位证、毕业证<br>（原件或复印件均可） | 50 |
| 中文学历学位证明 | 身份证、学位证、毕业证<br>（原件或复印件均可） | 10 |
| 注：如需多份，请自行复印 |  |  |

三、其他事项

1．教务处仅可办理普通全日制本专科阶段成绩单材料，研究生阶段请

咨询研究生院培养办（行政楼703，025-86185535）

来华留学生请联系国际教育学院，继续教育生请联系继续教育学院。

2．不提供GPA证明，药科大学信封

等，如需请自备（盖章时间为每周一全天）。

3．如遇节假日或特殊情况，办理时间顺延。

4．咨询电话：025-86185203。
