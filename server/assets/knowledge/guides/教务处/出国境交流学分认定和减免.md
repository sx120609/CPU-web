# 关于开展2026年下半年本科生出国（境）交流学分认定和减免工作的通知
来源：https://jwc.cpu.edu.cn/ba/fe/c854a244478/page.htm
日期：2026-09-22
部门：教务处

各院部：

根据《关于印发<中国药科大学本科生出国（境）交流学习管理办法>的通知》（药大教〔2016〕330号），现将2026年下半年本科生出国（境）交流学分认定和减免有关事项通知如下：

一、认定对象

2026年3月至2027年3月期间参加国际交流项目且符合《关于印发<中国药科大学本科生出国（境）交流学习管理办法>的通知》的本科生。

**注：如本学期仍在外学习的学生，也请先预先填写本学期学分认定申请，以便在回国前制定学习计划，如课程无解决方案，可及时回国参加期末考试。**

二、认定程序

1、学生阅读《关于印发<中国药科大学本科生出国（境）交流学习管理办法>的通知》，查看自己是否符合学分认定及减免条件。

2、学分认定

符合条件的学生于10月8日前填写本通知附件中的《学分认定申请表》中的内容，并需另附外方成绩单原件、每门课程的课程简介、大纲等材料以便审核。所有材料交至教务处陆怡老师处。如尚在国外学习，暂无成绩单，可后期补交。

3、学分减免

符合条件的学生于10月8日前填写本通知附件中的《学分减免申请表》。所有材料交至指定邮箱。
