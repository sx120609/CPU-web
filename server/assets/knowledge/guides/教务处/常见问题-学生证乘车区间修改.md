# 学生证乘车区间修改
来源：https://jwc.cpu.edu.cn/28/38/c855a10296/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 如题

【问题类别】： 学籍管理

【更新日期】： 2012-12-20 16:41:38

【答案】：

乘车区间原则上不允许随意修改，属于下列两种情况之一的，可以修改学生证乘车区间。

1、父母或其他直系亲属户口变化或常住地改变，导致学生乘车到站发生变化。

2、由于铁路部门调整运行图或变更车次，导致学生乘车到站发生变化。

因家庭地址变更需要更换学生证，凭原学生证和父母或其它直系亲属迁入地派出所出具的户口迁移证明办理。

如父母常住地改变，凭父母常住地派出所出具的暂住证办理。

从2011年开始，乘车区间需在教育部学籍平台备案，办理时间为每年12月左右，具体时间见当学期通知，请属于以上2种情况的同学，提前准备好相关证明材料。
