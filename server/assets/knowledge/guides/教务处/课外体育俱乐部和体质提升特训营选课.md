# 关于2026-2027-1学期课外体育俱乐部和体质提升特训营网上选课的通知
来源：https://jwc.cpu.edu.cn/bc/d6/c884a244950/page.htm
日期：2026-10-15
部门：教务处

为贯彻落实党和国家关于学校体育工作的决策部署，引导学生通过体育锻炼“享受乐趣、增强体质、健全人格、锤炼意志”，有效培养学生的体育锻炼习惯，增强学生的身心健康水平，本学期继续开设课外体育俱乐部和体质提升特训营并通过教务系统进行选课。

**一、选课对象**

课外俱乐部和身体素质训练营面向**本科一、二年级**报名。身体素质训练营以体质较弱、体测成绩不理想的学生为主，其他想提高身体素质的同学也可报名。以前报过课外俱乐部和身体素质训练营的同学也可以再报，但是上学期未按要求完成课程的同学不得报名，即使报名也无法获得加分。特别提醒有重大疾病或其它不适宜运动情况的同学不要报名。

**二、选课程序选课时间：2026年10月16日（周五）12：00-15：00**。选课截止后，选课系统将关闭，无法选课。选课系统运行正常的情况下拒绝任何原因任何形式的手工选课申请。

具体的上课时间**以通知附件中项目时间的为准，请勿按照课表上的时间，请特别注意。**

报名采用网上报名方法，网址为：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/）, 请注意：务必用电脑进行选课，浏览器推荐使用windows系统下的360安全浏览器的兼容模式。手机浏览器可能会出现无法退选等未知问题。

选课操作完成后请退出选课系统，再次登录选课系统并在学生空间中查看课表确认所选课程是否已选上。如遇到点击选课或退选时系统提示“请连接VPN”的情况，请清除浏览器缓存或换其他类型浏览器重试。

出现退课失败为浏览器不兼容，请使用电脑windows操作系统下的360安全浏览器兼容模式选课。浏览器不兼容退课失败的同学，可前往A106韩老师处借用电脑，登录选课系统并退课。

**三、课外体育锻炼加分规定**

因资源有限，每人只能选择课外俱乐部或身体素质训练营中的一个项目。本课程没有公选课学分，不会显示在成绩单上。分数体现在当学期体育必修课上，通过考核后可以获得最高5分的课外体育锻炼加分。

**四、上课时间及地点**

第8周（10月19日）开始上课，每周1次共8周。选课成功后即刻加入老师的QQ群，老师会在群里通知具体上课地点及其它要求，没有QQ群的按时到指定地点集合。
