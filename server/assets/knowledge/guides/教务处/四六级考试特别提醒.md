# 大学英语四六级考试特别提醒
来源：https://jwc.cpu.edu.cn/74/b7/c887a95415/page.htm
日期：2026-06-01
部门：教务处

**特别提醒1.考生须将试题册背面条形码揭下粘贴到答题卡1指定区域。未贴条形码的将按违规处理。2.非听力考试期间考生不得佩戴耳机答题，否则按违规处理。**

3. 考生严禁携带各种通讯工具进入考场，如已携带，考前立即交监考员保管，否则开考后发现即按违规处理。

4. 考试结束前，考生不得提前退场。因特殊情况离开考场后，不能再进场续考，且必须在指定地点等候，待考试结束后方可离开。

**5.**考试结束后，考生不得带走试题册和答题卡，否则按违规处理。
