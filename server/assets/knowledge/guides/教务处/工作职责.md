# 工作职责
来源：https://jwc.cpu.edu.cn/gzzz/list.htm
部门：教务处

教务处是学校直属二级行政管理部门，在校党委和行政领导下，主管学校本科教学工作的职能部门，全面负责学校本科教育教学运行、教学研究与改革、教学质量保障以及教学管理服务工作。部门内设教务科、实践教学科、教学研究科、教学评估科、教材科和综合科六个科室，为学校教育教学工作的高效运行和持续发展提供有力保障。各科室主要职责如下：

**教务科**

主要负责本科教学运行管理、学籍学历管理及考试组织工作，统筹教学环节的组织实施与服务保障，维护正常教学秩序，推进教学管理规范化、信息化建设，为学生提供高效、精准的教学管理服务。

1.制作发放毕业证和学位证，学信网数据维护报送，高基表报送；

2.本科生期末考试、补考重修考试、英语水平考试、四六级考试、英语口语考试、普通话考试、学业支持相关工作，毕业生图像采集；

3.成绩管理，重修管理，学业预警，毕业资格审核相关工作，转专业事宜，双学位工作，制作课表，审批借用教室，开具往届生中英文成绩单和相关英文证明材料；

4.办理学籍异动，组织选课，教学计划录入和变更，教务处信息化工作，推免工作，学生证及磁条办理，普通话考试收费，四六级考务工作。

**实践教学科**

主要负责学校本科实践教学的组织与管理工作，统筹推进实验教学、毕业实习与毕业论文（设计）以及大学生创新创业教育，强化实践育人功能，提升学生创新精神和实践能力。

1.负责本专科生毕业实习、毕业论文（设计）的统筹安排、过程管理、质量监控与总结评价，组织开展实验教学计划落实、教学改革与运行管理，推动实践教学体系建设；

2.负责大学生创新创业训练计划项目的组织申报、立项评审、过程指导、中期检查、结题验收及成果推广，指导学生开展创新创业实践活动，营造良好的创新创业教育氛围。

**教学研究科**

主要负责学校本科教育教学改革与建设工作，统筹推进课程体系优化、人才培养方案制定、专业内涵发展、教学成果培育及教师教学能力提升，推动教育教学质量持续提高。

1.负责课程建设规划与实施，组织开展精品课程、一流课程等各级课程项目建设，统筹教学改革课题的立项、管理与成果推广，推进课程平台的运行与维护；

2.牵头组织人才培养方案的修订与优化，推进专业结构优化与内涵建设，开展一流专业、特色专业等专业建设项目的组织实施与管理；

3.负责教师教学发展中心建设，组织开展教师教学培训、教学研讨与教学能力提升活动，推进本科生导师制实施和基层教学组织的规范化建设与管理。

**教学评估科**

主要负责学校本科教学质量保障体系建设与教学评估工作，统筹推进教学检查、质量监控与教学评价，促进教育教学质量持续改进。

1.负责本科教学质量保障体系的建设与运行，组织开展教学评估、教学检查及专项督导工作；统筹学生评教工作的实施，管理学生教学信息员队伍，收集、分析和反馈教学信息，推动教学质量提升；

2.负责本科生国际交流项目学分认定与课程对接工作，组织暑期国际课程的引进、审批、运行与管理，支持国际化人才培养和优质教学资源的融合共享。

**教材科**

主要负责学校本科教材的建设与管理工作，统筹推进教材选用、征订供应和质量建设，保障教学用书的规范性、科学性和先进性，服务课程教学与人才培养需求。

1.负责全校本科教材的征订计划制定、采购组织、发放管理及售后服务，确保教材按时到位，保障教学运行有序；

2.统筹推进教材建设工作，组织规划教材、优秀教材的申报、立项与建设，促进优质教材资源开发与应用。

**综合科**

主要负责教务处日常行政事务与综合协调工作，保障部门高效运转，提升管理服务效能。

1.负责部门印章管理、公文与公函的收发流转、处理督办及文件归档工作，推进办公规范化、制度化建设；

2.负责进修生的招生、学籍管理、教学安排及日常服务，协调处理各类日常事务，支持教学管理工作的有序开展。
