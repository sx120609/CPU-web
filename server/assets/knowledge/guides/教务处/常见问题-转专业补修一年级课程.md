# 转专业学生如何申请补修新专业一年级的课程？
来源：https://jwc.cpu.edu.cn/28/2d/c855a10285/page.htm
日期：2025-09-23
部门：教务处

问：转专业学生如何申请补修新专业一年级的课程？

转专业同学如需申请补修课程，请及时关注教务处主页发布的报名通知。补修报名一般安排在每学期开学初进行，届时请登录教务系统完成报名。

补修课程以“重修”形式办理，但是最终成绩中的考试性质为“正常考试”。重修课程的考试性质为“重修”。因此转专业学生补修的课程与正常考试的成绩性质一样，不会对保研等产生影响。补修课程需按学分缴费。

补修课程的考试，与重修课程一起，参加正常课程的期末考试及补考。
