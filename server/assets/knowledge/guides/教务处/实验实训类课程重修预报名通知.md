# 2026-2027学年第一学期实验(实训)类必修课程重修（补修）预报名通知
来源：https://jwc.cpu.edu.cn/b6/77/c886a243319/page.htm
日期：2026-09-01
部门：教务处

**一、说明**

1. 因实验（实训）类课程的特殊性，此类课程的重修（补修）报名采取“预报名+网上正式报名”的形式。

2. 本学期可以重修的课程为各学年第**一**学期的必修课课程，需要重修各学年第**一**学期实验（实训）类课程的学生，可以预报名重修。

3. 需要补修各学年第**一**学期实验(实训)类必修课的与重修课程的操作相同。

**二、报名步骤**

1. 预报名（提交纸质申请报名）

需要重修实验（实训）类课程的学生，请于2026年9月7日前持填写好的《实验（实训）课重修预报名申请表》（教务处网站“下载专区”下载）到教务处预报名。地点：行政楼202联系电话：86185797。

因部分实验（实训）课在第二周就开课，预报名后，请尽快持报名表的第二联，自行与开课学院的相关教研室联系，安排本学期的实验（实训）课的重修。

2. 正式报名（网上报名）

提交纸质申请只是**预报名**，其主要目的是提前安排实验（实训），预报名后还必须进行网上正式报名和缴费。**正式报名和缴费成功才为有效的重修报名。**本学期重修网上报名的具体时间和报名方法请关注教务处网站的后续通知。

注意：所有的报名课程必须是各学年第**一**学期的课程。
