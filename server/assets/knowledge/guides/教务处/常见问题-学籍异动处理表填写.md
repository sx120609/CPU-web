# 学籍异动处理表填写有何要求？
来源：https://jwc.cpu.edu.cn/28/3e/c855a10302/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 学籍异动处理表填写有何要求？

【问题类别】： 学籍管理

【更新日期】： 2010-3-25 16:37:19

【答案】：

1、事由一栏：不能涂改，学生本人要签名。
(1)凡因病休学、复学、退学均需附医院的诊断证明；
(2)学生本人申请退学的，需附上退学申请，经家长同意并签字。
(3)学生留级填写“事由”从以下三种情况选择其中之一填写：① 各学期必修课程累计有20学分以上（包括20学分）未获得；② 第七学期必修课程累计12学分以上（包括12学分）未获得；③ 学生本人申请留级（需附本人留级申请）。

2．卫生科一栏：因疾病办理学籍异动，才需要卫生科盖章，否则不需要卫生科签字盖章。
