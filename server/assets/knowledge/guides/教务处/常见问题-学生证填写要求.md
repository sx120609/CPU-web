# 学生证填写要求是什么？
来源：https://jwc.cpu.edu.cn/28/2c/c855a10284/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 新生入学办理学生证及补办学生证的填写要求是什么？

【问题类别】： 学籍管理

【更新日期】： 2010-3-25 16:26:34

【答案】：

（1）．学生应准确、如实填写学生证中的相关信息。并贴上学生本人一寸彩色证件照片。

（2）．要求字迹工整、不得涂改。

（３）．学生证需填写以下信息：“学号”“姓名”“性别”“出生年月”“专业”“班级”“籍贯”“入学年月”“家庭住址”“乘车区间”。

（４）．“乘车区间”填写格式如下：“起点站-终点站”。起点站、终点站是指购买火车票时的站点。起点是南京站，终点站是指火车到达家庭户口所在地的终点站，例：“南京－苏州”。终点站应与家庭户口所在地一致。若因填写的地点与实际不符，导致今后无法购买学生火车票，后果由学生本人自负。

（５）．教务科将核对家庭住址与乘车区间，如果不一致，学生证将不予盖钢印。

（6）．学生证相关信息一旦填写，将不予更改。
