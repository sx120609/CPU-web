# 关于2026-2027学年第一学期《有机化学（二）》等重修（补修）课程上课安排的通知
来源：https://jwc.cpu.edu.cn/bc/c0/c887a244928/page.htm
日期：2026-10-14
部门：教务处

各学院：

根据《关于加强课程教学过程性评价的指导性意见（试行）》（药大教函〔2017〕5号）文件精神，为了对学生学习状况和学业成果进行全方位、多形式、分阶段的考核评价，本学期《有机化学（二）》等重修（补修）课程将实施教学过程性评价，教学过程性评价成绩计入重修（补修）的总评成绩。具体事项通知如下：

一、开课课程

《有机化学（二）》（课程编号：1112050064、1112050381）、《物理化学》（课程编号：1112050313）、《物理化学（上）》（课程编号：1112050260）、《基础化学（一）》（课程编号：1112050306、1112051025）、《高等数学（一）》（课程编号：1112050237、1112050238）、《仪器分析》（课程编号：1112050014、1112050303、1112051032）、《物理学（一）》（课程编号：1112050092、1112051007、1112051047、1112051061）

二、开课对象

未通过以上课程考试，且本学期已在教务系统报名重修的学生，或本学期已在教务系统报名补修的学生。请学院务必通知到学生。

三、开课形式

相关课程上课形式及要求等说明详见附件1。过程性考核要求按照《关于加强课程教学过程性评价的指导性意见（试行）》（药大教函〔2017〕5号）执行。
