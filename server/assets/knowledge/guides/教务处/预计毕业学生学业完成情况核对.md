# 关于2026届预计毕业学生学业完成情况核对的通知
来源：https://jwc.cpu.edu.cn/84/58/c885a230488/page.htm
日期：2025-12-05
部门：教务处

各学院：

为督促2026届本科毕业生了解本人学业完成情况，及时重修或补修所缺必修课课程，按时修满所缺选修课学分，保证下学期能顺利毕业，特于本学期进行预计毕业学生的学业完成情况核对。

核对主要内容为：必修课课程完成情况、选修课学分完成情况。

现将相关注意事项通知如下：

**一、核对流程**

1.学生登录教务处网站“学生空间”的“学业完成情况”栏，查询“已完成必修课程”及“未完成必修课程”、“毕业要求专业选修课（公共选修课）学分”及“已完成专业选修课程（通识选修课程）情况。

2.学生查询后，由本人在《2026届预计毕业学生必修课课程、选修课学分核对表》上签名。签名后即表示学生本人对毕业要求已了解,对所缺必修课课程和所缺选修课学分已了解。

**二、核对说明**

1．学生符合毕业要求的条件是：完成现年级（专业）所有 “必修课程”且“已完成专业选修课程学分”和“已完成通识选修课程学分”达到毕业学分要求。

如果在“未完成必修课程”栏，有非“2025-2026学年”的课程，务必在最后两学期报名重修；如果“已完成选修学分”尚未达到“毕业要求学分”，务必在最后两学期选修相应课程。

2．学生空间“学业完成情况”一栏，是与学生现所在年级（专业）的学业要求所做的比对，有过学籍异动的学生（休学、留级、卓工班选拔、转专业、基地班分流等），毕业资格是按照最后所在年级（专业）的要求审核。

如有需要成绩认定的课程，请参照《学生申请成绩认定流程》申请成绩认定。

http://jwc.cpu.edu.cn/f9/dc/c930a195036/page.htm

成绩认定的原则可查询：

http://jwc.cpu.edu.cn/3d/92/c930a212370/page.htm

如有需要补修的课程，请在重修报名时间，按照重修报名通知上的要求办理。

3．拔尖计划生，要求完成“拔尖计划”所有修读课程。

4．选修课学分不能“四舍五入”。

5．“开放实验”和“大创”等的奖励学分,将由教务处实践教学科在2026年的5月份统一作学分认定。

6. 任何专业不安排毕业前补考。

学生全部签名后由辅导员签字，以学院为单位于2025年12月12日前交行政楼202。如学生本人确因故不能亲自签名，务必请辅导员通知其核对后，由辅导员代签，并在签名栏注明“已通知本人核对，xxx代”字样。

学生如对某课程的成绩有疑议，请参照《学生申请复查考试成绩流程》申请复核。http://jwc.cpu.edu.cn/f9/ff/c930a195071/page.htm

如有其它疑问，在通知要求的核对期间，向教务处咨询，咨询电话：86185797，地点：行政楼202。
