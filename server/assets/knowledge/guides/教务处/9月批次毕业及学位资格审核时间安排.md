# 2026-2027-1学期9月批次毕业及学位授予资格审核工作时间安排
来源：https://jwc.cpu.edu.cn/b6/ad/c885a243373/page.htm
日期：2026-09-02
部门：教务处

2026届及往届未领取到毕业证和学位证需要申请9月批次毕业及学位的同学，可在9月批次审核的规定时间内进行申请，申请通过后，教务处会将符合要求的毕业证和学位证发放到学院，由学院进行分发。具体时间安排如下：

**申请时间：9月3日-9月8日23:00前**需要申请的学生在个人教务系统中进行线上毕业资格及学位资格审核申请（操作步骤见附件《1.毕业申请相关指南-学生版》），同时将《学位申请书》纸质材料交到学院（具体提交要求可咨询学院）。

**2026届之前**的学生申请时还需提交《往届生论文信息表》（附件5）。

**初审时间：9月9日-9月12日23:00**学院毕业资格审核委员会进行学院初审，学院初审名单需在线上审核通过并将《毕业资格初审汇总表》（附件4）、《学位初审结果报告》的纸质材料签字盖章交到行政楼202，并以院部为单位将《往届生论文信息表》（附件5）（此表只需提交**审核通过的往届学生**的相关材料）。未通过初审的学生务必通知到学生个人。（操作步骤见附件2）

**9月13日开始复审**，复审通过后，教务处将《中国药科大学学位授予决定》及相关证书发放到各学院，由学院发放给学生。
