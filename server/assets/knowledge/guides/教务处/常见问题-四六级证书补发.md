# 请问英语四六级证书丢失了可以补发吗
来源：https://jwc.cpu.edu.cn/27/f6/c855a10230/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 请问英语四六级证书丢失了可以补发吗？

【问题类别】： 成绩管理

【更新日期】： 2016-3-7 16:09:09

【答案】：

接省考试院通知，全国大学英语四六级考试委员会规定申请补办CET成绩证明，统一改在网上申请办理（限于2005年及以后的笔试），网址为：http://chaxun.neea.edu.cn 实行网上办理之后，学生不需要到教务处开具证明，可直接登录网站办理即可。（办理成绩证明有一段时间过程，请同学提前申请办理。）
