# 2026年普通话测试报名通知
来源：https://jwc.cpu.edu.cn/c5/4d/c887a247117/page.htm
日期：2026-11-02
部门：教务处

一、测试对象：我校本科和研究生在籍学生，以自愿测试为主。

二、测试时间：2026年12月

三、报名事项：

1．**网上报名时间:2026年11月2日—11月9日**。

2．**报名方式：请查看江苏省普通话水平测试考生在线报名操作说明**。

3．**报名费：学生每人25元**。

4. **由于测试机位有限，报名额满为止。**

四、普通话水平测试形式和内容

1、测试形式：计算机辅助方式即考生采用上机模式参加考试。

2、测试内容：读单音节词、读多音节词、朗读短文、命题说话，其中读单音节词、读多音节词、朗读短文三项由计算机辅助普通话测试系统自动评分，命题说话部分由省中心调配优秀测试员通过网络在线评分。

五、学分奖励

凡是参加普通话水平测试的本专科生测试级别达二级甲等以上者（含二甲）可奖励一个公选课学分，奖励学分计入当学年。（普通话奖励学分不重复计算）

注：需教材者自行购买（《普通话水平测试指导用书》江苏版，商务印书馆出版

**六、根据教育部颁布的新版《普通话水平测试管理规定》（https://jwc.cpu.edu.cn/c5/4d/c887a247117/page.htm#wechat_redirect）（教育部令第51号），第十五条普通话水平测试等级证书分为纸质证书和电子证书，二者具有同等效力。纸质证书遗失的，不予补发，可以通过国家政务服务平台查询测试成绩，查询结果与证书具有同等效力。2022年1月1日起，包括2022年以前参加过普通话水平测试在“全国普通话水平测试信息资源网”（www.cltt.org）能查询到成绩。江苏省普通话水平测试考生在线报名操作说明（学生专场）1.docx**
