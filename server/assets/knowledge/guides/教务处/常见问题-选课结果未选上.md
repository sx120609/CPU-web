# 为什么我明明选课程，最终选课结果里却没选上？
来源：https://jwc.cpu.edu.cn/28/22/c855a10274/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 公选课、指选课网上选课过程中，明明我上网登录选了课程，但最终选课结果里却没有选上，为什么？

【问题类别】： 课程管理

【更新日期】： 2010-3-23 16:10:29

【答案】：

**原因A：**因个人选课操作失误，或者系统或者网络原因引起未选上，而本人又没有在每个阶段选课截止之前再次登陆系统确认并补救。
**原因B：**是在第一阶段确定选上的课程，但是系统随机抽签时并未抽上，而本人又没有进行下面二个阶段的选课。
**原因C：**在第一阶段和第二阶段确认都选上了，但由于选课人数未满25人造成该课程停开，因此选课结果被删除，而本人又没有进行第三阶段的补选课操作。

**综上所述**，所有选课学生务必在选课的每个阶段结束之前登陆选课系统确认自己所选的课程是否已选上，如果未选上则立刻再次选择补救。避免由于人为疏忽或者系统或者网络原因造成课程未选上。选课必须在规定时间内进行，时间截止后，选课系统将关闭，不能再进行选课，选课系统运行正常的情况下拒绝任何原因任何形式的手工选课申请。
