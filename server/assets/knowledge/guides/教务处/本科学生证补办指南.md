# 本科学生证补办指南

日期：2024-10-15
部门：教务处

一、补办学生证的程序

学生遗失学生证后需在正式出版的刊物上发布遗失启示。（需登报的学生可直接关注金陵晚报、南京晨报等自主登报，截图凭证也可作为登报凭证）

学生携带刊登的遗失启示或出版社发票在规定时间到教务科办理，补办时需交填写好的《中国药科大学学生证补办申请表》（见附件）。

因学生证损坏而换学生证，不需刊登遗失启示，但需携带坏证、补办申请表。

二、 补办学生证和火车票优惠卡的时间

补办时间是工作日每周三，遇假日顺延至下周三。领取时间是补办交表后一周后的周二上班时间。

三、 补办学生证的地点
