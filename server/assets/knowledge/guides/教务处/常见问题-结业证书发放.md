# 在何种情况下可发结业证书？
来源：https://jwc.cpu.edu.cn/28/33/c855a10291/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 在何种情况下可发结业证书？

【问题类别】： 学籍管理

【更新日期】： 2014-3-25 16:28:37

【答案】：

Ø 学生在学校规定学习年限内，修完教育教学计划规定内容，未达到毕业要求（有一门或一门以上课程不及格）准予结业，由学校发给结业证书，办理离校手续。

Ø 结业后可于下一学年内按学校规定办理考试手续，如在结业后一年内考试合格取得所缺学分，达到毕业要求，学校可换发毕业证书及学位证书。

Ø 对合格后换发的毕业证书，毕业时间按发证时间如实填写。
