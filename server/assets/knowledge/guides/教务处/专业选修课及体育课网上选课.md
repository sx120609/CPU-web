# 关于专业选修课及体育课网上选课的通知
来源：https://jwc.cpu.edu.cn/b2/37/c884a242231/page.htm
日期：2026-07-09
部门：教务处

各学院：

2026-2027-1学年第一学期专业选修课和体育课提前至本学期选课，采用网上报名方法（选课地址：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/），点击“学生空间”登录后中选择学生空间首页的“选课中心”，再点击进入选课,请注意：务必用电脑进行选课，手机浏览器可能会出现无法退选等未知问题，如遇到点击选课或退选时提示“请连接VPN”的情况，请试着清除浏览器缓存或换其他类型浏览器重试。出现退课失败是因为浏览器不兼容，推荐使用windows操作系统下的360安全浏览器兼容模式选课。），专业选修课和体育课均从下学期第一周开始正常上课，具体安排如下：

一、正选阶段：2026年7月10日（周五）12：00—2026年7月12日（周日）12：00。

二、补退选阶段：2026-2027-1学年第一学期初,具体时间另行通知。

三、根据学校要求，欠费学生不能参与选课。本次选课加入了欠费控制，请欠费学生务必在选课期间缴清各类费用并在选课阶段结束前及时选课，关于欠费如有疑问，请咨询学校计财处查询详细欠费情况。

四、专业选修课报名人数较少的课程将由开课学院决定是否停开，停开的课程将于2026年7月13日（周一）下午14：00后公布在教务处主页，请各院部教学秘书按时查看，通知相关学生与教师。

五、受课程资源限制，本轮选课阶段，高年级学生不能选修本专业低年级开设的专业选修课；已修读未通过的课程亦不可重复选课。在退补选阶段，课程剩余名额将统一对上述两类情形的同学开放选报。

六、选课步骤参见通知附件，本次选课采用新的选课模块，请各位同学提前阅读选课操作指南。

七、报名时间结束前，请点击【选课结果】查看选课结果信息，如发现未报上，及时在结束前补报。选课系统正常运行的情况下，拒绝任何原因任何形式的手工选课申请与删除课程。

八、专业选修课和体育课的所有项目额满为止。过期无法补选，如错过选课，不能参加专业选修课和体育课上课，即使参加期末考试，成绩也无效，体育课期末成绩将以“缺考”录入系统。

九、已结业的学生线下选课，统一安排在下学期初退补选阶段进行。

十、请各院部教学秘书及时通知有关学生和任课教师。务必通知到每位学生仔细阅读《关于2026-2027-1学期体育课网上选课安排及要求》（附1）和《关于专业选修课学生网上报名的安排及要求》（附2）后再正确选课。

附2：关于专业选修课学生网上报名的安排及要求

2026-2027-1学年第一学期专业选修课采用网上报名方法（选课地址：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/），进入“学生空间” ），具体安排如下：

一、网上报名时间安排：

1、正选阶段：2026年7月10日（周五）12：00—2026年7月12日（周日）12：00。此阶段结束后，报名人数较少的课程将由开课学院决定是否停开；

2、补退选阶段：2026-2027-1学期开学初,具体时间另行通知；选择已停开课程的（与前阶段忘记选课的）同学补选本专业所开的其他专业选修课程。

请严格遵守选课时间，过期选课系统自动关闭！

二、所有开设的专业选修课可在教务处主页搜索“教学一览”（或选课期间登录选课系统）查询。

三、报名人数较少的课程将由开课学院决定是否停开，停开的课程将于2026年7月13日（周一）下午14：00后公布在教务处主页，请各院部教学秘书按时查看，通知相关学生与教师。

四、专业选修课报名后，无故不参加考试的学生，该课程成绩以“缺考”记入学籍档案。

五、受课程资源限制，本轮选课阶段，高年级学生不能选修本专业低年级开设的专业选修课；已修读未通过的课程亦不可重复选课。在退补选阶段，课程剩余名额将统一对上述两类情形的同学开放选报。

六、有实验课的专业选修课，该课程的理论课和实验课必须同时选修。不得单独选修该课程的理论课或实验课。例生科院的“抗生素”：已选抗生素理论课的学生，则必须选“抗生素实验”。如单独选“抗生素”理论课或实验课，则视为“无效选课”，即使参加学习和期末考试，期末成绩也将记为0分。如之前学期通过了“抗生素”理论课程但实验课未通过，本学期仅需选“抗生素实验”，则需上课后自行联系“抗生素实验”的任课老师，出示“抗生素”理论课的学分并说明情况，期末考试即可正常计分。如之前学期单独通过了实验课同样适用。

七、报名时间结束前，请点击【选课结果】查看选课结果信息，如发现未报上，及时在结束前补报。选课系统正常运行的情况下，拒绝任何原因任何形式的手工选课申请与删除课程。

八、请同学们按时选课，所有项目额满为止。过期无法补选，如错过选课，即使参加期末考试，成绩也无效。

九、如网上报名有问题请联系：86185797，张老师。

十、请各院部及时通知到有关学生和任课教师。
