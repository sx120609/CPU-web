# 关于学生课程学分认定（替代）的处理原则
来源：https://jwc.cpu.edu.cn/01/d3/c930a197075/page.htm
日期：2024-01-09
部门：教务处

一、**必修认定指选（专业选修课）：**针对个别毕业班学生，出现指选课（专业选修课）学分未修满，且当学期学生所在专业当前年级及低年级均无指选课（专业选修课）可选的情况，允许学生申请参加与所在专业指选课（专业选修课）计划中相同或相近课程的必修课修读，考核通过后认定为指选课（专业选修课）学分。处理原则如下：

1．对于所选择的必修课，课程名称相同且课程内容相同或相近（或课程名称虽有不同但授课内容相同或相近），且必修课的课程内容及考核要求高于或等于指选课（专业选修课）的要求；

2．必修课学分大于或等于指选课（专业选修课）学分；

3．办理程序：学生填写申请，申请上须有认定课程以及被认定课程的开课教研室主任签署意见，意见要注明认定课程的教学内容及要求高于或等同于被认定课程，可以进行认定；

4．此类认定针对毕业班学生，且再无机会选指选课（专业选修课）修满指选课（专业选修课）学分的学生。如仍有机会选修本专业本年级或低年级指选课（专业选修课）的学生不适用必修课认定指选课（专业选修课）的方式。

**二、必修认定必修：**针对转专业（留降级）等学籍异动学生，对于在原专业（原年级）已修读且成绩合格的必修课程，如在新专业（新年级）教学计划中需要修读相同或相近的课程，可以申请原必修课学分认定新必修课学分，处理原则如下：

1.原专业（原年级）的已修必修课，与新专业（新年级）必修课**课程名称相同**且课程内容相同或相近，原专业（原年级）必修课学分大于或等于新专业（新年级）必修课学分的，可以认定；原专业（原年级）必修课学分小于新专业（新年级）必修课学分但学分相差在1学分或以内的，也可以认定。

2. 原专业（原年级）的已修必修课，与新专业（新年级）必修**课课程名称不同**但课程内容相同或相近，原专业（原年级）必修课学分大于或等于新专业（新年级）必修课学分的，可以认定;

3.办理程序：转专业（留降级）等学籍异动学生根据教务处的相关通知办理;

4.此类认定针对转专业（留降级）等学籍异动学生原专业（原年级）已经通过的必修课认定为新专业（新年级）教学计划相同或相近的课程。

**三、指选（专业选修课）认定必修:**针对留降级学籍异动的学生

因学校培养方案（教学计划）调整原因导致原年级的必修课（指选课/专业选修课）在新年级的培养方案（教学计划）变成了指选课/专业选修课（必修课），名称相同且学分大于或等于原年级必修课（指选课/专业选修课）学分的，可以申请认定。
