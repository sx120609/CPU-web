# 关于公布2026年中国药科大学本科生科创竞赛认定清单的通知
来源：https://jwc.cpu.edu.cn/af/59/c940a241497/page.htm
日期：2026-06-15
部门：教务处

各院部：

为进一步规范我校本科生科创竞赛管理，引导师生集中精力参与覆盖面广、含金量高、认可度高、影响力强的标志性赛事，全面提升学科竞赛成绩与人才培养质量，特制定《2026年中国药科大学本科生科创竞赛认定清单》（以下简称“清单”）。

本清单是学校投入经费、开展竞赛项目建设的重要依据，也是学生推免加分、教师职称评审、师生奖励等工作的基础。清单将根据赛事实际发展情况及学校工作部署，每年进行动态调整。现将2026年认定清单予以公布（见附件）。

请各院部进一步加强科创竞赛管理，组织教师积极开展赛事研究和培训，不断提升学生参赛质量，充分发挥竞赛以赛促教、以赛促学、以赛促创的作用，推动我校人才培养质量持续提升。

特此通知。

附件：中国药科大学本科生科创竞赛认定清单（2026年版）.pdf

教务处

2026年6月15日
