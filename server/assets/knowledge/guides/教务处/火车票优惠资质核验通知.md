# 关于做好2024-2025学年第一学期学生火车票优惠资质核验工作的通知
来源：https://jwc.cpu.edu.cn/48/7c/c948a215164/page.htm
日期：2024-12-02
部门：教务处

各学院、各位同学：

根据教育部办公厅 国铁集团办公厅《关于进一步便利普通高等学校学生购买优惠火车票的通知》（教学厅函〔2023〕4号）精神，普通高等学校在校生在铁路12306客户端学生专区中准确填写个人信息和与学生证上一致的优惠乘车区间，经铁路12306系统与学信网进行线上信息比对，完成学生优惠资质核验通过后（一个工作日内日，系统会显示通过与否）即可享受火车票优惠购票政策（每学年4次，每学年可购买家庭居住地至学校所在地之间4次单程的学生优惠票，优惠乘车次数按学年使用有效，当学年不能使用下一学年的次数，当学年未使用的不能留作下学年使用），学校不再单独发放纸质的火车票优惠卡，为保障学生顺利乘车，现将有关事项通知如下：

一、办理对象

需要购买火车优惠票的本科在校学生

二、办理流程

1. 学生需根据中国铁路官网发布的学生票核验最新规定通知完成资质核验，地址为：https://mp.weixin.qq.com/s/vICbL_Q7yq620NY5fGTy1Q，核验并了解相关政策。学生每学年乘车前，都需完成上述资质核验。

2. 学生在学生证上准确填写往返家庭与学校优惠乘车区间，注意学生证的乘车区间信息要和12306资质核验信息一致。请使用黑笔水笔填写学生区间信息，**确保字迹工整、清楚，不得涂改**。填写完整后学生证以**班级**为单位交至辅导员处，在学院进行注册，学生证上的新生与老生注册时间为2024年9月20日。

三、提醒事项

1. 学生本人请确保12306客户端“学生资质核验专区”中所填写的学生票优惠乘车区间与学生证中记载的优惠乘车区间一致。因区间信息填写有误导致无法使用乘车优惠，需由学生本人自行承担补票差额。

2. 针对**已有纸质优惠卡**的学生，不再进行补充磁的线下办理。新生、老生，请务必先在12306客户端**线上**完成资质核验，铁路部门对于已经完成资质核验的旅客，乘车途中不再核验学生证内是否附有学生优惠卡。（如有核验，可将此铁道部的通知链接向列车员出示https://mp.weixin.qq.com/s/vICbL_Q7yq620NY5fGTy1Q）

3. 学生家庭住址发生变更时，要及时在铁路12306客户端“学生资质核验专区”中，办理学生优惠乘车区间变更申请，同时需到教务处202室重新加盖教务处校正章，私自涂改则视为无效。

请各学院通知到全体学生，务必按上述规定完成相关流程。学生证资质核验过程中乘车区间变更咨询，联系电话：025-86185203。其他问题请咨询铁路热线：12306。

教务处
