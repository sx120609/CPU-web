# 关于2026级新生体育必修课及专业选修课网上选课的通知
来源：https://jwc.cpu.edu.cn/bb/04/c884a244484/page.htm
日期：2026-09-22
部门：教务处

各院部：

本次选课对象对应的可选类型如下：

2026级本科生可选课程类型：必修课体育（一）、专业选修课（仅部分专业需要选，以选课系统中看到的为准，选课系统中没有课程则说明该专业本学期没有开设专业选修课）。

所有类型的选课都采用网上选课的办法，请同学们登录选课系统进行选课。选课网址：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/），登录方式：主页“学生空间”点击后从“新版教务平台”进入。账号为录取通知书号，初始密码为身份证后六位。

一、选课时间为：2026年9月23日（周三）12：00--9月24日（周四）12：00。

选课时间截止后，选课系统将关闭，无法选课。选课系统运行正常的情况下拒绝任何原因任何形式的手工选课申请。

二、体育必修课选课额满为止，如错过体育选课，不能参加体育课上课，即使参加期末考试，成绩也无效，本学期体育课期末成绩将以“缺考”录入系统。具体选课方式见附1：体育课选课注意事项。

三、专业选修课额满为止，没有门数限制。

四、选课操作完成后请退出选课系统，再次登陆选课系统并在学生空间中查看课表确认所选课程是否已选上。选课成功后无故不听课或不参加考试的学生，该课程成绩以“缺考”记录。名单以外的学生，不得参与上课,即使参加上课与考核，其成绩也不予承认。如遇到点击选课或退选时提示“请连接VPN”的情况，请试着清除浏览器缓存或换其他类型浏览器重试。出现退课失败可能为浏览器不兼容，推荐使用windows操作系统下的360安全浏览器兼容模式选课。
