# 中国药科大学本专科学生姓名、身份证等学籍信息更改说明
来源：https://jwc.cpu.edu.cn/23/1f/c866a8991/page.htm
日期：2023-10-25
部门：教务处

学生在教育部全国高等教育学生信息网上查询学籍信息，如发现学籍信息有误，根据江苏省教育厅学籍学历工作会议精神和要求，我校本专科在校生如更改姓名和身份证号等信息需提供以下证明材料：

**一、更改姓名**

1、户口不在学校的学生：更改姓名需提供户口簿复印件和身份证复印件，户口簿中的曾用名需与教育部招生库中的姓名一致，并盖县级以上公安局户籍章

2、户口在学校的学生：更改姓名需提供《常住人口登记表》复印件和身份证复印件，《常住人口登记表》复印件,其中曾用名需与教育部招生库中的姓名一致，需盖校保卫处章。

3、新生入学时姓名与教育部招生库中姓名不一致：如是招生时姓名弄错，需考生所在省省级招办在《普通高校新生录取名册》中更改姓名，同时在更改姓名处盖省级招办章。

**二、更改身份证号**

1：从15位升号到18位：只要更改的身份证号码符合身份证自动升号规则，仅需提供身份证复印件即可。

2、属于身份证号变更的：需提供公安部治安管理局居民身份证更改证明，县级以上公安局盖章以及身份证复印件。

3、新生入学时身份证号与教育部录取库身份证号不一致，如果是高考报名时报错，则需提供考生所在省省级招办出具的身份证号在报名时录错的证明以及身份证复印件。如其它原因更改身份证号，则需提供公安部治安管理局居民身份证更改证明，县级以上公安局盖章。

**三、更改出生日期**

身份证号正确，但出生日期错，只需身份证复印件即可。

**四、更改民族**

需提供《常住人口登记表》复印件和身份证复印件，《常住人口登记表》复印件需盖校保卫处章。

**注：以上证明材料均需一式二份，一份交省教育厅审核并更改，一份教务科存档。**

中国药科大学教务处

2023年10月25日
