# 关于医药代表备案专业证明办理的工作提示
来源：https://jwc.cpu.edu.cn/b3/e7/c851a242663/page.htm
日期：2026-07-25
部门：教务处

《医药代表管理办法》将于2026年8月1日起正式实施。关于医药代表备案的相关事宜，官方在政策解读中明确：“对于不在参考目录内的专业，若专业培养方案中设置医学、药学类相关必修课程，也可视为相关专业。办理备案时，可提供校方出具的医学、药学类必修课修读证明和加盖学校公章的课程成绩单后进行备案”。

（一）医药代表备案专业证明办理流程

1.医药代表备案专业证明相关下载系统未开通前（7月25日--8月1日）可通过联系相关学院办理。

2.8月1日系统开通后，2003级及以后入学的毕业生的医药代表备案专业证明通过可信电子成绩单平台自主办理，平台链接:https://dzpzstu.cpu.edu.cn/student/#/ykdxLogin。

3.2002级及以前入学的毕业生医药代表备案专业证明可通过联系相关学院办理（可信电子成绩单平台不支持自主办理）。
