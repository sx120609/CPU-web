# 转专业学生如何申请成绩（学分）认定？
来源：https://jwc.cpu.edu.cn/27/ee/c855a10222/page.htm
日期：2025-09-23
部门：教务处

**问：转专业学生申请成绩（学分）认定的原则是什么？申请流程是什么？成绩（学分）认定原则：**

《中国药科大学全日制本科生转专业实施办法（2025年修订）》第十二条转入新专业的学生，按照转入专业教学计划审核毕业资格。转专业学生可申请学分认定，无法认定的所缺必修课程须补修，具体事项按照《中国药科大学本专科学生学分认定管理办法》执行。

成绩（学分）认定的具体要求见http://jwc.cpu.edu.cn/3d/92/c930a212370/page.htm，http://jwc.cpu.edu.cn/01/d3/c930a197075/page.htm

**成绩（学分）认定申请流程：**

学生登录学生空间---查询学业完成情况未通过的课程---根据认定原则确定可以认定的课程---在成绩认定申请模块中申请认定---线上审核（审核流程：辅导员--开课学院教研室主任--教学秘书--教务处）

具体操作见http://jwc.cpu.edu.cn/b9/a8/c930a244136/page.htm

**特别注意：**课程编号完全一样的课程不需要申请成绩（学分）认定，系统自动转换。

无法认定的所缺必修课程须补修。

新专业教学计划不作要求的必修课程，可以申请转通识（公共）选修课学分；必修课程转通识（公共）选修课不是强制性的，由学生自己根据通识（公共）选修课学分要求情况、修读情况及后续个人发展情况等决定是否转换；一旦进行了必修转通识（公选），将无法再转回。
