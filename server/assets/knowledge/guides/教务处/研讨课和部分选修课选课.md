# 关于2026-2027-1学期研讨课和部分选修课的选课通知
来源：https://jwc.cpu.edu.cn/bc/0e/c884a244750/page.htm
日期：2026-10-09
部门：教务处

各学院：

本学期我校面向本科生开设了小班研讨类课程及部分普通选修课。本类课程的学分类型均为“选修”，即通识选修课，上课名单采取网上选课系统选课，具体安排如下：

1.网上选课的地址为：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/）（主页“学生空间”点击后从“新版教务平台”进入）。

2.选课对象：**本次选课面向2026级新生**。具体的以选课系统中显示的为准，能在系统中看见的课程，就可以选，课表都可以在教务处网站查询。

3.报名时间为：2026年10月10日12：00—10月12日24：00，请同学按时上网登录选课系统报名，先到先得，选修课额满为止，逾期不再补报。因本次课程资源有限，每人限选两门，未选上的学生不能上课，即使上了课也不能获得该门课程的学分。

4.选课操作完成后请退出选课系统，再次登陆选课系统并在学生空间中查看课表确认所选课程是否已选上。选课成功后无故不听课或不参加考试的学生，该课程成绩以“缺考”记录。

5.请不要使用手机浏览器选课，否则可能会出现无法正常选课或退选的问题。如遇到点击选课或退选网页卡死的情况，请试着清除浏览器缓存或换其他类型浏览器重试。

如网上报名有问题请拨打86185797，联系人：张老师。
