# 关于公布2025-2026学年第二学期期末考试安排的通知
来源：https://jwc.cpu.edu.cn/ad/b3/c887a241075/page.htm
日期：2026-06-08
部门：教务处

各院部、相关单位：

本学期期末考试时间：2026年6月29日（周一）—7月10日（周五）。考试日程安排见附件。

现将有关注意事项说明如下：

1. 考试时间：具体课程考试时间见附件。考试地点：江宁校区教学楼B、C、D、E教室。

2. 请监考、巡考人员和所有考生仔细核对课程考试时间和地点，做好考试相关准备工作，以免延误考试。

3. 请同学们认真复习迎考，突击应试不可取，严肃考风考纪。考生必须携带学生证、身份证，重修（补修）的学生还需携带重修证，按照规定时间、地点参加考试。证件不齐者，不得参加相应课程考试。

4. 重修（补修）学生务必与任课教师联系，确认考试时间和地点，避免错过考试。

5. **特别提醒：**E205教室为冲突考场。如果考生重修（补修）课程考试与正常考试冲突，请提前30分钟到E205教室签到，参加考试（连续考试）。

6. 请各学院通知到相关教研室教师和所有学生，**尤其是报名重修（补修）的学生**。

7.如有问题请及时联系教务处，联系电话：86185797。

教务处
