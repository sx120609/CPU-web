# 关于2026级新生查询教育部学籍电子注册信息的通知
来源：https://jwc.cpu.edu.cn/c0/58/c885a245848/page.htm
日期：2026-10-16
部门：教务处

各学院：

按照教育部《普通高等学校新生学籍电子注册暂行办法》，高等学校学生可以在中国高等教育学生信息网（学信网）上查询本人信息，必须保证学生本人信息在学信网上准确无误。

查询时间：即日起至2026年10月26日；

查询办法：登录http://www.chsi.com.cn/；在首页点击“学籍查询”进入：

注册实名帐号后登陆，进入学信档案→学籍信息（图像校对）即可查询学籍信息（如遇到学信网账号相关问题，如手机号已被注册等，请联系学信网客服,电话：010-67410388，邮箱：kefu@chsi.com.cn）。

查询时请仔细核对身份证号、姓名、专业、学制、民族等信息，如有错误请及时联系：025-86185204，饶老师。

为保证我校学生教育部学籍库信息的准确性，请各院系通知到每位学生及时上网查询本人信息。

注：如有更改请参照附件中的说明准备相关材料

附件：中国药科大学本专科学生姓名、身份证等学籍信息更改说明（http://jwc.cpu.edu.cn/23/1f/c866a8991/page.htm）
