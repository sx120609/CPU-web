# 关于公共选修课报名及上课的通知
来源：https://jwc.cpu.edu.cn/b8/40/c884a243776/page.htm
日期：2026-09-09
部门：教务处

各学院：

2026-2027学年第一学期公共选修课报名及上课安排如下：

一、公共选修课报名采用网上报名方法，网址为：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/）, 请注意：务必用电脑进行选课，浏览器推荐使用windows系统下的360安全浏览器的兼容模式。手机浏览器可能会出现无法退选等未知问题。

二、报名时间为2026年9月10日12:00（周四）—9月13日24:00（周日）；学生选课具体安排及要求见《关于公共选修课学生网上报名的安排及要求》。

三、9月14日（第三周）公共选修课正式上课，公共选修课课表可于9月14日在教务处主页的课表查询中下载。9月14日后任课教师可从个人的教师空间中查询公共选修课的学生名单。

四、请各院部系教学秘书及时通知有关学生和任课教师。务必通知到每位学生仔细阅读《关于公共选修课学生网上报名的安排及要求》后再正确选课。

五、请各同学们注意，各专业学生在校期间美育课学分要求详见各专业《教学一览》（如果教学一览中未体现相关要求，则默认为至少选修一门）。美育类公选课在选课系统中会标注类别。人文艺术类学分等同于美育课程学分。

六、浏览器不兼容退课失败的同学，可前往A106韩老师处借用电脑，登陆选课系统并退课。

七、已结业的学生线下选课，在选课时间内将纸质选课申请（无固定格式）递交到行政楼202陈老师处，并现场付费，1学分/100元。上述申请和付费均可请别人代交。

教务处

2026年9月9日

附1：关于公共选修课学生网上报名的安排及要求

一、选课范围：2022临床、2023、2024、2025级在籍本科生

报名网址为：http://jwc.cpu.edu.cn；报名时间为2026年9月10日至9月13日。

报名安排：

·第一阶段报名（9月10日12：00至9月10日23：00）：报名先到先得，额满为止，本阶段只能选课，不能退选。

·退选阶段报名（9月11日8：00至9月11日12：00）：本阶段**集中退选，不能选课**，退出的名额集中回收到课程池。本阶段结束后，不可再次退课。此阶段结束后，报名人数未达15人的课程停开，停开的课程将于本阶段结束后在教务处主页另行通知，请各院部系教学秘书按时查看，通知相关学生与教师。

·补选阶段报名（9月12日上午9:00至9月13日24：00）：选择已停开课程的（与前阶段忘记选课的）同学补选其它公选课。本阶段选课**只能选课，不能再退选**，请慎重选择。

二、请同学们注意，各专业学生在校期间美育课学分要求详见各专业《教学一览》。

三、所有学生退出学生空间前务必再次登录确认课程是否已选上。选课时间截止后，选课系统将关闭，无法选课。系统运行正常的情况下拒绝任何原因任何形式的手工选课申请。

四、退补选阶段结束后，请已报名的学生务必登录学生空间查看课表，确认是否报名成功。名单以外的学生，不得参与上课,即使参加上课与考核，其成绩也不予承认。

五、各门公选课的上课对象及具体要求见课程介绍，请同学们仔细阅读；课程介绍见通知附件。特别注意，同一门课程不能重复选修。

六、已结业的学生线下选课，在选课时间内将纸质选课申请（无固定格式，需写明学号，姓名，专业，申请课程名称和课程编号）递交到行政楼202，并现场付费，1学分/100元。上述申请和付费均可请别人代交。

七、9月14日（第三周）公共选修课正式上课，公共选修课课表可于9月14日在教务处网页课表查询一栏下载。

八、因选修课资源有限，全校学生每人限选**三**门课程。选课操作完成后请退出学生空间，再次登陆确认所选课程是否已选上。选课成功后无故不听课或不参加考试的学生，该课程成绩以“缺考”记入学籍档案。

九、请仍然缺公选课学分的毕业班同学务必在选课期间网上选课，避免因错过选课导致学分不够而影响毕业。

十、各年级的《教学一览》上公共选修课学分要求是针对本科生在校期间的学习要求，本学期未选到课的学生可以在下学期继续选课。

十一、校际联盟课程针对大二、大三、大四本科生开放。

十二、如遇校际联盟课程问题，请拨86185207，联系人：李老师。如公共选修课网上报名有问题请拨86185797，联系人：陈老师。
