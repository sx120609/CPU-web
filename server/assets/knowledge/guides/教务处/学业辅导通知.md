# 关于开展2026-2027学年第一学期学业辅导的通知
来源：https://jwc.cpu.edu.cn/c2/e3/c948a246499/page.htm
日期：2026-10-28
部门：教务处

各学院：

根据《中国药科大学学业指导与支持工作管理办法》（药大教〔2023〕210号）和《中国药科大学学业预警工作管理办法(2021年修订)》（药大教〔2021〕80号）相关文件精神，学校学生学业支持中心每学期有针对性地开展学业辅导，帮助学生（尤其学业困难学生）提高课程学习成效。现将具体通知如下：

一、辅导对象

1. 基础薄弱或学习相关课程存在困难的学生；

2. 未通过相关课程考试，且已在教务系统报名重修的学生；

3. 正在学习相关课程的预警学生；

4. 其他有意向参加指导的学生。

二、相关要求

1. 辅导以帮助学业困难学生提高学业成效为目标，指导教师应有针对性地准备教案、内容和试题等，帮助学生了解课程学习的方法、要点，指导学生做好本课程的学习规划。

2. 辅导过程中建议以问题为导向设计课堂组织形式，有条件的情况下，按照学生学习该课程的困难类型（学习方法、基础薄弱、课程兴趣等）进行分组教学；建议开展过程性考核（如随堂测验），根据测验结果循序渐进调整后续课程安排。

3. 辅导期间指导教师可以根据需要向学业支持中心申请教学助理，协助其共同做好辅导工作。

4. 参加辅导的学生，应总结学习该课程中遇到的难点，及时反馈给指导教师，结合授课内容巩固学习效果，做好辅导后的复习工作，学有所得。

三、辅导安排

本学期，基础类课程由学校统一安排，其他课程由各学院自行按需申请开设。

1. 基础类课程

基础化学、高等数学、大学英语等基础类课程，具体安排见附件1。

2. 其他课程

各学院根据课程不及格率和学生学业预警情况，做好相关课程的申报及组织工作。学院将课程报教务处，组织学生报名和教师授课工作，报名人数低于15人的课程原则上不予集体开课。

学院需要开设辅导的，需填写《中国药科大学学业辅导申请表》（附件2），以学院为单位，于11月2日前报送学业支持中心。

四、工作流程

学校学业支持中心发布辅导计划=>辅导员组织学生报名=>学业支持中心将报名情况反馈给学院和指导教师=>指导教师有针对性地准备教案、内容和试题等，辅导员督促学生按时参加辅导=>指导教师授课=>指导教师在授课过程中可开展过程性考核（如随堂测验），根据测验结果调整课程后续安排=>辅导效果评估

五、辅导报名

11月2日17:00前，学生通过点击链接（https://v.wjx.cn/vm/eWcGICs.aspx）或者扫描以下二维码进行报名。红色预警及以上学业预警级别且报名参加相关课程重修的学生，原则上必须参加。

六、其他事项

1. 请各学院做好学业困难学生学业帮扶工作，参与学业辅导的组织管理，指导教师填写《中国药科大学学业辅导考勤表》（见附件3），报送学业支持中心。

2. 学业支持中心将抽查辅导质量和学生参与辅导情况，做好辅导过程的资料收集、整理工作，备案课时量，通过随机抽样调查，开展学生教学评价工作。

3. 辅导课酬标准参照相关文件执行。经批准开课的课程，由开课学院教学秘书申报，学业支持中心审核汇总，按学期发放。

4. 联系方式：025-86185797。
