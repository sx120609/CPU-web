# 关于组织2026年中国药科大学英语水平考试的通知
来源：https://jwc.cpu.edu.cn/9f/0e/c887a237326/page.htm
日期：2026-05-08
部门：教务处

各学院：

根据学校有关规定及安排，现将2026年中国药科大学英语水平考试工作相关事项通知如下：

一、考试资格

1. 本校2026届预计毕业生（英语专业除外）中未通过全国大学英语四级考试者。

2. 本校2025届已毕业（结业）学生（英语专业除外）但未通过全国大学英语四级和英语水平考试者。

3．本校2024届已毕业（结业）学生（英语专业除外）但未通过全国大学英语四级和英语水平考试者。

二、考试命题

参照目前全国大学英语四级考试的标准和题型。试卷总分为100分，由四大部分构成：写作、听力、阅读、翻译。具体内容如下：

（1）写作（Writing）分值比例为15%；写作的体裁包括议论文、说明文、应用文等。

（2）听力（Listening Comprehension）分值比例为35%。

（3）阅读（Reading Comprehension）分值比例为35%。

（4）翻译（Translation）分值比例为15%；翻译的题型为段落汉译英，内容涉及中国的历史、文化、经济、社会发展等。

三、考试安排

中国药科大学英语水平考试每年举行一次，本次考试时间定于2026年5月26日（星期二）上午9：00—11：20举行，时长140分钟。考试地点：江宁校区教学楼C101。

四、准考证发放

具备本次考试资格的学生准考证由教务处提前发放到各学院，由各学院发给学生，请及时联系辅导员老师领取。

五、考试成绩公布

5月26日后，由学校统一公布考试成绩，考试成绩60分及以上为合格。

六、学校英语水平考试不收取任何费用，各单位不得举办任何形式的辅导班。

七、由学生所属学院负责通知具备考试资格的学生，具体名单见附件。因本次考试涉及到学生的学位获得，请各学院务必通知到每一位具备考试资格的学生。
