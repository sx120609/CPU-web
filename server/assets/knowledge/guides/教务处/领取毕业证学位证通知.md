# 关于2026届本科毕业生领取毕业证、学位证的通知
来源：https://jwc.cpu.edu.cn/ae/b2/c885a241330/page.htm
日期：2026-06-12
部门：教务处

各学院：

关于我校**2026**届本科毕业生领取毕业证、学位证及证书外壳的安排如下：

一、**证书发放安排**：**2026**年**6**月**15**日上午

**9:30-10:30**：药学院，孟院，生科院，理学院，外国语学院

**10:35-11:40**：中药学院，商学院，基临院，工学院

发放地点:教学楼**A105**。集中发放的证书为第一批符合毕业及学位条件的学生证书，发放方式为毕业班辅导员集中统一领取所带班级的双证，同时领取学位授予决定。往届共3位学生的证书，请各学院安排一名人员前往**A105**以学院为单位领取。

**注意事项：当天同时领取档案用成绩单并现场盖章**，辅导员可带两名学生一同清点核对证书和盖章，辅导员必须到场。

**二、外壳发放安排：2026**年**6**月**15**日上午

**9:30-10:30**：药学院，孟院，生科院，理学院，外国语学院

**10:35-11:40**：中药学院，商学院，基临院，工学院

发放地点：教学楼**A101**

请每个班班长和学习委员按时前往指定地点领取外壳，过期关门将无法领取。
