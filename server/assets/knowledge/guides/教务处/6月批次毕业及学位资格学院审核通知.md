# 2025-2026-2学期毕业及学位授予资格学院审核工作（2026年6月批次）通知
来源：https://jwc.cpu.edu.cn/a3/c3/c885a238531/page.htm
日期：2026-05-19
部门：教务处

根据学校工作安排，2026届本科毕业生以及往届生的毕业及审核工作开始。学院毕业及学位授予资格审核流程为：学院政治审核-学生申请-学院初审。具体工作安排如下：

1、5月24日前在教务系统完成思政审核；（操作步骤见附件一）

2、5月24日-5月31日23:00前学生（包括2026届所有应届生以及往届学生中需要申请毕业或学位的）在个人教务系统中进行线上毕业资格及学位资格审核申请，同时将《学位申请书》纸质材料交到学院；（操作步骤见附件二）

请往届生申请时同时提交《往届生论文信息表》（附件六）。

3、6月1日-6月6日学院毕业资格审核委员会进行学院初审，初审名单需在线上审核通过并将《毕业资格初审汇总表》（附件三）、《学位初审结果报告》以及《往届生论文信息表》（附件六）（此表只需提交审核通过的往届学生的相关材料）的纸质材料签字盖章交到行政楼202，并以院部为单位将《往届生论文信息表》（附件六）发送到jandycj@163.com。未通过初审的应届生名单需经学生签字确认后由学院留存。（操作步骤见附件四）

4、复审通过后，教务处将《中国药科大学学位授予决定》下发到学院，学院将《学位申请书》及《中国药科大学学位授予决定》一并放入学生档案。（《学位申请书》见附件五）

5、未能在本批次通过审核的同学请关注教务处通知，在本学期结束前还将开放7月批次，申请和审核的时间另行通知。

毕业学位学院审核工作为学校毕业审核工作的重要环节，关系到学生能否顺利毕业获取学位，请各学院高度重视并指派专人负责此项工作。为确保我校2026届毕业生各项工作顺利进行，请各学院严格按照教务处工作安排进行，务必在规定时间内完成。
