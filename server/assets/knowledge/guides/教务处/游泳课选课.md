# 2026‑2027学年第1学期游泳课选课通知
来源：https://jwc.cpu.edu.cn/bb/56/c884a244566/page.htm
日期：2026-09-24
部门：教务处

为进一步激发大学生游泳运动兴趣，帮助学生掌握游泳技能，提升身体素质，习得水上自护自救本领，体育部于2026年10月12日—12月2日开设游泳公共选修课。现将有关事项通知如下：

**一、选课对象**：本科阶段所有学生

**二、课程性质：**公共选修课

**三、课程学分、学时等：**0.5学分，16学时

**四、选课、开课时间及要求：（一）选课时间**

2026年10月8日（星期四）12:00—17:00**，**选课时间截止后，选课系统将关闭，无法选课。在选课系统运行正常期间，不受理任何手工补选申请。

**（二）选课健康要求**

患有心脏病、心脑血管疾病、癫痫、传染性疾病等不适宜参加游泳运动的学生，不得选报本课程。

存在高血压、哮喘、近期手术、耳部疾病等情况的学生，请审慎选课，建议先行咨询任课教师，评估自身身体条件是否适宜参加游泳课程学习。

**（三）开课时间**

根据教学计划安排，本学期公共选修课游泳课程自2026年10月12日（第7周周一）起开课，课程周期至12月2日结束。选课学生需完成8次课程学习，每周上课1次。如遇法定节假日与课程冲突，课程顺延。

学生选课成功后，请加入对应任课教师QQ群，课程相关安排、注意事项均在群内发布。

上课时间为每周一、周二、周三的上午、下午。每日设置4个教学时段，每课时60分钟。具体安排如下：

10月12-14日、10月19-21日、10月26-28日、11月2-4日、11月9-11日、11月16-18日、11月23-25日、11月30日-12月2日。

第一时段：10：00～11：00

第二时段：11：00～12：00

第三时段：13：30～14：30

第四时段：14：30～15：30

**（四）上课地点：**中国药科大学游泳馆

**（五）其他说明**

1. 学生须自备泳衣、泳帽、泳镜等个人游泳装备，泳帽为进入泳池的必备用品，无泳帽不得入池。

2. 本课程严格执行学校公共选修课考勤管理规定，学生应按时参加课程学习；无故缺课、旷课将按照学校公选课相关管理规定予以处理。

3.学生上课期间务必注意人身安全，遵守课堂纪律，严禁跳水、追逐打闹等危险行为。

4. 学生应如实告知任课教师自身健康状况，如课程学习过程中身体出现不适，须第一时间向任课教师报告。
