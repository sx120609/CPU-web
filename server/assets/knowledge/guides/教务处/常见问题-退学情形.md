# 学生在什么情形下，应予以退学?
来源：https://jwc.cpu.edu.cn/28/15/c855a10261/page.htm
日期：2025-09-23
部门：教务处

【问题描述】： 学生在什么情形下，应予以退学?

【问题类别】： 学籍管理

【更新日期】： 2010-3-25 16:40:57

【答案】：

（一）未经批准，超过学校规定期限,未办理注册手续者；

（二）不论何种原因，在校学习时间超过最长学习年限者；

（三）除应征参加中国人民解放军（含中国人民武装警察部队）外，休学超过两年者；学生应征参加中国人民解放军（含中国人民武装警察部队）保留其学籍至退役后一年；

（四）休学期满，在学校规定期限内未提出复学申请或者申请复学经复查不合格的；

（五）经学校指定医院诊断，患有疾病或意外伤残无法继续在校学习的；

（六）未请假离校连续两周未参加学校规定的教学活动；

（七）因其他特殊情况，学校认为必须退学者；

（八）

本人申请退学的。
