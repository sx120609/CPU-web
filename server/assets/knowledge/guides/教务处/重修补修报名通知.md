# 2026-2027学年第一学期重修（补修）报名通知
来源：https://jwc.cpu.edu.cn/b7/e5/c886a243685/page.htm
日期：2026-09-08
部门：教务处

各学院：

根据校本科学生学籍管理规定，学生修读必修课程经补考仍未通过的，可以办理重修手续，重修时间一般安排在下年度相对应的学期进行。

重修报名手续包含网上报名和网上缴费两个阶段，已网上报名并缴费成功的为有效报名。本学期可以报名重修原各学年第一学期的课程。有关重修的相关规定请参阅《中国药科大学本科学生学籍管理规定》。

重修报名具体安排如下：

**一、网上报名时间及方法1.报名时间：**2026年9月9日9:00 — 9月14日22:00。请务必按时报名，逾期系统将自动关闭，不能补报。非报名时间内可在系统查询课程。

**2.报名方法：在校生：**

学生登录药科大学信息门户，进入教务系统首页，点击左侧“考试成绩→补重管理→重修报名选课”，选择要重修的课程，点击“报名”并确定。

**结业生：**

教务系统登录地址：http://jwxt.cpu.edu.cn/jsxsd

账号：10位学号。

默认密码：Cpu+@+身份证号后6位，如Cpu@123456。

登录后报名操作同在校生。

**3.注意事项：**已报名的课程会在“是否报名”栏显示“√”，报名后请务必再次核实。

**二、重修费缴纳1.缴费时间：**2026年9月17日—22日（提醒：22:00--0:00不要缴费），请务必在规定时间内缴费，逾期系统将自动关闭。

**2.缴费标准：**100元/ 学分，收费依据见校计财处网站。

**3.缴费方式：**网上自主缴费。学生登录校计财处“网上缴费平台”（http://pay.cpu.edu.cn/payment/），不用注册，直接以用户名和密码登录：

**用户名：**10位数的校园卡号

**初始密码：**Jfpt@身份证号码后6位（第一位字母大写）

**缴费项目：**26-27-1学期重修缴费

缴费时请务必核实学分总数和所缴金额，一旦缴费成功，不能退费。

**4.特别注意：**因教务处网上重修报名和计财处网上缴费是不同系统不能实时同步信息，缴费成功后，不会立刻在重修报名页面有显示。在整体缴费时间结束后三个工作日内，教务处会统一处理，已缴费成功的报名课程会在报名页面的**“是否缴费”**栏显示“√”。“是否报名”栏和“是否缴费”栏均显示“√”为有效报名。报名页面上的“是否选课”、“取得资格”等其它项目不会有显示，请忽略。

**三、重修证**

报名缴费结束后，学生可在报名端自行打印重修证，学生凭重修证参加重修考试。

**四、重修课程的学习和考核1.理论课**

理论课重修一般不单独安排上课或辅导，无平时成绩且不参加期中考试。学生报名成功后可根据自己的情况选择低年级的相同或相近课程听课，也可通过网络教学平台自主学习。学生应主动跟所重修课程的开课教研室或任课教师联系，确定重修听课及考试相关事宜。理论课重修考试时间一般与期末考试同时进行。

**2.实验（实训）类课程**

已预报名的实验（实训）类课程，务必在网上正式报名和缴费。实验（实训）类课程重修考核时间和方法由该课程教师自行安排。

**3.体育课**

体育课重修的具体测试项目请到体育部网站查询《体育考试办法》，具体测试时间请咨询体育部。

**4.其它特殊类型的课程**

请学生自行与开课教研室或任课教师联系。

**五、补修和提前重修1.补修本学期开始，补修直接在系统报名。**补修与普通重修一致，只能报各学年第一学期的课程。如有第二学期课程补修请参考提前重修流程

**2.提前重修（补修）**

本学期可以报名重修原各学年第一学期的课程。如果有其它年级（专业）开设相同课程编号的非本人学年第一学期的课程（新教务系统支持学生查询全校课表，），且本人希望提前到本学期重修的，可以在重修报名期间填写《提前重修申请表》（教务处网站下载专区可下载）并经相关院部签字盖章审核通过后交到行政楼202，待教务处将相关课程信息加入报名系统后，再进行报名。请务必关注重修报名系统，一旦课程信息加入后请及时报名。后续各步骤及安排与重修一致。

原则上报名之后不能退出，如因特殊情况确需取消重修报名的，请于考试周之前，本人书面申请学院签字盖章后将纸质申请交到行政楼202，重修费用无法退回。

特别提醒：根据学籍管理规定要求，课程报名重修后，以最后一次成绩作为本课程的最终成绩，即重修考试的成绩会覆盖前面的成绩，请各位同学注意。

请报名重修的同学及时与开课教研室或任课教师联系。

请欲报名的同学仔细阅读以上说明，如还有其它疑问，务必在重修报名期间联系教务处陈老师（行政楼202电话86185797）。
