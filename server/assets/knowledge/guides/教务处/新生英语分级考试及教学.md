# 关于2026级本科生英语分级考试及教学的通知
来源：https://jwc.cpu.edu.cn/b7/f1/c887a243697/page.htm
日期：2026-09-08
部门：教务处

2026级本科生：

为更好地满足广大同学对英语课程学习的需要，充分调动学习积极性，做到因材施教、分类指导，学校将对2026级本科生开展英语分级考试及教学。现将有关事项通知如下：

**（一）参加分级考试及教学对象**

2026级本科生，以下专业除外：药学（杰出药学家实验班）、临床药学（卓越药师实验班）、药学（拔尖创新班）、中药学（拔尖创新班）、生物制药（拔尖创新班）及英语专业。

**（二）考试安排**

考试时间：**普通班为9月15日（周二）18:00-20:00，不包含药学（中外合作办学）、临床药学（中外合作办学）专业。中外合作办学班为9月15日（周二）18:00-20:30，包含药学（中外合作办学）、临床药学（中外合作办学）专业**。

参加考试的学生请携带身份证，提前15分钟到指定考场（见附件安排）参加考试。

本次**普通班**考试的题型贴近大学英语四级考试题型，包括作文、听力、阅读理解、选词填空、段落翻译，满分为100分，考试时长2小时；**中外合作办学班**考试的题型贴近雅思考试题型，包括听力、阅读理解、图表型作文和议论文写作，考试时长2.5小时。

本次**普通班**考试需要**涂答题卡**，请学生自带HB-2B铅笔，**中外班**考试不涂卡。所有班听力考试部分全部使用教室电脑放音，学生无需携带耳机。

**（三）分级教学层次及分级依据普通班**大学英语课程分级教学分为三个层次，即（A、B、C级）。根据英语分级考试成绩和学生个人意愿选拔成绩优秀的240名左右的学生进入A级（愿意进入A级且成绩相同的情况下依次比较作文、听力、翻译、阅读部分的得分）；C级针对英语基础薄弱，包括高考外语语种为小语种的学生，结合分级考试成绩和学生个人意愿，自愿报名构成，总人数在120人左右，报名C级的同学请在分级考试结束后到9月25日之前加QQ群152678717自己报名；其余学生为B级学生。因病、事假无法参加英语分级考试的学生直接编入B级。

**中外班**不进行分级教学，通过模拟雅思考试了解学生的进校英语水平，为教师日常教学提供参考。

**（四）普通班分级教学内容和模式**

A级的教学目标：

1. 巩固和提高听说读写译能力；

2. 加深语言知识的广度和深度，增强学生英语思辨能力、公共演讲和跨文化交际能力；

3. 从人文教育、批判性思维、跨文化意识等多角度学习教材，发挥大学英语课程的新优势；

4. 学习英语写作策略与方法，提高学术英语写作能力。

在大一第二学期的时候，A级的同学会较为系统地学习学术英语课程。

B级的教学目标：

1.按照大学英语教学指南的“提高”要求培养学生的听说读写译能力；

2.扩大专业知识面，提高文化知识素养；

3.教学中体现大学英语课程的人文性和工具性的特性。

C级的教学目标：

1. 帮助英语基础薄弱的学生打基础；

2. 帮助学生通过四级考试；

3. 按照大学英语教学指南的“基础”要求培养学生的具备大学毕业生应有的听说读写译能力。

普通班A、B、C级的具体课程介绍请查看超星学习通上的《2026级大学英语新生导学课》，网址：https://mooc1.chaoxing.com/mooc-ans/course/portal/2RPrIQ4GVJ704-fASE5eUg==?edit=true

分班结束后，学生可于9月25日在教务系统的课表里查询自己的英语课班级，上课教室及任课教师。

请参加英语分级考试的同学做好准备工作。如有疑问请联系教务处，电话：025-86185797。
