# 2026届毕业生学生证注销的通知
来源：https://jwc.cpu.edu.cn/ae/f4/c948a241396/page.htm
日期：2026-06-15
部门：教务处

各院部:

2026届毕业生即将离校，为了保证毕业生离校工作的顺利进行，请各院系在毕业生返校后，于2026年6月15日起进行毕业生学生证注销工作，具体时间由各院系自行安排，该工作在6月23日之前完成。(若注销时有部分毕业生的学生证已经丢失，请学生登报进行学生证作废声明操作，可将登报的截图或者打印纸质交由辅导员，由院部把关。)

特此通知。

教务处

2026年6月15日

注：学生注销后仍然可以购买一次优惠学生票
