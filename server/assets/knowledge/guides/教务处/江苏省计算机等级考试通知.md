# 2022秋季江苏省计算机等级考试通知
来源：https://jwc.cpu.edu.cn/a3/e5/c887a173029/page.htm
日期：2022-09-30
部门：教务处

通知

2022年秋季江苏省计算机等级考试定于10月15（周六）、16日（周日）举行,二级为120分钟，请考生凭准考证、学生证、身份证准时参加考试，迟到15分钟不得进入考场，并请考生自备口罩等防护用品。考试为无纸化考试(机考),请考生阅读了解《江苏省计算机等级考试考场指令》。如准考证遗失可在14日（星期五）上午到教务科（行政楼213室）补办。如同学有不清楚的地方可打电话86185204咨询。

教务处

2022年9月30日
