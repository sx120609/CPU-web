# 关于2026届预计毕业生学历证书电子注册信息核对的通知
来源：https://jwc.cpu.edu.cn/84/59/c885a230489/page.htm
日期：2025-12-05
部门：教务处

各学院：

根据省教育厅相关文件要求，为确保我校2026届毕业生学历电子注册信息的准确性，请各学院通知2026届毕业生核对电子注册信息。此信息将同时用于毕业证学位证书打印，非常重要，请各学院务必重视，通知到每个学生。具体说明如下：

1、每位学生必须仔细核对学号、姓名、性别、民族、身份证号、班号、学制、专业等字段；

2、所有出错信息请在书面稿上直接更改，并在班级核对表右下角空白处标注“有更改”，要求更改信息字迹清晰，如更改无法识别则更改无效。若更改姓名或身份证号请按《中国药科大学本专科学生姓名、身份证等学籍信息更改说明》中的要求上交材料；若无证明材料则无法修改。

3、学生核对信息，确认无误后签字；

4、辅导员审核签字；

**每个学生务必认真核对电子注册信息并签字，暂时不在校的学生可委托辅导员或班长代为签字确认信息，务必确保其准确性！因学生本人不认真核对引起的学历证书电子注册信息不正确，后果自负。**请各学院在2025年12月12日前将2026届预计毕业生学历电子注册信息书面稿**以学院为单位**交至行政楼202房间。

教务处

2025年12月5日
