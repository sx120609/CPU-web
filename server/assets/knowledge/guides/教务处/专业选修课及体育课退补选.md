# 关于专业选修课及体育课退补选的通知
来源：https://jwc.cpu.edu.cn/b6/2b/c884a243243/page.htm
日期：2026-08-28
部门：教务处

各院部：

2026-2027学年第一学期专业选修课、体育（三）必修课采用网上报名方法（选课地址：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/），点击“学生空间”登录后中选择学生空间首页的“学生选课中心”，再点击进入选课,请注意：务必用电脑进行选课，手机浏览器可能会出现无法退选等未知问题，如遇到点击选课或退选时提示“请连接VPN”的情况，请试着清除浏览器缓存或换其他类型浏览器重试。出现退课失败是因为浏览器不兼容，推荐使用windows操作系统下的360安全浏览器兼容模式选课），专业选修课和体育课均从第一周开始正常上课，具体安排如下：

一、退补选阶段：2026年8月31日（周一）12:00 — 2026年9月2日（周三）12:00

二、特别注意：参加了转专业、基地班滚动分流、卓越工程师班选拔以及专业分流和分方向的同学，请务必在本阶段按照新专业的课表选课。

三、根据学校要求，欠费学生不能参与选课。本次选课加入了欠费控制，请欠费学生务必在选课期间缴清各类费用并在选课阶段结束前及时选课，关于欠费如有疑问，请咨询学校计财处查询详细欠费情况。

四、专业选修课和体育课的所有项目额满为止。过期无法补选，如错过选课，不能参加专业选修课和体育课上课，即使参加期末考试，成绩也无效、体育课期末成绩将以“缺考”录入系统。

五、未获得学分的同专业低年级的专业选修课已预置进高年级同学的选课界面中，高年级同学正常修读并获得该学分后，计入毕业要求的专业选修课学分，注意：已获得学分课程不能重复选修。

六、已结业的学生线下选课，在选课时间内将纸质选课申请（无固定表格格式）递交到行政楼202，现场付费，1学分/100元。上述申请和付费均可请别人代交。

七、浏览器不兼容退课失败的同学，可前往A106韩老师处借用电脑，登陆选课系统并退课。

八、请各院部系教学秘书及时通知有关学生和任课教师。务必通知到每位学生仔细阅读《关于体育（三）网上选课安排及要求》（附1）和《关于专业选修课学生网上报名的安排及要求》（附2）后再正确选课。

附2：关于专业选修课学生网上报名的安排及要求

2026-2027学年第一学期专业选修课采用网上报名方法（选课地址：http://jwc.cpu.edu.cn（http://jwc.cpu.edu.cn/），进入“学生空间”），退补选时间为:

2026年8月31日（周一）12:00 — 2026年9月2日（周三）12:00。

请严格遵守选课时间，过期选课系统自动关闭，无法报名！

一、选课范围：2025、2024、2023级本科生和2022级临床药学专业学生

二、所有开设的专业选修课可在教务处主页（或选课期间登录选课系统）查询。

三、专业选修课报名后，无故不参加考试的学生，该课程成绩以“缺考”记入学籍档案。

四、**高年级的同学可以选修同专业低年级开设的专业选修课，正常登录选课系统进行选课，学分计入专业选修课学分，注意：已获得学分课程不能重复选修**。如有低年级课程时间与本年级课程冲突而导致无法在系统中选课的情况，请自行协调上课时间并提交书面选课申请（需任课老师签字）。

五、有实验课的专业选修课，该课程的理论课和实验课必须同时选修。不得单独选修该课程的理论课或实验课。例生科院的“抗生素”：已选抗生素理论课的学生，则必须选“抗生素实验”。如单独选“抗生素”理论课或实验课，则视为“无效选课”，即使参加学习和期末考试，期末成绩也将记为0分。如之前学期通过了“抗生素”理论课程但实验课未通过，本学期仅需选“抗生素实验”，则需上课后自行联系“抗生素实验”的任课老师，出示“抗生素”理论课的学分并说明情况，期末考试即可正常计分。如之前学期单独通过了实验课同样适用。

六、报名时间结束前，请同学们务必登陆选课系统或学生空间再次确认课程已报上，如发现未报上，及时在结束前补报。选课系统正常运行的情况下，拒绝任何原因任何形式的手工选课申请与删除课程。

七、请同学们按时选课，所有项目额满为止。过期无法补选，如错过选课，即使参加期末考试，成绩也无效。

八、如网上报名有问题请联系：86185797（陈老师）。

九、请各院部系及时通知到有关学生和任课教师。
