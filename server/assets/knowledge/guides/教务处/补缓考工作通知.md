# 关于2025-2026学年第二学期补（缓）考工作的通知
来源：https://jwc.cpu.edu.cn/b4/d8/c887a242904/page.htm
日期：2026-08-10
部门：教务处

各院部、相关单位：

按照学校部署，现将补（缓）考工作安排如下：

时间：2026年8月28日—8月30日，具体考试日程见附件。

已结业（毕业）学生重修补（缓）考与校内考试同步。

一、工作要求

1. 各院部通知相关课程所属教研室，查看考试日程安排和考试学生名单，准备好补（缓）考试卷等相关事宜。

2. 监考教师发放试卷时注意区分不同专业学生所用试卷，根据考试学生名单（见附件）核对学生的学号、专业等信息，并让学生签到。

3. 参加考试的学生（包括补考、重修补考、正常考试(缓)、重修(缓)）务必仔细查看考试安排（时间、地点），以免错过考试。学生在查看补考日程时，务必核对考试学生名单，确认名单中本人需补（缓）考的课程名称、课程编号与考试日程中的课程名称、课程编号相对应。

4. 学生参加考试必须携带有效证件（学生证或身份证），此外，重修补考的学生需携带重修证，缓考的学生需携带缓考审批单。

5. 各学院必须安排专人巡考，有学生补（缓）考的辅导员必须到场，巡查考试纪律。

6. 任课教师将本人所承担课程的学生成绩，于考试结束后三天内录入教务管理系统。

二、其他事项

1. 体质测试补（缓）考时间预计在开学后第三周，需要补缓考的学生请关注体育部官方网站，将于开学后发布补缓考的时间、地点和注意事项。

2. 补（缓）考课程时间冲突的学生，请务必提前30分钟到教学楼E205冲突考场签字并参加连续考试，中途不休息。

3. 如遇不可抗力影响会对既定工作进行调整，请及时查看教务处通知。

4.教务处联系电话：025-86185797。
