# 关于中国药科大学2026年暑期国际课程项目开放报名的通知
来源：https://jwc.cpu.edu.cn/a2/0d/c854a238093/page.htm
日期：2026-05-15
部门：教务处

各院部：

为进一步提高人才培养质量，拓宽学生国际视野，提升学生跨文化交流能力，学校于2016年暑假期间开始举办暑期国际课程项目（International Summer Course Program, ISCP）。2026年第八届暑期国际课程将于7月开课。上课形式采取讲座和研讨相结合的面授方式，考核形式和内容由主讲老师确定。上课规模为30-60人。学生不出校门便能享受优质国际教学资源，开拓视野，感受国外课堂教学氛围。

在各院部、各部门的大力支持下，本年度受邀任课教师分别来自英国剑桥大学、英国曼彻斯特大学、英国伦敦大学学院、韩国成均馆大学等，课程涵盖医学、药学等领域（课程介绍详见本通知附件）。课程由境外知名大学或机构专家学者采用全英文授课，将通过多样化的授课、讨论、作业和考核方式体现先进本科教育教学理念，所学课程将记入学生成绩单，以“国际课”的类型（非必修，非选修）加以体现。

现将暑期国际课程的报名方法公布如下：

一、报名时间为5月18日中午12:00-5月20日中午12:00。报名采用网上报名方法，报名地址：http://jwc.cpu.edu.cn，点击“学生空间”登录后中选择学生空间首页的“选课中心”，再点击进入选课,请注意：务必用电脑进行选课，手机浏览器可能会出现无法退选等未知问题，如遇到点击选课或退选时提示“请连接VPN”的情况，请试着清除浏览器缓存或换其他类型浏览器重试。出现退课失败是因为浏览器不兼容，推荐使用windows操作系统下的360安全浏览器兼容模式选课。

二、暑期国际课程大多于7月11日至7月17日上课。

三、请各院部系教学秘书及时通知有关学生。务必通知到每位学生仔细阅读《关于暑期国际课程学生网上报名的安排及要求》后再正确选课。

四、暑期课程面向2023、2024、2025级所有专业本科生以及2022级临床药学专业本科生开放。

附件2：关于暑期国际课程网上报名的安排及要求

一、选课范围： 2023、2024、2025级所有专业本科生以及2022级临床药学专业本科生

报名网址为：http://jwc.cpu.edu.cn；报名时间5月18日中午12:00-5月20日中午12:00。点击“学生空间”登录后中选择学生空间首页的“选课中心”，再点击进入选课,请注意：务必用电脑进行选课，手机浏览器可能会出现无法退选等未知问题，如遇到点击选课或退选时提示“请连接VPN”的情况，请试着清除浏览器缓存或换其他类型浏览器重试。出现退课失败是因为浏览器不兼容，推荐使用windows操作系统下的360安全浏览器兼容模式选课。

报名安排：

5月18日中午12:00-5月20日中午12:00。报名采取先到先得的方式，每门课最多容纳60名学生（建议同学们选课时避开已报名人数超出课程限制人数的课程）

二、所有学生退出学生空间前务必再次登录确认课程是否已选上。选课时间截止后，选课系统将关闭，无法选课。系统运行正常的情况下拒绝任何原因任何形式的手工选课申请。

三、选课结束后，请已报名的学生务必登录学生空间查看课表，确认是否报名成功。名单以外的学生，不得参与上课,即使参加上课与考核，其成绩也不予承认。

四、各门课的上课对象及具体要求见课程介绍，请同学们仔细阅读；课程介绍见通知附件。

五、7月11日开始正式上课，课表可于7月11日前在教务处网页查询。

六、因资源有限，每位学生限选一门课程。选课操作完成后请退出学生空间，再次登陆确认所选课程是否已选上。选课成功后无故不听课或不参加考试的学生，该课程成绩以“缺考”记入学籍档案及成绩单。
