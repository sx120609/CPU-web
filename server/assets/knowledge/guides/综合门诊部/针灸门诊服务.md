# 江宁校区综合门诊部新增“针灸门诊”服务
来源：http://jjc.cpu.edu.cn/3b/a0/c548a211872/page.htm
日期：2024-10-14
部门：综合门诊部

各位师生：

为满足广大师生的针灸需求，多元化服务师生健康，江宁校区综合门诊部与校附属浦口中医院开展合作，自2024年10月15日起，新增“针灸门诊”服务。

一、开诊时间

每周二、周四（9:00—12:00；13:30—16:00，以预约系统设定时间为准）

二、开诊地点

江宁校区门诊部二楼201室（2楼右转）

三、开展项目

针对颈腰腿疼痛，颈椎病，腰椎间盘突出、头晕头痛、关节疼痛、偏瘫、面瘫、骨折以及各种手术后期疾病，开展针刺、艾灸、拔罐、小针刀、热疗等治疗，具体治疗方案需经医师诊治后确定。

四、就诊要求

通过微信“扫一扫”下方的二维码（需要在校园网环境下），统一身份认证后，按照说明填报预约信息。未预约成功不能就诊，如需取消预约请致电86185481或86185776。

基建后勤处

2024年10月14日
