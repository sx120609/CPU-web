# 关于2025级新生参加南京市大学生医保的通知
来源：http://jjc.cpu.edu.cn/74/7d/c518a226429/page.htm
日期：2025-08-27
部门：综合门诊部

各位新生：

我校大学生参加南京市大学生基本医疗保险由学校统一办理，个人缴费部分由学校代收代缴。参保缴费后，自下一年度1月1日至12月31日享受相关待遇。其中，首次办理参保缴费后，入学当年的9月1日起即按规定享受相关待遇。

不论是否参加医保，所有新生务必按照流程进行登记办理或不参保备案。请各位新生务必在参加新生入学体检前，完成医保线上填报手续，并体检现场完成最后确认环节。具体参保流程详见附件《大学生医保参保流程》。
