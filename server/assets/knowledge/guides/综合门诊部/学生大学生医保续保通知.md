# 关于各年级学生办理大学生医保续保的通知
来源：http://jjc.cpu.edu.cn/76/54/c518a226900/page.htm
日期：2025-09-09
部门：综合门诊部

各位同学好：

中国药科大学2026年度大学生医保续保工作即将开始，请各年级因各种原因（如因病休学、参军等）未能在所读学制内按时毕业的同学，主动于9月10日—9月26日（工作日9：00—15：00）至江宁校区综合门诊部医保办公室（三楼304）办理续保手续，逾期未成功办理续保，视为自动放弃，后期发生所有医疗费用由本人及家庭承担。

望各位同学认真对待此项工作，相互转告，谢谢配合！
