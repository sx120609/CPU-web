# 就医指南
来源：http://jjc.cpu.edu.cn/516/list.htm
部门：综合门诊部

自2023年1月1日起，我校教职工和大学生医疗保险已全部纳入南京市医保中心统筹管理，为方便师生就医，我校两校区综合门诊部均已成功获批为南京市医保定点医疗机构（参照社区医疗机构管理），现将两校区综合门诊部就诊流程及门诊时间调整如下：

一、就诊流程

1、门诊就医均须持医保卡（或电子医保凭证）进行实时结算


二、门诊时间

1、江宁校区

门诊时间：9：00—18：00

急诊时间：24小时

2、玄武门校区

门诊时间：周一至周五9：00—12：00，13：30—17：00（法定节假日除外）
