# 门诊部简介
来源：http://jjc.cpu.edu.cn/515/list.htm
部门：综合门诊部

中国药科大学综合门诊部隶属于国家首批“211工程”重点建设高校、“双一流”建设高校——中国药科大学，归口基建后勤处管理，是江苏省高等教育学会卫生健康研究会常务理事单位、南京市企事业单位医疗机构管理协会会员单位。门诊部分设玄武门校区和江宁校区两个医疗点。其中，玄武门校区医务室设立于1959年，现注册于鼓楼区卫生健康委员会；江宁校区门诊部设立于2006年，现注册于江宁区卫生健康委员会。

一、人员与科室设置

目前，综合门诊部共有卫生技术人员29人（在职在岗10人，外聘人员18人），其中高级职称7人，研究生以上学历7人。设有内科、外科、妇科、中西医结合科、眼科、耳鼻喉科、预防保健科等临床科室，以及医学检验科、医学影像科（含X线、超声、心电图）、护理部、财务科等医技与职能科室。

二、设备配置

综合门诊部配备先进的医疗仪器设备，包括数字化X线摄影系统（DR）、西门子彩色超声诊断仪、全自动生化分析仪、血球分析仪、尿液分析仪、血流变分析仪、糖化血红蛋白检测仪、十二导联心电图机、低频电子脉冲治疗仪等，并配有完善的计算机网络管理系统，保障医疗服务高效、精准开展。

三、主要职责

综合门诊部承担着全校师生员工的常见病、多发病诊疗及24小时院前急救服务，具体职责如下：

1、提供学校师生常见病、多发病的诊疗服务；

2、承担南京市城镇职工医保、大学生医保的日常管理和相关工作；

3、负责传染病防控及医院感染控制工作；

4、定期组织健康教育宣传活动；

5、配合相关部门开展校园食品、药品安全监督与检查；

6、协助处理学校公共卫生突发事件；

7、指导校内红十字会工作及大学生应急救助工作；

8、组织实施各类体检、健康监测及健康管理；

9、为学校重大活动提供医疗保障服务。

四、特色医疗服务

近年来，江宁门诊部联合学校各附属医院，持续推出多样化特色医疗服务，包括针灸门诊、中医专病专治门诊、中医“治未病”服务、代谢异常专家门诊等，深受广大师生欢迎。

中国药科大学综合门诊部全体职工始终秉持“关爱师生，呵护生命”的服务理念，认真履行各项职能，不断提升医疗质量和服务水平，致力于为广大师生员工提供更加优质、便捷、暖心的医疗卫生服务。
