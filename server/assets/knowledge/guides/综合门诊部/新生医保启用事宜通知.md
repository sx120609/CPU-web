# 关于新生医保启用事宜的通知
来源：http://jjc.cpu.edu.cn/50/c2/c518a217282/page.htm
日期：2024-10-23
部门：综合门诊部

各位新生辅导员：

2024级新生医保已基本办理完成，烦请各位老师将新生医保启用事宜通知到每位新生，具体如下：

1.参保成功的新生可正常使用电子医保进行就医就诊；

2.尚有部分学生因存在未缴费，核实姓名、身份证号码等问题未成功参保，近期将逐一修正再进行参保，如遇特殊情况会单独联系学生；

3.学生可通过识别下图海报二维码，关注“南京医保”微信公众号，申领本人电子医保码和查询参保情况等事项。

中国药科大学医保办

2024年10月23日
