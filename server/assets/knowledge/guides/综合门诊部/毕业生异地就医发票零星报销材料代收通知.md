# 关于2025届毕业生异地就医发票零星报销材料代收的通知
来源：http://jjc.cpu.edu.cn/6d/2f/c518a224559/page.htm
日期：2025-06-10
部门：综合门诊部

各位同学：

根据《南京市城乡居民医疗保险指南》规定，如您有2025年异地就医无法结算的医疗费用可申请零星报销，校医保办将统一代收零星报销材料：

一、材料接收时间

6月16-17日上午9：30-12：00；下午1：30-3:30

二、材料接收地点

江宁校区综合门诊部304室

三、材料准备

1.门、急诊：发票原件、明细清单原件、就诊病历原件、身份证复印件（写上学号、联系电话）、非户籍地需提供医疗费用产生地实习证明或委培协议；

2.住院：发票原件、明细清单原件、出院小结原件、身份证复印件（写上学号、联系电话）、非户籍地需提供医疗费用产生地实习证明或委培协议。

四、特别提示

1.如本人不能前往，可请他人代送报销材料。

2.离校后请暂不注销学费银行卡以便汇入报销款。

3.毕业生医保待遇享受期截止日期为2025年12月31日。毕业生如需停保可通过“我的南京”app医保服务—业务办理板块“毕业大学生停保”模块办理大学生停保的手续；或进入“南京医保”微信公众号服务大厅“大学生服务专区”中的“停保登记”模块办理。

4.学生毕业后如发生异地门诊或住院费用，请在费用结算前关注“南京医保”微信公众号，登录后通过“服务大厅”中的“异地就医备案”栏填写申请并提交材料供南京市医保审核，审核通过后可持省卡或南京第三代市民卡刷卡结算医疗费用。

中国药科大学医保办

2025年6月10日
