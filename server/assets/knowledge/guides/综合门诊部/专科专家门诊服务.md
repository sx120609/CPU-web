# 江宁校区综合门诊部新增“专科专家门诊”服务
来源：http://jjc.cpu.edu.cn/3b/9f/c548a211871/page.htm
日期：2024-10-21
部门：综合门诊部

各位师生：

为满足广大师生的健康新期盼，持续提升校园医疗服务水平，经专科专家门诊师生需求调研，江宁校区综合门诊部自2024年10月23日起，定期邀请校附属医院专家进校园，将“专家门诊”服务带到师生身边。

一、开诊时间

每周三（9:00—12:00；13:00—16:00，以预约系统设定时间为准）

二、开诊地点

江宁校区门诊部二楼

三、门诊安排

每周三开设专科专家门诊，具体开设科室（中医科、消化内科、妇科、呼吸内科、甲乳外科等）、专家信息、诊疗范围、就诊地点每月更新，详见预约系统。

四、就诊要求

通过微信“扫一扫”下方的二维码（需要在校园网环境下），统一身份认证后，按照说明填报预约信息。未预约成功不能就诊，如需取消预约请致电86185481或86185776。

基建后勤处

2024年10月21日
