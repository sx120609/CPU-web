# 毕业生重领《就业推荐表》申请表
来源：https://cpu.91job.org.cn/sub-station/detail?xwid=171517&xxdm=10316
日期：2022-03-06
部门：招生就业处

附件：毕业生重领《就业推荐表》申请表.doc（制表：中国药科大学就业办公室）

表格栏目：姓名、性别、申请原因、辅导员意见、院系分管毕业生就业工作负责人签署意见（公章）、学生工作处就业办公室审核意见（公章）、备注。

申请原因（选择一项）：

1. 遗失补办：本人因保管不慎，将推荐表丢失，现申请补办。申请人签字。要求：（请附上登报的遗失启事）
2. 换领(破损、污损、填写错误)：申请人签字。要求：请附原破（污）损、填写错误的《就业推荐表》
3. 因解约重新申领：申请人签字。要求：请附原签约单位解约函

填表说明：

1. 请按照各自情况在“申请原因”栏中选择一项，在方框内“√”；并按要求附相关材料。
2. 如有特殊情况需由院系出具说明。
